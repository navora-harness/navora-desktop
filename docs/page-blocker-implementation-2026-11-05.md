# 网页阻断观察与人工交接：宿主实现及验证

日期：2026-11-05。源码实现；没有重新打包。本文对应详细规划第 4 节，产品界面与运行历史由本轮总集成验证。

## 已实现的数据流

- `shared/page-blocker.ts` 定义版本 1 宿主摘要：`unknown / not_observed / suspected / confirmed`、验证／登录／普通站点对话框类型、观察身份、视口范围、覆盖与遗漏原因、至多四条结构化证据。`not_observed` 仅指此次视口检查未发现阻断。
- `page-blocker-observer.ts` 使用固定只读脚本检查可见性、视口交集、验证提示及控件、容器和前景命中点；独立于正文 `MAX_NODES`。最多 64 个候选容器、8 个可见直属子 frame，整个探测上限 1,500 ms。跨域直属 frame 使用 Electron 实际提供的 `WebFrameMain.executeJavaScript` 读取宿主固定探针，不声称浏览器提供原生“检测验证码”接口。
- 域名或隐藏 iframe 不足以确认；确认本人验证需要当前视口内具体提示／控件、前景与阻断容器相符。普通 Cookie 对话框归为 `site_dialog`，不强制本人接管；验证及登录归为需要本人处理。透明前景、嵌套 frame、无法读取、节点／frame 截断和超时保留覆盖不足，不声称页面畅通。
- 相同文档及候选几何／前景代次的疑似线索至多一次额外只读检查；仍未确定转为 `unknown`，不循环刷新、点击、加载音频或绕过验证。新增摘要不保存验证题目、答案、输入原文、Cookie、token、URL 查询参数或 IP。
- `browser-tool-coordination.ts` 为单工具、Flow 子动作、插件浏览器宿主调用提供同一入口。新动作在取得页面租约后再次检查，覆盖排队期间新出现的验证。需要本人处理的页面拒绝输入、任意 evaluate、导航／刷新及该页或会话请求／下载，保留已经结算的数据。无关页面仍可操作。
- `browser_get / browser_evaluate / browser_screenshot / browser_wait` 回执附独立 `pageBlocker`；脚本成功额外说明 `scriptCompleted`，正文可读与前台被阻断可以同时成立。首次发现需要本人处理时，当前读取结算后复用控制器暂停与安全清理；后台观察不夺走用户已经持有的控制权。
- 控制器 `resume()` 先重新检查，仍受阻或未确认则拒绝恢复。复查通过后只恢复新操作资格，仍要求重新观察，旧 epoch 的意图继续失效，不启动或重放已经结束的任务。运行 checkpoint、历史引用和“明确继续”的新 run 接线见本轮执行事实实现。
- `page-digest.ts` 在正常、安全摘要、原生空快照和通用缩减路径预留阻断摘要；极小预算保留状态／身份／覆盖／原因，连最小包也容纳不了时明确 `page_blocker_context_budget`，不悄悄消失。

## 同步完成的执行诊断与键盘回读

`BrowserAutomationError.diagnostic` 输出白名单 cause、stage、期望／实际 epoch、documentEpoch 和派发已知性。没有细分的旧失效保留 `unknown`，不猜用户接管；提交后的错误与提交前拒绝区分，原错误码不变。

`browser_press` 的 Tab／Ctrl+A 使用宿主固定前后焦点／选区样本，要求同文档、同控制代次；全选还要求同一字段和实际改变为完整选区。已全选、不支持的子 frame、缺失前样本不补造成功。回执只保存确认状态与布尔值，不保存字段值；字段回读不证明服务端业务保存成功。旧 `sendInputEvent` 无原生投递回执，仅记提交，不伪造原生确认。

## 已通过的验证

1. 定向单元与现有控制器／协调器／原生摘要回归：98 项。包含域名及隐藏线索、前景要求、Cookie 类型、一次补观测、旧文档回执丢弃、排队期间新验证、用户控制保留、页面隔离、请求／下载拒绝、恢复不重放、各摘要预算路径、Tab／全选证据。
2. `npx tsc --noEmit -p tsconfig.node.json` 通过。
3. `node scripts/browser-page-blocker-smoke.mjs`：真实 Electron、临时 profile、双 localhost 合成网页，共 11 组通过：顶层验证、跨域 iframe 验证、隐藏 iframe、真实 1×1 frame、普通验证码技术文章、Cookie 对话框、登录页、被另一前景覆盖的验证、透明前景、嵌套 frame、600 个商品节点及 `MAX_NODES`。最后一组同时核对暂停、evaluate 派发零次、本人接管、未完成拒绝恢复、模拟用户完成后仅恢复资格且保留新观察要求。

验收报告与已目检的前景截图位于 `_planning/page-blocker-verification-2026-11-05/`。测试未访问真实站点、用户账户、既有个人配置或模型；临时 profile 已移除。普通受限沙盒受 Electron 安装目录 ACL 阻止，隔离测试获准在正常宿主权限下执行；没有改动安装目录 ACL。

## 能力边界

不承诺识别所有网站验证。深层嵌套 frame、无法核实的透明／遮挡关系与探测超时保守保持未确认；没有通过验证码或视觉解题。没有新增常驻截图、持久化验证内容或完整工具队列，也没有把 UI 恢复控制当成重新启动聊天的授权。安装包仍需另行构建后才能声明包含本次修复。
