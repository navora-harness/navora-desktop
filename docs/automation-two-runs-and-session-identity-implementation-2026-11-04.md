# 自动化恢复与交互优化实施记录

2026-11-04，北京时间。对应[规划](./automation-two-runs-and-session-identity-plan-2026-11-04.md)。本轮已实现可在现有公开能力下落地的应用逻辑，并完成类型、构建及定向检查；没有运行完整测试、用户个人任务、系统应用选择器或安装程序，没有生成新的发行包。

## 自动化与光标

- **R01／R02**：文字回读、Enter 派发／清理与页面效果分别记录。编辑框因 Enter 隐藏／移除时保留已确认文字，原生部分失败和 `ok:false` 保持真实；只读核对结果，不重放输入／提交。恢复按页面隔离，最多三次有效观察或重复阻断后收束。
- 通用文字证据要求完整原生快照、同 WebContents／frame／document、原编辑目标隐藏／移除，以及提交前不存在的新可见非编辑匹配文字。框架只更换旧文字的节点 ID 不再被当作新结果；即使页面出现匹配文字，也不声称服务端保存成功。合法新增相同文案同样保守视为未知，需要更明确的业务证据。
- **R03／D01**：最后一轮预留总结，预算或恢复策略停止后在输入清理结束后提供最小事实答复；清理失败明确记录未确认。目标 schema 与宿主共用五字段校验，诊断保留观察时间、可见／聚焦／只读状态、停止原因及有界步骤记录，不新增用户输入正文日志。
- **P02／P03**：主视口逻辑坐标的已确认位置按 WebContents 保存，未知位置不假造左上角起点，部分批次按原生最后派发索引保留确定点。新缺省速度为 0.6，保留已有显式速度；优化时序曲线并保留采样和绘制帧率。
- **公开内核缺口仍在**：`.7` 没有 selector／target-local 动作的最终主视口位置、可靠 frame 变换代次及原子 current-to-target 接口。因此不能宣布所有 selector/ref 跨 frame 光标轨迹已完全连续；不能确认时缓存保持未知。没有调用私有光标状态接口。

具体路径、证据及边界见[自动化专项报告](../../_planning/automation-followup-implementation.md)。

## 界面与资源操作

- **V01**：外观设置支持混合生成、折纸晶体、几何符印、叶芽生长、星体轨道、万花筒；同 ID／样式／版本稳定生成，所有子对话入口同步。预览使用真实种子，形状和配色有连续变化。
- **UX01**：主／子对话共用一个发送控件。运行中没有载荷显示停止，有有效载荷切为加入队列；加入后或清空后恢复停止。入队不停止当前任务，宿主确认后才清除已提交草稿，保留输入法、幂等提交和新编辑内容。队列继续支持折叠与展开。
- **UX02／UX03**：最终交付仅展示文件元数据卡片，显示可见的“打开方式 ▾”；过程／示例文件使用图标文字链接。去掉本地文件图片的自动大图补充，主动打开预览仍保留。新增显式文件用途，旧记录缺省语义兼容；相应工具 schema 与运行提示已接入四类用途。
- 文件卡片、正文文件链接、预览面板及普通文件资源共用原生菜单：预览、系统默认打开、选择其它应用、另存、复制完整／相对路径、完整文本复制、定位。Windows 应用选择调用系统选择器，未伪造已安装应用列表；其它不支持平台禁用。已完成下载使用文件菜单，活动／未落盘下载保留其暂停、取消等专用操作。
- 文件操作校验工作区、来源窗口和资源修订；独立文件窗口可在所属窗口另存。完整复制支持 UTF-8／带 BOM 的 UTF-16，8 MB 以上或二进制不伪称复制完整内容；预览不执行文件／脚本。系统应用选择器尚未进行交互验收。
- **UX05**：浏览器设置提供软件内新窗口（默认）、软件内新标签、系统默认浏览器。聊天／子对话正文、来源、文件预览及编辑器显式打开等入口复用受控 HTTP 链接路由；右键访问、复制、外部访问。新窗口使用公共默认浏览会话并保留来源聊天，创建新页面，不导航或接管原页面。无明确聊天归属时提示先选择聊天，不制造隐藏聊天；远程 Web 界面保留客户端浏览器行为。
- **UX06**：默认节点显示“默认浏览会话”；未命名专用会话分配资料范围内持久保存的显示编号。存储分区序号、ID、Cookie 与页面归属不变。旧明确名称保留，重复名称附稳定短标识；资源侧栏、引用选择与管理文案同步。
- **UX07**：最左侧底部按钮组整体使用 16 DIP 底部留白，保持按钮尺寸和对齐。

## 标签信息面板与标题

- **UX08**：统一标签及内部按钮移除 HTML `title` 属性，完整信息使用无障碍名称及原生信息面板。
- 每个窗口按需复用一个 `NativePanel`；首次悬停延迟 500ms，面板已经显示时跨标签直接更新文字和锚点，离开标签区域约 60ms 后隐藏。标签卸载不销毁已由另一个标签持有的面板，窗口关闭时销毁。
- 固定面板生命周期身份，单独校验标签 owner／身份／代次；迟到显示回执不覆盖新目标。被动提示不抢焦点，关闭后不强行聚焦旧 guest；不会取代正在使用的编辑面板或菜单。
- 移除 DOM 标签提示和对应截图占位触发，网页继续实时显示。修正内联尺寸约束与 flex 分配，有空间时不再只显示“百…”，多标签保持最小可读宽度及滚动。
- `.7` 未提供被动面板透明命中／点击穿透的明确公开契约；没有声称实现穿透。提示仅展示信息，离开标签时收起。

## 菜单与截图替换剩余项

- **UX04 尚需公开原生能力**：需求已统一为“按钮下方、右边缘对齐、窗口内自适应位置／尺寸与滚动”，不使用空间不足时翻转的方案。当前 `.7` Menu.popup 仍只有左上锚点 x/y，appearance.width 是最小宽度，无法可靠完成真实宽度下的右对齐和父窗口限制。缺口已写入[定制接口清单](./electron-native-panels-customization-spec-2026-11.md)，没有猜宽、私有测量或替换为 HTML 菜单并声称完成。
- 标签信息已退出截图占位；地址建议、Agent 控制、下载列表和普通菜单在定制版中优先走原生入口。
- **复杂迁移继续保留**：浮动侧栏、HTML 批注编辑器、附件／来源及部分通用对话框，重叠时仍可能经 BrowserTabPanel 的覆盖检测 → 预览截图 → 隐藏 View。没有将这些残留描述为全部清除，也没有因单项标签修复恢复整套搁置改造。
- 正常截图工具、批注证据、用户主动预览、远程画面流继续保留，属于各自功能。
