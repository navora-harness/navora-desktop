# 应用菜单盘点与实施规划（2026-11-05）

> 2026-11-05 最新实施更新：本文保留静态审计基线；本轮 P1 菜单及退出一致性已实施，P2 产品扩展不纳入，最新验收见[本轮实施与验收](./confirmed-plans-implementation-2026-11-05.md)。下文规划和审计基线保留追溯，不再代表当前源码尚未实施。

状态：已完成源码静态盘点与规划；本次没有修改功能代码，没有运行真实界面、测试或打包。浏览器标签、网页右键、浏览器更多、下载与会话资源的专属盘点由总规划的浏览器部分补充。本文包含应用、聊天、文件、编辑器、插件、技能、设置及选择面板。

盘点方式：同时查找 `contextmenu`、`ActionMenu`、`SidebarContextMenu` / `SidebarMoreMenu`、`native.popupMenu`、`v-menu`、应用命令、`aria-haspopup`、`<details>` 与 `<select>` / `v-select`，再跟踪调用和处理函数。以下 A01–A31 是合并后的菜单族/选择面板台账，**不是“全部菜单共 31 个”的统计**；同一菜单可能有多个页面入口，原生与 DOM 也不是两项独立业务菜单。

明确排除：`RemoteBridgePage.vue` 上的 `@contextmenu.prevent` 仅禁止远程画布的浏览器默认右键，并不构成一个遗漏条目的菜单；需要浏览器输入转发专项处理。`<details>` 中的草稿内容、问卷已提交答案、审批详情只是信息展开，不是业务更多菜单；资料卡的“更多操作”则实际包含动作，已纳入 A16。系统 select 与 Vuetify select 属于值选择面板，纳入能力、状态和键盘检查，但不要求改成应用右键菜单。第三方网页自己提供的菜单与操作项由该网站维护，不以本地应用源码穷举；Navora 注入/注册的网页原生右键仍属浏览器盘点范围。浏览器专属 `BrowserResourceActions` 等由浏览器台账收录。

总入口：[菜单审查与三项后续修复总规划](./已完成/menu-audit-and-followup-plan-2026-11-05.md)。

## 1. 如何判断缺项

- **已有**：不仅能在模板看见，还能追到处理函数；直接按钮、快捷键和选择控件也是有效入口。
- **同类不一致**：同一对象在 A 入口能做、B 入口不能做，且 B 入口业务上确实需要该操作。
- **确证缺口**：源码可证明入口、动作或对应状态处理缺失；不等于已在真实界面复现。
- **产品建议**：增加便利性，需要定义业务规则后再开发，不冒充已有问题。
- 优先级：P0 防止错对象操作、草稿丢失或真实网页被截图替换；P1 补齐高频对象动作与原生/降级一致性；P2 提升可发现性和批量体验。

菜单不统一堆砌“复制、重命名、删除”。对象不同，能力不同：关闭标签不删除文件；删除下载状态不删除文件；取消外链不删除源目录；关闭问卷不取消任务；停止某个下载不等于停止整个 Agent 任务。

## 2. 菜单基础设施与降级

### A01 通用更多菜单

- 入口：`src/components/ActionMenu.vue`。
- 现有：支持原生菜单，运行时不支持则切 DOM `v-menu`；菜单有禁用原因、勾选、分隔、快捷键；DOM 支持方向键、Home/End。原生动作返回时重新比对 items、disabled 和 contextKey，防止旧菜单作用于新对象。
- 规划：保留此单一动作数据源；补充所有业务调用的 contextKey，不把仅 label 一样理解为对象一样。异常回退策略与“未支持”保持一致；不可因错误直接悄悄吞掉用户操作。危险项语义与视觉提示也需原生/DOM 对齐，不能只依赖 DOM 的红色文字。
- 优先级：P1。验收：对象切换、菜单打开期间更新、无原生能力、Esc/Tab 取消、键盘聚焦及高 DPI 边缘位置。

### A02 通用右键 / 侧栏更多

- 入口：`src/components/sidebar/SidebarContextMenu.vue`、`SidebarMoreMenu.vue`、`src/utils/native-menu-source.ts`。
- 现有：右键菜单支持原生与 DOM；从同一 slot 提取原生项目，观察条目变化后关闭；接受 MouseEvent/KeyboardEvent，以控件位置放置键盘菜单；DOM 有方向键、Home/End、Esc、Tab、恢复焦点。侧栏更多增加“隐藏侧栏”。
- 确证边界：外壳支持键盘事件，不代表每个业务对象已绑定键盘入口；必须检查调用方。
- 规划：条目及业务目标一起绑定；原生 slot 签名变化保护不能替代 owner/id/revision 验证。所有 DOM 回退纳入真实 View 叠层替代项目，不能再次触发静态截图替换。
- 优先级：P0（目标绑定与 View），P1（键盘完整性）。验收：下述每个调用方分别检查，不能只测一个公共 fixture。

### A03 链接菜单

- 入口：`src/components/AppLinksHost.vue`、`src/composables/useAppLinks.ts`；聊天来源列表、Markdown 链接等复用。
- 已有：访问链接、复制链接、在外部浏览器访问；`appLinkUrl` 校验与 `app.openLink` 处理，网页端普通点击走新窗口。
- 确证缺口：右键处理直接 `popupMenu`，没有与通用更多相同的 DOM 回退；返回 `supported:false` 时没有明确反馈。全局监听只接鼠标 `contextmenu`，需要补键盘上下文入口；命名应统一为“在外部浏览器中打开”。
- 规划：同一链接动作模型服务鼠标和键盘；只有允许的 HTTP/HTTPS 才提供外部浏览器动作；保留复制等能力所允许的目标；不得把 `javascript:`、内部协议、文件链接直接送外部。没有本地系统能力时禁用并说明原因。
- 优先级：P1。验收：正常链接、失效链接、空 URL、上下文切换、web/remote、取消、不支持与实际异常分别覆盖。

## 3. 顶栏、托盘与全局导航

### A04 文件 / 编辑 / 视图 / 帮助

- 入口：`shared/app-commands.ts`、`src/components/ApplicationMenuBar.vue`；主界面 `ChatPage.vue`、独立文件窗口 `FileHostPage.vue`、独立浏览器窗口分别提供状态与处理器。
- 文件已有：新对话、新浏览器标签、重开浏览器标签、打开对话文件、打开对话目录、导出对话、关闭当前内容、设置、退出；独立文件窗口有系统显示、默认应用打开、移回工作区。
- 编辑已有：撤销、重做、剪切、复制、粘贴、纯文本粘贴、删除、全选、添加/移除链接、附加、当前内容查找、搜索对话。
- 视图已有：侧栏显示/固定、工作区显示/展开、对话摘要、定位编辑器、全屏；独立浏览器有重载、忽略缓存重载、静音、窗口置顶。
- 帮助已有：文档、快捷键、使用引导、关于。无需因为缺少某个传统桌面条目就添加无实现的“检查更新”或开发者工具。
- 原生/回退：已有两个呈现分支、Alt 访问键、方向键；编辑操作有 capture/restore target。必须按主窗口/文件窗口/浏览器窗口的模式分别验收，而非给全部模式展示所有命令。
- 规划：文件相关命令与统一文件动作共享能力和 revision 校验；当前只读预览的 Edit 不能误写聊天编辑器；查找应说明搜索的是聊天、文件还是网页。菜单取消不执行；关闭问卷必须先保存草稿。浏览器外部打开命令由浏览器专项统一接入。
- 优先级：P1；未发现“整个 File/Edit/View/Help 都缺失”的问题。

### A05 系统托盘

- 入口：`electron/modules/tray.ts`、`electron/main.ts`。
- 已有：根据窗口状态切换“显示 Navora / 隐藏到托盘”，退出；点击/双击显示和恢复最小化。并非缺少“显示”动作。
- 需核实的一致性：主界面退出有确认，托盘退出直接调用主进程退出链。规划统一退出意图、运行中任务说明和草稿 flush，明确强制退出的最终选择；不得给用户两个含义不同却同名的退出。
- 优先级：P1；源码链路差异已确认，是否有数据损失仍需隔离场景验收。
- 产品建议：托盘保留简短，不默认加模型、主题、全部对话等二级菜单。全局暂停任务不是同义的“隐藏”，若增加需另定业务协议。

### A06 侧栏导航轨右键 / 侧栏更多

- 入口：`ChatPage.vue` 的 `railContextMenu`；各侧栏标题的 `SidebarMoreMenu`。
- 已有：显示侧栏、固定侧栏；浏览器显示时固定状态/禁用原因；设置、创建器、移动布局等状态禁用；导航轨已绑定 ContextMenu / Shift+F10。
- 规划：所有入口反映同一侧栏状态；不能在某个更多菜单绕过“网页可见则退出悬浮”的约束。显示/隐藏与固定/悬浮应是两种清楚的状态。
- 优先级：P1。验收：浏览器开始显示、最后一个网页隐藏、侧栏切面板、小窗口、移动布局及设置/创建器切换。

## 4. 对话、消息、子对话与问卷

### A07 对话列表：行内更多与右键

- 入口：`ChatPage.vue` 的 `showNativeChatRowMenu`、行内 `v-menu`、`onChatItemContext`、`pageCtxMenu`。
- 已有：修改标题、置顶/取消置顶、导出、删除；原生行内菜单返还时检查 chatId、消息是否存在、置顶和导出状态。删除走确认，不能另加跳过确认的菜单。
- 同类不一致：当前对话顶栏更多还有“查找、打开对话文件夹、停止任务”，列表右键没有；这是高频便利补齐建议，而非这些业务能力完全不存在。
- 规划：列表补“在此对话中查找”“打开对话文件夹”；只在该对象运行中显示“停止此对话任务”。动作始终作用于右键对象，即使对象不是当前对话；停止不能误停当前前台对话。导出禁用原因与空对话状态一致。子对话不加入主对话置顶，避免制造平级入口。
- 键盘缺口：列表未发现为行对象绑定 ContextMenu / Shift+F10，虽更多按钮可键盘点击，仍应补统一上下文入口。
- 优先级：P1。验收：非当前行、运行/空内容、批量选择模式、重命名输入中右键、切聊天后旧菜单不执行、删除确认取消。

### A08 当前对话更多 / 页面级更多

- 入口：`src/components/ChatResourcesMenu.vue`。
- 已有：打开浏览器标签、打开对话目录、标题、查找、置顶、导出、运行时停止、删除；原生 `ActionMenu` / DOM `v-menu` 两套展示。文件管理、插件、设置、创建器等 pageActions 根据当前页面提供创建插件、模型配置、打开插件管理、技能创建器、新浏览器及返回对话。
- 规划：保留对象相关动作；文件管理页面更多可接“刷新当前目录 / 打开当前目录 / 返回对话”，复用 FileManager 已暴露的 refresh/openFolder，属于入口一致性；不在所有页面强塞新对话/删除。
- 验收：页面切换立即关闭旧菜单；远程禁用本地目录；已有页面时快速打开浏览器不重复创建。原生与 DOM 的 busy/checked/reason 一致，原生 folder busy 与 DOM 目前状态保护不同需统一。
- 优先级：P1。

### A09 聊天内容右键与回答工具栏

- 入口：`ChatPage.vue` 的 `onMessagesContext`、`resolveMsgContext`、`pageCtxMenu`、`copyReply`；`ConversationActivityRow.vue`、`ChatMarkdown.vue`。
- 已有：复制选区、引用选区、复制本条、引用本条、复制全部对话、导出；回答已有复制/重试等直接入口，文件链接和输出文件交给专用菜单。
- 规划：菜单清楚区分“复制选中内容 / 复制本条 / 复制此轮回答”；当前 resolve run block 会聚合多条工具记录，不宜继续用容易误解的“本条”。复制格式是否用原文 Markdown/显示文本应明确，并共享回答工具栏规则。增加可定位的键盘上下文入口，优先引用真正的选区，而不是旧窗口选区。
- 不默认加删除单条消息、编辑任意工具历史、重新执行任意工具：这些会改写已发生的事实与任务关系，需要新业务协议，不属于菜单补漏。
- 优先级：P1（作用对象、键盘与命名），P2（复制 Markdown 选项）。验收：用户消息、回答、折叠日志、代码块、文件、空白区域、子对话引用及只读历史。

### A10 子对话列表、详情与工作区标签

- 入口：`SubchatList.vue`、`SubchatDetail.vue`、`SubchatWorkspace.vue`、`FileWorkspace.vue`。
- 已有：列表状态筛选和清除筛选；详情搜索、刷新、停止或重试；模型、回答方式、权限直接选择；标签右键返回子对话列表、定位父对话、关闭。主列表出现的子对话已有标题/导出/删除右键。
- 同类不一致：子对话工作区列表没有对象右键，但相近对象在主列表能重命名/导出。规划补“打开、定位父对话、导出、运行中停止”；重命名/删除是否保留由父子关系与已有 API 能力一致决定，不能删除父对话后遗留孤立子任务。
- 约束：列表选中不修改执行状态；停止只作用于明确 childId；详情草稿与问卷先保存，父对话定位保留当前视图；不加入分离窗口（当前设计限制）。
- 优先级：P1/P2。验收：父对话已删、子任务运行、只读终态、未读与待问卷、列表过滤后对象消失。

### A11 问卷标签、问卷卡、填写界面

- 入口：`FileWorkspace.vue`、`QuestionnairePanel.vue`、`QuestionnaireChatCard.vue`、`useQuestionnaireDraft.ts`。
- 已有：动态“问卷: 标题”；标签关闭；卡片打开填写/查看；表内返回聊天、逐题重置、说明、未知/委托/跳过、取消和提交，草稿冲突处理及重试。关闭标签会 flush；问卷保持全局一个，不能拖出独立窗口。
- 规划：标签可补“返回所属对话”；必须清楚“关闭标签”只隐藏表单且保留草稿，“取消问卷”是结束等待任务，需要走现有确认和持久化流程。无需为了菜单齐全而再造重复提交或删除已提交答卷。
- 优先级：P1（关闭与所属对象），P2（便捷入口）。验收：不同聊天的问卷切换、草稿保存失败、冲突、取消确认、已提交只读、旧记录恢复。

## 5. 编辑器、附加、资料卡、链接与选择面板

### A12 普通输入框与普通选区右键

- 入口：`TextContextMenuHost.vue`、`src/utils/editable-context.ts`。
- 已有：选区剪切/复制/删除、粘贴、全选；只读禁写，密码禁止复制/剪切；已保存原输入目标与内容快照，操作前还原选区；普通文本选区复制。结构编辑器和 owned region 交给专用菜单。
- 确证缺口：全局只监听鼠标 `contextmenu` 且要求 `e.button===2`，没有键盘菜单键/Shift+F10 入口。
- 规划：加入键盘路径，以焦点输入框与保存的选区作为目标；原生和 DOM 都显示真实可用能力。撤销/重做与纯文本粘贴是与顶栏/结构编辑器对齐的建议，按真实编辑历史支持程度接入，不能声称任意 input 已有可靠跨修改撤销。
- 优先级：P1。验收：密码、禁用、只读、textarea、重命名输入、问卷、设置输入、异步粘贴中内容变化/节点移除、IME。

### A13 结构化消息编辑器右键

- 入口：`ComposerEditor.vue` 的 contextActions/getCommandState/menuCommand。
- 已有：剪切、复制、粘贴、纯文本粘贴、删除选区、全选；添加/编辑链接、移除链接、复制链接地址、附加；已经支持 ContextMenu / Shift+F10。撤销/重做在命令与顶栏已存在，但未列在该右键菜单。
- 规划：把可用撤销/重做加入此右键作为入口一致性；链接只对可编辑的普通文本/单个有效链接显示对应动作；不能把上下文来源块当普通文本破坏。快捷键展示按平台，不继续把所有系统写成 Ctrl。
- 优先级：P1/P2。验收：选区跨资料块、光标位于链接、正文为空、只读、发送中、草稿 revision 变化、快捷键与菜单各触发一次撤销。

### A14 选中文字格式工具栏 / 段落格式

- 入口：`ComposerSelectionToolbar.vue`。
- 已有：链接、粗体、斜体；正文、标题 1/2/3、编号列表、项目符号；可编辑摘录中保留原格式，禁止不适用的块转换。
- 规划：保留轻量面板，不无差别加所有富文本格式；格式项状态与右键一致。纳入消除截图替换的叠层范围，保留原光标与撤销单元。
- 优先级：P0（叠层），P2（键盘细节）。验收：选区上/下方空间、小窗口、滚动、选区改变、IME 与快捷键。

### A15 附加菜单与来源选择

- 入口：`ComposerAttachmentMenu.vue`、`ComposerSourcePicker.vue`、`WorkspaceFilePicker.vue`、`ComposerResources.vue`。

## 8. 建议实施顺序与交付条件

1. **先做底座和业务动作模型**：按聊天、文件、链接、插件、技能、问卷区分 objectRef；动作统一声明可见/禁用及原因、目标、能力、确认、取消语义。复用现有 useWorkspaceFileActions / appCommands / ActionMenu；不为简单 UI 再造一套执行总线。与浏览器能力模型保持同源。
2. **先补确证缺口**：FileManager 普通文件右键、独立文件标签右键、主工作区文件标签动作、键盘上下文入口、链接菜单 unsupported 降级与反馈。实体文件树已完整，避免重复开发。
3. **对齐常用入口**：聊天列表的查找/文件夹/停止，问卷返回所属对话，文件页面更多。先定对象再调已有业务处理器，不把“当前 active”当默认目标。
4. **与真实 View 替代迁移协同**：所有 ActionMenu/SidebarContextMenu 回退和附加/资料卡/模型/权限浮层纳入原生覆盖层计划；原生不可用时给可用降级，不许用旧截图假装真实网页。设置中的 select 按原生系统控件或页面容器能力处理，避免在平台无支持时展示空壳。
5. **保护和体验收口**：主/托盘退出、文件删除、技能/插件卸载、草稿 flush、危险重置、平台能力和主题；最后做文件集批量与创建器草稿管理等产品扩展。

首轮验收按业务对象选择有意义场景，不为所有菜单机械复制同一套测试。必须覆盖：鼠标/键盘、原生/降级、主/独立窗口、非当前目标、远程/本地、忙/只读、文件或页面换版本、运行中、取消确认、保存失败、窄窗/高 DPI/暗色主题/真实动态网页。每项记录“静态确认 / 自动验证 / 人工动态验收”三个不同状态；静态盘点不冒充真实界面已通过。

首轮完成标准：普通用户从对象右键或其更多入口能找到该对象常用动作；不误操作另一个聊天/文件/版本；不存在点了无响应的不支持状态；不会丢草稿；真实网页持续显示且可动。产品建议单独排期，不以菜单数量作为完成度。
