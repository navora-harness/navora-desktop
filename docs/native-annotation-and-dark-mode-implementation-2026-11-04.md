# 原生批注、暗色与菜单位置实施

日期：2026-11-04 至 11-05。当前源码仍为 0.4.3 开发树，运行时为重新发布的 `45.0.0-cloudbypass.7`。本轮没有生成安装包或覆盖个人安装资料。

## 批注

- 正常导航和地址栏保留，在同一工具行提供独立“批注”开关、已保存数量和临时网页操作按钮。开启即可点击目标或拖选，Space 临时浏览沿既有隔离选择层处理；不会执行所选网页按钮或链接。
- 删除旧底部批注栏、拖动调高区域及 HTML 评论输入框。评论统一由 `BrowserAnnotationEditor` 的 NativePanel textarea 承载；列表由 `BrowserAnnotationsPanel` 的 NativePanel 承载。
- 输入为圆角长方形、约 2–8 行，确认／收起位于输入框下方。应用以 Segoe UI 实测字宽、单词及字素软折行、实际可用区域协调高度，超过上限由原生编辑区内部滚动；更新省略 value，保留原控件输入与选区。这是应用协调尺寸，不声称内核新增 autoGrow 或原生内容测量接口。
- Enter 确认、Shift+Enter 换行；submit 使用原生事件全文，下方确认使用有序 change 所维护的正文，两者走同一保存链路。保存成功继续待选，数量等待正式记录确认。
- 正式意见仍限 4000 UTF-16 码元。关闭原生硬截断以保留 emoji；超出正式上限的草稿可完整保留至桥接上限 65536，不能确认提交。超过桥接上限只传递安全的超限状态，锁住旧值保存，不静默保存旧正文。草稿文件保留有限大小，旧记录和截图证据兼容。
- 列表保留搜索、页面／对话范围、状态与排序、目标草稿和冲突副本恢复。详情提供编辑、定位、证据、加入对话、解决／重开、比较及明确确认删除；加入对话只插入引用，不自动发送。
- 关闭先等待草稿，失败由 keep 回执恢复同一编辑器；按编辑身份和最新本机缓存序号判断保留状态。关闭／提交重置选择时携带 expectedTargetId，旧面板的迟到回调不会清除下一个目标。滚动或尺寸变化后标记原锚点待核对。
- 删除 `annotationTargetImage` 背景铺图和批注浮层覆盖标记。编辑与列表开关不调用背景 preview、不隐藏实时 View、不改变网页 viewport。取证截图仍用于批注证据保存；其它兼容 HTML 弹窗的通用截图路径没有在本轮冒充整体清除。

## 暗色与窗口材质

取消“应用与系统深浅色不同就降级实色”的判断，保留真实系统 Acrylic，以当前应用主题的半透明覆盖色保证标题栏／图标栏／侧栏可读。系统主题和应用主题分别传递，不改变全局 nativeTheme，网页 prefers-color-scheme 不受应用强制配色影响。

设置、侧栏、对话标题／正文／表格／用户气泡、过程详情、传送菜单和浏览器工具行的漏白与低对比颜色改用共享主题色。关闭开关、平台不支持、强制颜色／减少透明等情形继续完整实色回退。

三类宿主相反色调的真实截图有效；旧的“第一次前景合成可能灰色”问题仍保留未验证边界，不从本次强制暗色修复推断其所有生命周期已解决。NativePanel Acrylic 继续关闭。

## 菜单与侧栏

更多菜单保持原生 Menu，默认在触发按钮下方右对齐。应用按内容区 DIP、菜单行／字体／图标／控制项／padding 估计占位，按可用空间平移约束位置；不是方向翻转。网页右键共用约束；常见子菜单有空间时预留展开区域。极长标题或小于整个菜单的窗口仍由原生屏幕边界及滚动兜底，公共 API 没有实际菜单尺寸查询。

展开工作区时禁用悬浮侧栏及切换悬浮的入口，已打开侧栏固定停靠；原有 mode 与持久偏好不改写。恢复分栏后恢复原偏好，避免浮动侧栏盖住实时网页。
