# 输入浮层与主窗口滚动条（2026-11-05）

状态：源码已实现，类型检查、前端构建和隔离应用定向检查通过。本轮未打包，不改变已发布 0.4.3 的交付记录。

## 现在的行为

- 主窗口 HTML 滚动区域共用主题滚动条：8px 透明轨道，滑块默认使用 24% 不透明度（76% 透明度），保持淡淡可见，悬停或键盘焦点进入时加深，取消两端箭头按钮。浅色和暗色使用同一规则，强制高对比度模式保留可见滑块；已有隐藏滚动条的标签带以及会话右侧刻度导航保持各自布局。
- 附加浮层以实际编辑框为锚点，左边对齐并显示在编辑框上方。一级与二级固定为 310px 窄面板和单列列表，编辑框或窗口更窄时随可用宽度缩小；窗口高度不足时限制高度并在内容区滚动，所有来源均可通过滚动和搜索访问。
- 一级选中文件、网页、会话、历史消息、技能／插件说明或批注后，二级在同一浮层内只显示对应来源的搜索和列表。二级搜索复用一级样式，不再重复分类导航及预览表单；打开和搜索后默认高亮第一条，方向键切换时保留搜索框焦点，点击或 Enter 确认插入，Esc 返回一级。没有匹配项时清除选择并禁止插入，中文输入法确认不会误插入。
- 文字与代码、网址保留必要的手动输入。导入本地文件仍使用系统文件选择器。主对话、子对话和队列编辑复用该浮层；原有选区书签、对话／草稿身份检查及取消恢复保留。独立来源编辑器仍保留摘录／引用、行范围和预览控件，嵌入列表默认插入引用，历史消息和技能／插件说明插入摘录。默认选中引用时不自动读取网页正文或生成截图。
- 主输入框下方回答方式、权限、模型／思考等级和上下文用量卡片使用 HTML。模型仍按真实服务能力加载，选择继续通过原有对话服务保存。生产入口不再挂载 ComposerNativePanels；旧组件保留供历史独立夹具使用。
- 选中文字的链接、加粗、斜体和段落格式工具栏直接使用 HTML，不再申请原生格式面板。工具栏、展开菜单和链接编辑器按实际聊天列宽度与工作区高度定位；主聊天的 `conversation-content` 为 `display:contents`，因此横向测量实际 `.composer`，纵向测量工作区，子聊天测量自身面板，避免向相邻 WebContentsView 展开。
- 所有附加来源共用原有小标签外观，引用和摘录默认均不展开。点击标签，在该标签旁浮出 HTML 描述卡片；点击外部、另一个标签或按 Esc 收起。卡片不会撑大输入框，含来源信息、范围、图片预览和描述／摘录内容，保留重命名、来源操作及摘录编辑。浮卡在 HTML 顶层显示，仍保留编辑器内容节点的 DOM 归属，避免输入区的背景模糊和滚动容器裁剪卡片；格式工具栏和链接编辑器也可在浮卡上方操作。
- 引用标签只在用户展开时读取描述，不修改引用或自动导航；摘录和链接补充说明保留在原文档节点内，收起只改变显示状态。持久化、发送编译和复制仍使用既有文档结构，浮卡界面不写入发送内容。

此次 HTML 范围是用户确认的输入区浮层。网页上的批注输入／列表、浏览器菜单等原生面板沿用各自实现；确实覆盖 WebContentsView 的其他旧浮层兼容逻辑不在本次变更范围内。
