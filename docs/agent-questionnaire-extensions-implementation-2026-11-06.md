# 问卷扩展与 Electron .10（2026-11-06）

应用版本 0.4.14。条件分支、附件、日期与日期范围、提交后修改和模板复用均已实现。界面使用现有主题、单列填写和唯一问卷标签；本轮使用 frontend-design 技能审阅布局，沿用项目的 Vue/Electron 验证工具。

## 五项扩展

- 条件分支：`showWhen: {questionId, equals}` 只引用前面的题目；单选、开关、数字、文本和日期比较实际值，多选判断是否包含选项。前题必须可见且已作答。拒绝向后引用、循环和无效条件。进度按当前可见题目计算；隐藏答案仍在独立草稿中，但不进入必填检查、提交快照或 Agent 摘要。
- 附件：`attachment` 题支持文件和图片，可指定扩展名、数量和单文件大小。默认最多 5 个，允许配置到 10 个；单文件上限 10 MiB，每份问卷累计保存上限 50 MiB。上传内容保存为管理目录内的独立副本，记录 SHA-256。宿主核对归属和内容，拒绝伪造路径、超限文件和已变化的副本；删除聊天时清理关联副本。移除答案附件不会删除原提交所引用的文件。
- 日期与范围：`date` 使用日历输入；`dateRange` 分别保存开始和结束日期。验证真实日历日期、上下界和先后关系。输入未完成或范围暂时反向时仍可保存草稿，提交时定位错误。
- 提交后修改：任务处理完成后从“修改答案”创建新的待答问卷，保留来源、原快照和独立草稿。页面展示修改前后的答案及补充说明；再次提交作为新的持久输入继续任务，不改写原工具回执，也不自动撤销已执行操作。重复打开复用同一份修改草稿；旧版本不能形成重复修改分支。
- 模板：提供需求澄清、项目初始化、执行参数三份内置模板。用户可命名保存、删除及导出模板；当前问卷结束后可直接使用模板。Agent 可以跨任务发现并使用用户模板。模板只保存题目，不保存答案、补充说明、附件或任务约束；删除原聊天不删除用户模板。

题目协议和工具定义同步扩展。`agent_form_templates` 列出内置与用户模板；`agent_ask_form` 支持 `templateId` 或完整题目定义。`agent_form_attachment` 只读取当前聊天已提交且适用的附件：文本支持分页；图片在支持图像的模型请求中临时附加，不把 base64 写入历史。其他二进制文件返回元数据与管理副本路径，不宣称已解码内容。仅上传、隐藏或已移除的附件均不能通过该工具读取。

桌面 IPC 和远程桥同步接入；远程可上传文件，在宿主本地打开附件的动作仅限桌面应用。提交前将响应式答案转换为独立普通对象，修复真实 IPC 暴露的克隆失败。
