## 2 .7 新增能力与使用决策

### 2.1 原生多行输入

真实节点为 `type:'textarea'`，沿用 `value`、`placeholder`、`maxLength`、`width`、`height` 和公共 style；不是 `input.multiline`。`submitOnEnter` 默认 true：非输入法组合态下无修饰 Enter 发出带当前全文的 submit，Shift+Enter 换行；false 时 Enter 也换行，不自动提供 Ctrl+Enter 提交。

批注目标为圆角长方形 NativePanel、上方无边框 textarea、下方固定操作行，Enter 确认／Shift+Enter 换行，保留草稿和历史多行全文。现有 column／row 可制作正常空间下的下方动作区样板，但没有固定页脚或最小编辑高度的公开约束，低高度屏幕上的固定可见效果仍需尺寸契约和实测。详见[多行批注面板](./已完成/native-annotation-multiline-panel-plan-2026-11-04.md)。资料编辑按各自提交规则处理，不把批注快捷键强加给全部编辑器。

**尚未补齐：随内容自动增高。** `.7` 仅支持固定高度、自动折行与内部滚动，没有自动增高参数、原生排版高度事件或公开测量方法。保留初始约两行、最多约八行后内部滚动的目标；需要后续原生排版／尺寸契约，不能用字符数估算、隐藏 HTML 编辑器、频繁重建控件或改成固定高度来宣称完成。可先验证原生编辑基础，但完整批注验收仍受此缺口约束。

按钮 click 不带编辑全文，主进程需维护当前编辑请求的 change 草稿；Enter submit 使用该动作携带的全文。保存按钮与 IME 提交／change 的顺序和原子性必须单独验证；如果无法证明最新文字已同步，需要明确的原生提交契约，不能用延时或先失焦补救丢字。同 ID／type 刷新保留控件，不相关更新省略 value，避免旧状态覆盖组合输入。

**另有已知限长风险**：`.7` 当前实现直接截 UTF-16，可能截断跨 4000 边界的 emoji 代理对；组合态又可能先发出超限 change，而现有草稿库会拒绝。接入须先确定 Unicode 安全限制或完整的有界溢出草稿策略，正式提交仍遵守 4000；不能把原生 maxLength 等于后端上限当成无损保证。详见多行专题第 6 节。

### 2.2 NativePanel 自身的 Acrylic（已发布，当前搁置）

构造及 update 公开支持 Windows `backgroundMaterial:'none'|'acrylic'`，默认 none，更新省略保留原请求。它是面板自己的系统材质请求，不继承父窗口、不更改 Menu，也不是任意透明度；`theme.background` 提供实色后备，不透明子控件会挡住底材。

当前不启用该面板能力：面板使用默认／显式 `none` 和不透明 `theme.background`，根与子控件不套用宿主的透明配色，也不随宿主开关更新为 acrylic。仅更新普通主题不能误发 acrylic 请求；隐藏复用的实例也遵守此策略。不为这项搁置能力安排产品设置、原生接口扩展或发行验收，未来恢复时再按契约接入。

主窗口／独立窗口的 BrowserWindow 材质路线仍按[窗口 Acrylic 规划](./window-acrylic-material-plan-2026-11-04.md)保留：不支持、系统限制、用户关闭或失败时，宿主原生材质与额外透明配色一起撤销。面板的普通实色外观不受宿主透明状态影响；不使用私有 `_getState` 当作公开能力。

### 2.3 原生滚动条与独立滚动槽

面板构造／update、`list` 和 `textarea` 节点各自支持 `scrollbarPlacement:'gutter'|'overlay'`，默认 gutter。**外层选项不向内层列表／编辑器继承**；需要分别指定。gutter 在溢出时为内容之外的滚动轨道保留 12 DIP，overlay 覆盖内容；两者都在分配给面板或节点的边界内，不会把滚动条移到浮窗外。

应用列表与批注优先 gutter，让滚动条避开行背景、右侧动作和正文。原生灰色圆角滑块通常 4 DIP、悬停／按下 6 DIP、无箭头，随浅深主题变化；几何由内核固定，不能传 CSS 改造。内容完全适配时滚动条消失，gutter 不等同于始终占位的 CSS `scrollbar-gutter:stable`，出现／消失时需核对折行与布局稳定。

落实[侧栏滚动槽规划](./已完成/sidebar-scrollbar-layout-plan-2026-11.md)：HTML 停靠列表继续原有 CSS 布局路线；原生列表采用新字段，避免面板外层、list 和 textarea 同时出现不必要的多重竖向滚动。固定底部按钮放在编辑器滚动容器外；不为此扩大网页边界或重启页面。

### 2.4 .6 已有能力继续使用

原生 `item`、iconButton、selected、单行省略、高亮、显式按钮变体、style 和 contentInset 继续承载地址建议、标签搜索及批注列表。地址输入保留焦点与组合输入保护，整行选择和内部按钮动作分离；查询代次／候选 ID／来源页共同校验。

普通菜单继续统一 Menu；横排缩放使用已有 `MenuItem.controls`、根 Menu 的 `control-action(detail)` 和 `menu.refresh()`。`.7` 公开类型未为这些接口增加新的布局或材质能力，不虚构 controlRow。本轮桥接已接入当前菜单请求内的连续动作与原位刷新，实际检查见实施进展；菜单百分比读取真实网页缩放，按目标页串行，25%–300% 边界不改变应用缩放。详情沿[浮层补全规划](./native-panels-followup-plan-2026-11-04.md)。

## 3 仍需定制补充的内容

- **批注自动增高及提交完整性**：原生排版驱动的首选高度／行数约束、可保留光标与 IME 的尺寸更新，以及保存按钮取得最新全文的明确顺序或原子契约；另须解决已知 UTF-16 限长／组合超限草稿风险。字段名以将来实际发布为准，能用完整应用策略保证的部分按真实验证登记，不要求一律新增内核 API。
- **被动提示**：`focusMode:'none'` 不代表卡片全域鼠标穿透。仍缺被动命中模式与最大行数／多行省略契约，不能重放用户点击、屏蔽主窗口输入或解除 Agent 保护来模拟。
- **持久悬浮侧栏**：仍缺所需的树交互、行右键、拖放引用、调整宽度及父子 popup 协作。固定 HTML 与悬浮 NativePanel 共享业务状态而非控件实例，跨承载的阅读锚点／焦点恢复缺公开契约；同 ID 更新保留或选中行滚入视口不能代替任意偏移恢复。item 组合或滚动槽不等于这些交互已经存在；应用自己的业务状态和搜索／分页仍需先完成，不能用缩水平铺列表替代资源管理。
- **其他复杂界面**：受限图片预览、按键录制、完整富内容编辑等尚未成为公开节点；icon 不冒充大图预览，textarea 不等于富文本编辑器。
- **关闭传播与焦点**：外部点击观察不等于消费点击，原生圆角／阴影穿透不等于卡片全域穿透，暂无公开父子 panel／Menu 归属契约。须明确关闭、点击是否到达底层、IME 候选及焦点恢复的行为，不把 JavaScript 角色管理当成全部原生保证。

以上属于仍未满足的目标或待证明的接入条件，不是请求本轮修改内核。继续保留完整截图退出的发行门槛；`.7` 发布不自动解除这些条件。

## 4 原生桥接和生命周期

1. 实施先对齐 package／lock、下载校验与实际制品，再扩展 `shared/native-ui.ts`、主进程白名单／转换、动作路由和应用能力登记。规划阶段的 `.5` 硬编码已在本轮升级中处理，不能只改展示版本；保留历史发行记录中的 `.5` 标识。
2. 当前扩展 textarea、submitOnEnter 及合法位置上的 scrollbarPlacement；面板 backgroundMaterial 的 acrylic 接入搁置，不因字段已发布便默认透传启用。按公开 schema 拒绝跨节点字段；几何统一从应用坐标换成 DIP，枚举、UTF-16 长度／高亮不做几何缩放。
3. 以窗口／面板角色、来源页面、宿主代次、请求和编辑修订管理动作，不再无差别 `dismissOthers()`。每窗口提示按需复用；来源页导航、销毁、移窗导致失效时重新创建，不能更换旧面板 parent。
4. 运行时更新时保持原生控件身份和输入；主进程保存有序草稿，界面迟到回执不可覆盖新文本。原生 schema 校验原子性不等于保存按钮读文本的事务原子性。
5. 普通菜单／NativePanel 不新增 WebContents；显式证书窗口和 DevTools 属于独立用途，分别核对资源和权限。`showPageInfoDialog` 应用调用与业务语义保持，内核自带外观变动单列兼容验证，不以 HTML 仿造旧界面。

## 5 业务路线与交付顺序

本次打包的既定硬门槛是：独立窗口白屏恢复、两种宿主标签配色一致、全部弹层背景截图替换退出，以及这些改动必需的功能保真与应用回归。多行批注、被动提示和悬浮侧栏等现存覆盖入口不能以缺功能、隐藏入口或截图降级来冒充清理完成。

公共默认会话、消息声明、网页右键菜单及宿主 Acrylic 继续保留后续规划，以下给出依赖顺序，但用户尚未将它们全部指定为这一安装包的额外前置；不能由“所有规划”自动扩大此次发行门槛。以后选择同批实施的功能须完成自己的验收与迁移，不把未实施的规划写成发行能力。显式搁置的面板 Acrylic 不计入当前待完成项，不阻塞截图清理或发包。

1. **基线与能力接入**：核对制品、类型和实际运行时，完善桥接、分项登记、面板协调、独立窗口呈现和主题回归。`.5` 未发行白屏／配色及五个入口修复保留，不重复宣称已发行。
2. **明确可做的列表和菜单**：地址建议整行、标签列表、普通菜单外观、横排缩放、简单搜索／编辑／确认及原生滚动条布局；主窗口与独立窗口一起验证，逐入口退出背景截图链。
3. **多行批注与宿主窗口材质**：接入已发布的 textarea 和滚动槽，用 column／row 制作下方动作区样板；自动增高及低高度约束下固定可见的 footer 继续按尺寸契约补齐和验证，不作为用户同意固定高度替代。宿主材质作为并行规划处理支持／实色策略和主题层遮挡；NativePanel Acrylic 搁置，批注等面板保持实色。
4. **公共会话与消息声明**：按各自迁移与权限前置实施，不等待内核之外的新字段。落实[公共默认会话](./已完成/browser-public-default-session-plan-2026-11-04.md)的存储共享／页面归属／网络观察隔离，再简化浏览器资源；独立窗口最左为移回工作区、置顶窗口、标签页。落实[任务声明](./已完成/composer-task-declarations-plan-2026-11-04.md)的草稿、提交身份、队列、恢复与执行阶段，再上线“自动化／计划”选择；附加菜单保留 HTML。

## 6 验收与不变边界

- 真实视频／动画持续推进，原 WebContents、表单、滚动及 Agent 租约保留；普通菜单与面板展示背景截图调用为零，业务截图单独计数。
- 批注物理中文输入法、Enter／Shift+Enter、粘贴多行、4000 UTF-16 限制、按钮提交、草稿恢复与修订引用正确；覆盖 3999 码元加代理对 emoji、组合文本临时超限及随后保存／收起／重启，全文无损。尺寸增减保持 caret／选区／撤销／IME 和屏幕边缘定位，固定 footer 不被挤出。
- gutter／overlay 分别验证面板外层、list、textarea，内容溢出临界点、滚动与拖动、浅深主题和 100%–200% DPI；滚动轨道不挡住列表按钮、文本和焦点框，不能由 schema 接受替代视觉验收。
