# 项目复核与下一阶段实施

日期：2026-10-31。范围为 navora-desktop 的主进程、渲染界面、共享契约、测试和现有规划；关联插件能力以宿主接口和本地回归为边界。以下区分本轮实施与长期方向，未把静态检查当成三端或真实站点验收。

## 整体判断

主进程继续作为会话、配置、Agent、浏览器和文件的状态源，preload 与远程接口保持同构。插件加载、Host API、权限计划、取消、技能和创建器已有独立契约，不需要为 UI 更新重写。定制 Electron 与现有模型配置保留。

对话已具备流式输出、队列与插入、过程折叠、来源和资源侧栏。当前缺口主要在跨功能的一致性：文件在根目录和深层目录的展示不一致，产物与相关回复没有稳定关联，导出仍将中间说明当成独立回答。新文件索引与相对链接修复已先行实现。

启动路径同时加载设置、创建器、帮助和远程页面；入口还注册了整个 Vuetify 组件集，尽管构建已启用模板自动导入。本机本轮优化前主脚本为 1,345,717 字节、入口样式为 1,184,860 字节。这是构建体积基线，不代表启动时间或模型响应速度。

浏览器已有原生能力探测、结构化观察、页面检索和失效引用处理；Agent 已有快速问答、天气直达、取消与重试边界。继续优化这些模块需要基于固定任务与真实站点证据，不能通过增加等待或泛化绕过规则宣称无阻碍访问。

ChatPage、SettingsPage、AgentRuntime 和 browser-tools 仍较大；本轮只拆分加载边界和共享语义，不同时重写运行时、权限和插件协议。样式收敛与模块拆分列入长期维护，避免大范围改动掩盖交互回归。

## 本轮实施清单

1. 文件基础体验：有上限的深层元数据索引、稳定 owner/path 身份与修改版本、请求合并及并发限制、局部失败/截断提示、文件名与路径搜索。嵌套 Markdown 正确解析相对链接；已有文件变更不反复打开手动关闭的卡片，后台刷新保留可见内容；停止状态不因关闭日志显示而消失。
2. 产物关联与 UI：仅从成功的内置写入、复制、移动、合并、下载和截图结果建立相关操作记录，关联提问与最终回复。未知来源明确保留为工作区文件，不凭扩展名猜测为生成产物。加入全部/产物/类型筛选和定位入口，定位到折叠过程时先展开。保留文件树和原生管理入口。
3. 导出一致性：Markdown 使用同一消息分类和过程分组，最终答复独立，工具与日志不丢失；JSON 继续保留原始消息和元数据。
4. 加载与恢复：利用现有模板自动导入按需打包组件，设置、创建器、帮助及远程页面延后加载。异步面板有加载状态、失败重试和返回入口；不因失败自动刷新整个对话。验证设置草稿、插件创建器与现有菜单动效。

验收以源码测试、普通/减少动效 UI 回归、浏览器宿主本地回归、构建体积对比及实际重启为准。真实模型调用、真实站点访问和 macOS/Linux 未执行时单独记录，不混入通过项。

## 长期方向

后续按资源版本与产物记录、浏览器工作区接管、可控文件编辑、运行耗时与恢复度量、插件渲染扩展的依赖顺序推进。统一 runId、附件/下载完整来源链、可重建的持久索引、内容摘要检索、语义检索和文档版本缓存仍需独立设计与验收；本轮的元数据 revision 不是内容哈希，提问 turnId 也不冒充运行 runId。

主要依据：electron/main.ts、electron/preload.ts、electron/modules/agent-runtime.ts、browser-tools.ts、browser-registry.ts、workspace-files.ts、workspace-resource-index.ts、plugin-store.ts、src/main.ts、src/router.ts、src/pages/ChatPage.vue、SettingsPage.vue、src/components/CreatorWorkspace.vue、shared/message-presentation.ts、export-chat.ts 及 scripts 下的现有回归入口。


## 交付与验证

本轮四项清单均已落地。完整构建和 90 项源码测试通过；业务界面、基础界面、插件/技能创建器在普通和减少动效模式下通过回归，覆盖生成文件后的最终回复关联、产物筛选与定位、嵌套链接、标签与焦点恢复、设置草稿、流式回复、队列和创建器安装/试用。Markdown 导出的过程分组、来源与大结果代码围栏另有回归。

浏览器宿主本地回归通过，覆盖原生可信输入、闭合 Shadow 查询、跨域 frame 定位/点击、文件上传、原生对话框、文档响应、失效 ref、取消、插件执行/权限、页面与登录态保留及显式释放。该结果来自隔离的本地页面，不代表任意外网站点均可访问。

最终入口主脚本 869,303 字节，对比本轮基线 1,345,717 字节减少约 35.4%；入口样式 964,455 字节，对比 1,184,860 字节减少约 18.6%。按需页面单独计入其加载阶段，不把这一比例换算成模型速度或启动耗时。

实际执行平台为 Windows，模型运行回归使用隔离的本地 HTTP/SSE 服务，没有修改真实模型、密钥或用户权限；macOS/Linux、远程页面的真实联网会话与外部模型端到端延迟未在本轮实测。异步面板的错误返回/重试入口已实现，网络故障下的所有模块加载失败类型未逐一注入测试。
