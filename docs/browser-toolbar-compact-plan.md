# 浏览器地址栏精简与 Agent 图标交互规划

日期：2026-11-03。状态：已实施，隔离运行时验证完成。用户已确认“批准”指页面“批注”按钮。本文保留实施约束，实际交付与验证边界见末节。

## 项目更新后的实施基线（实施前核对）

实施前对照 `4e6ca0b` 加当前工作区源码重新核对，已包含[主窗口规划第 24 节](./main-window-framework-v2-plan.md#24-浏览器常用标签功能接入2026-11-03)的标签功能接入。当时地址栏下的状态行、独立文字接管按钮、批注文字和常显下载入口仍存在；本次已完成这些界面调整，并保留新标签系统。

已实现并直接复用的部分：

- `BrowserTabsService` 和 `tabState/tabAction` 已管理标签顺序、固定、静音、多选、兼容宿主转移、关闭取消及运行内关闭恢复；`useBrowserTabController/useBrowserTabActions` 已共用菜单和命令。本次不再建立另一套标签命令或把批量标签操作放进 Agent 面板。
- `BrowserTabStrip/BrowserTabList/BrowserTabContextMenu/WorkspaceTabItem` 已提供标签搜索、右键子菜单、悬停卡片和一致外观；本次保留现有标签栏、R2、工作区数量开关及文件混排槽位。
- `AppIcon/getUiIcon` 已按实际尺寸选取共享 16px/20px 资产，主题与独立窗口外观同步已存在；本次使用这些规范，不增加图标字体或独立色板。
- 下载已有 SVG 进度环、未知大小与暂停动画、权限批准、完成通知和状态日志；`workspace-downloads` 与文件下载指示器已有有限数值校验及未完成最多 99% 语义。工具栏复用这些能力，补显隐、作用域、顺序保护和展示，不重做下载服务、不增加一次下载批准。

第 24 节当时记录的验证为类型检查与构建。首版自动化历史测试数字不作为新标签系统的验证证据；本次另行运行了标签与 Agent/下载的交叉回归，覆盖范围和剩余边界见末节，不替代标签系统全部拖放、关闭确认等实机验收。

## 布局

工具栏维持一行：导航按钮、地址栏、批注图标、有内容时的下载图标、更多图标。Agent 图标固定在地址栏内部右端，不在更多按钮右侧另设接管按钮。

- 删除地址栏下方固定 34px 自动化状态行，网页内容区域获得相应高度；详细状态移入 Agent 面板。
- 删除更多右侧的接管/恢复文字按钮，以及地址栏内重复的 AI/手动文字徽标。
- 地址栏输入聚焦时仍显示 Agent 图标；它不触发导航、表单提交或地址全选。更多按钮成为工具栏最后一个按钮。
- 批注使用现有 `annotate` 图标，移除文字与常驻数字；有批注时用小点提示，数量在工具提示和批注面板中展示。保留选中态、可访问名称和键盘操作。
- 保留固定宽度的 2px 网页外框槽；AI 操作时按现有反馈设置改变颜色，不随状态增减厚度。无需另加状态条、蒙层或占位文字。
- 关闭接管视觉反馈仅关闭装饰和活动强调，Agent 基本入口、控制状态与故障恢复提示仍保留。
- 工具栏高度固定。下载入口显隐仅改变地址输入的可用宽度，不改变网页视口。窄屏优先保留 Agent 和更多入口，导航沿用现有折叠规则。
- Agent/批注等常规工具栏图标采用共享 20px 规格，面板操作图标采用 16px；下载允许 16px 箭头配 20px 动态圆环。圆环以按钮中心定位，不依赖仅适合 32px 点击区的固定 inset，扩大点击区也保持同心。颜色使用项目主题变量，覆盖明暗及独立窗口；文件列表保留现有线性进度。

## 与现有标签系统的衔接

- Agent 控制切换和新批注选取只作用于当前显示网页；入口从该页面解析实际 `chatId/pageId`，下载再按其所属对话汇总，不取 `viewerChatId`、第一个会话、标签多选集合或后台右键目标。已有批注的定位继续按批注记录所属页面处理，定位成功后的页面切换沿用现有逻辑。主工作区能显示来自其他对话的页面，面板显示目标标题/域名以便核对；身份尚未确认时不派发。聊天页自己的下载入口仍属于聊天页对话。
- 控制切换继续使用单页 `workspace.command()`；标签新建、复制、固定、关闭、移动继续走既有 `tabAction()`。不因为多选 A/B 而把当前 C 页的接管扩大成批量接管。
- `BrowserTabState.revision` 用于标签快照，`automation.stateRevision/epoch` 用于页面控制和意图有效性。收到普通树更新不关闭面板或重建控制器；固定、静音和重排不改变控制者，也不因排序改变清空当前面板。真正失活或身份/宿主变化才使展示凭据失效。
- 移窗保留同一 WebContents/页面身份，复用已有 `withTransfer()` 结算；只作废源宿主弹层、截图和 `layoutOwner`，新宿主重新确认布局与控制状态。转移失败以主进程结果恢复，不本地猜测已移走，也不重新创建页面。
- 复制与关闭后恢复创建新的 `windowId/tabKey`。新页面使用新控制器和最新配置，不能按 URL、标题、标签位置或旧 ref 继承接管状态、未确认错误、面板缓存或旧输入意图。恢复历史不等于恢复在途自动化。
- 关闭请求不代表已关闭。可先收起面板，但只根据主进程实际关闭结果删除缓存；网页取消 beforeunload 后重新读取控制状态，不自动恢复 AI。批量关闭按已关闭/已取消的实际集合处理。空白页重启过滤、会话持久性、文件混排恢复沿用现有规则；Agent 面板不持久化，也不通过 ensure 重建被过滤的空白页。

## Agent 图标

机器人图形保持一致；AI 可操作时采用选中底色，人工状态使用中性色，暂停增加暂停标记，交还中使用小型转圈，交还未确认显示告警标记。状态不只靠颜色表达，工具提示和可访问名称同时说明当前状态与左键动作。选中只表示“允许 AI 操作”，实际执行、空闲和输入保护分别来自控制器，不把允许状态称为“AI 正在操作”。初次状态未知时显示读取状态、暂停主切换，不猜测控制者；详情入口保留。

左键行为：

1. AI 空闲、正在执行或等待网页时，发起 `takeControl()`，按现有控制器停止新输入并结算在途操作；保持接管入口可用。
2. 人工或暂停状态时，调用 `resume()`，允许新的 AI 操作；不启动已结束聊天，不重播旧动作。尤其不能沿用仅判断 `owner === 'user'` 的旧二选一逻辑。
3. 提交中或交还中，忽略重复左键切换；图标仍可右键或键盘打开详情。
4. 清理或解除保护未确认时，左键打开恢复面板，不直接恢复 AI。`release_unconfirmed` 提供现有 `retryRelease()`；`cleanup_unconfirmed` 的清理标记不会靠该方法清除，若已确认原生保护解除，则提供用户主动“重新加载页面”，明确未保存内容可能丢失，导航提交后才能重新观察并恢复。若保护也未确认，先处理解除保护；不自动刷新。确认成功后才呈现交还结果。
5. 原生状态已确认的普通动作错误仍遵循实际控制者；不能把所有错误都误判为“输入未释放”。

右键打开贴近图标、默认向下右对齐的 Agent 面板，建议宽度 300–320px，并按窗口可用空间翻转、限宽。面板包含当前控制者、当前动作/等待原因、实际输入保护状态，以及按状态提供的接管、暂停、恢复、重试交还和自动化设置入口。移动风格和速度可显示当前值，完整参数继续放在浏览器设置中。

打开面板本身不切换控制权。交还中允许查看但禁止重复提交；失败保留原因和明确恢复操作。活动页面首次出现新的交还未确认状态时显示一次不夺焦点的简短提示；不自动展开面板、关闭地址建议或打断批注编辑。已打开的 Agent 面板原地更新，后台页面只显示告警标记。详细日志不常驻工具栏。

## 键盘、触控与批注选择

- Enter/Space 等效左键；Shift+F10、菜单键或 ArrowDown 打开面板；Esc 关闭并把焦点返回图标。
- 触控长按打开面板，并抑制紧接着的 click；更多菜单保留 Agent 控制入口，供无法右键的设备使用。
- 面板采用含交互控件的 dialog 语义；移除状态行后保留不可见的简短实时状态播报，不在每个采样点重复播报。
- 交还/故障时不对整个图标设置 `disabled`，只保护主切换操作，避免同时封掉右键与键盘恢复入口。
- 批注选择模式保留 Agent 图标位置。恢复 AI 前先退出/取消选择并确认完成，不让选择模式隐藏控制入口或与 AI 输入交错。
- Esc 仅关闭最上层弹层并停止冒泡，下一次 Esc 才取消批注选择。Enter/Space 使用按钮原生 click，避免键盘与 click 重复调用，连续按键不反复切换控制权。
- 外部点击关闭面板时保留实际点击目标的焦点；只有键盘关闭才返回图标。页面失活、后台清空或其他窗口更新不得抢焦点。
- 地址栏内操作不提交、清空或重置未发送的网址，保留草稿及选区；中文输入组合期间不抢焦点或重复激活。图标沿用共享规格，桌面点击区域至少 32px、触控至少 40px，放大点击区域不改变工具栏高度。

## 下载入口

沿用现有下载列表和 SVG 圆环，统一为与批注、更多一致的图标按钮。

- 当前对话没有下载记录时隐藏，不显示空下载按钮。
- 仅隐藏触发按钮，下载订阅继续存活；首次新下载能自动显示入口。更多菜单打开同一面板，不另建一份订阅或下载列表。
- 有下载记录即保留入口，包括已完成、失败、取消和待确认项；不因活动数量归零而让结果消失。
- 进行中使用环形进度，中间为下载箭头；多任务按实际字节加权。仅对 started/paused 项合计，所有数值有限且有效时按接收总量/文件总量计算，并将每项接收量限于总量。未完成最多显示 99%，由完成事件确认结束。
- 任一进行中/暂停项总大小未知时使用不定长环；全部暂停时停止动画。失败、取消和待确认项不参与百分比；通过状态标记、工具提示及面板展示结果。
- 完成后回到中性下载图标；清空最后一条记录后关闭面板并隐藏入口。仅当焦点原本位于消失的按钮/面板内，才返回更多等仍存在的控件；后台清理不抢地址栏或网页焦点。移除记录不删除文件。
- 浏览器工具栏的作用域为当前页面所属对话的全部浏览器标签、会话和工具下载；关闭来源标签后仍能查看。独立窗口与主窗口同步，其他对话的下载不点亮该入口。聊天页下载入口则使用聊天页对话，不跟随异对话网页或后台标签菜单变化。
- 切对话先清旧列表，以请求代次拒绝晚返回；缺 chatId 的局部入口显示为空，禁止回退为全局下载。推送和操作请求按所属对话核对。记录数量限制只裁剪已结束项，不淘汰活跃下载及控制引用。
- 同一对话内也比较列表请求开始时的事件版本；新推送、终态或清空使旧快照失效，不让晚到 list 把记录复活。并行下载按创建时间/稳定插入顺序显示，不因每次进度的 updatedAt 更新而跳位；取消操作始终绑定条目 ID。
- 移除常驻下载数字徽标，任务数放入工具提示与面板。存在活动下载时，其他条目的失败不能覆盖进度环；圆环、主图标之外最多保留一种必要提示。全部暂停、控件不可见或系统要求减少动态效果时停止不定长旋转。
- 保留实际 `canPause/canResume/canCancel` 能力判断，不给工具下载显示不可用操作。更多菜单提供下载列表入口，空列表时仍可主动访问。
- 沿用 `browser-download-status` 的状态日志去重、完成时工作区通知和现有 `file.download.passive` 批准流程。下载作用域校验兼容两种调用：本地独立宿主核对所属对话，主窗口使用请求对话；已认证远程调用沿用 RPC 权限并显式传对话。远程 RPC 的 event 可为 null，不能假定所有调用都有 event.sender。若扩展接口参数/推送结构，同步共享类型、preload 和 remote shim，并兼容现有调用。

## 原生网页与弹层

Agent 面板不能只靠 CSS z-index 覆盖 WebContentsView。接入现有菜单的截图底图与原生 View 临时隐藏机制，显式上报面板开关；关闭后恢复相同网页矩形和适当焦点。截图与解码只用于改善观感，不能成为隐藏 View 或显示恢复面板的前置条件；优先使用缓存，异步获取新图，不可用时直接使用宿主底色。打开及关闭面板均不等待截图完成。

Agent、下载、更多、地址建议、连接信息、标签右键菜单/移动子菜单、标签搜索列表和悬停卡片纳入同一弹层仲裁；顺带补齐连接安全弹层尚未上报遮挡状态的问题。打开 Agent 面板复用现有 `navora:tab-hover-dismiss`，并将其纳入悬停检测及宿主快捷键 guard；不通过提高 z-index 覆盖新的标签菜单。Esc/方向键由最上层交互处理，Ctrl+L 关闭面板后聚焦地址栏，现有标签快捷键只执行一次。

面板在动作进行中、交还中及失败时均须能显示。打开/关闭面板不修改控制者，不缩小视口，不触发真实几何变化或隐式取消；原生输入结算不依赖面板关闭。组件通过 v-show 保活，切标签也必须关闭弹层；在失活、页面/对话/宿主身份改变及销毁时递增展示代次。截图、命令响应和焦点恢复核对捕获的页面 ID、宿主及代次；命令按发起时的身份校验，不能在 await 后改用后来选中的页面。自己的控制命令允许产生新的控制代次，不能因此把成功结果误报为取消。

状态行还承载现有网址、视口、批注保存和页面转移的普通错误。移除时将这些错误移到相应操作旁或可关闭的短提示，不把它们误标为 Agent 控制故障，也不能让错误失去可见出口。

## 实施范围与顺序

1. 先确定当前页面、所属对话、宿主与布局凭据；将新面板接入现有标签弹层/快捷键仲裁，复用标签快照与自动化状态，保留各自版本语义。
2. 提取统一 Agent 图标状态和主动作映射；复用现有单页控制器、IPC 与恢复契约。与标签多选、右键目标、转移和关闭取消交叉核对。
3. 在 BrowserAddressBar 接入右端操作插槽/图标与独立面板；BrowserTabPanel 移除旧按钮、文字徽标和状态行。内嵌与 BrowserHostPage 复用组件，不改现有标签栏。
4. 批注图标化；下载显隐、进度校验、页面所属对话作用域与晚返回保护，适配共享图标/主题和本地/远程调用。保留现有批准及完成通知。
5. 更新现有 UI 验证和截图；旧“34px 状态行存在”的断言改为不存在、可用高度增加、各状态网页边界恒定，并补最新标签功能的交叉回归。

主要修改：`src/components/BrowserAddressBar.vue`、`BrowserTabPanel.vue`、`BrowserDownloadsMenu.vue`、新 Agent 图标/面板组件、宿主弹层/快捷键适配、`electron/main.ts` 下载推送/操作、`electron/modules/browser-download-list.ts`、共享进度汇总及 `scripts/ui-browser-automation-entry.ts`。ChatPage 的同款入口同步聊天页对话作用域。

直接复用并做兼容核对：`BrowserTabsService`、`useBrowserTabController/useBrowserTabActions`、`BrowserTabStrip/BrowserTabContextMenu/BrowserTabList`、`WorkspaceTabItem`、`useFileTabs`、`AppIcon/getUiIcon`、`browser-download-status` 与 `workspace-downloads`。只补需要的弹层协调，不重写新标签系统、文件下载表现或会话恢复模型。涉及下载契约调整时同时覆盖 `shared/types.ts`、`electron/preload.ts`、`src/navora-remote-shim.ts`。

## 验收

- 工具栏仅一行，无下方状态行、无更多右侧文字按钮；地址聚焦和窄屏下 Agent 仍可操作。
- AI/人工/暂停/交还/未确认状态的左键映射正确；右键不误触发左键；快速连击不产生重复切换。
- 交还故障仍能打开面板和重试；普通动作错误不误报输入锁；后台提示不抢焦点。
- 键盘、触控长按、Esc 和焦点恢复正确；批注选择期间仍有 Agent 入口。
- 下载为空隐藏、完成保留、清最后项隐藏；未知大小、0 字节、并行字节加权、暂停/混合、失败均无假百分比。
- 切对话、后台下载、源标签关闭和独立窗口同步不串记录；旧请求不覆盖当前数据。
- 内嵌/独立、窄屏、125% 网页缩放和 175% 系统缩放下，状态切换及下载显隐不改变网页边界；面板在真实网页上方正确显示，关闭后无残留底图。
- .4 原生输入验证继续覆盖动作中打开面板、长拖动中接管与交还失败，不削弱首版旧意图失效和释放确认机制。
