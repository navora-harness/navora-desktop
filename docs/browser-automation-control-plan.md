# 浏览器自动化控制与可视反馈

日期：2026-11-03。依据当前源码与 `45.0.0-cloudbypass.4` 公开接口实施。

界面后续修订已实施：移除状态行和独立接管按钮，改为地址栏右端 Agent 图标、右键面板及按需下载入口，适配最新标签服务、关闭恢复、图标/主题与远程接口。隔离 `.4` 界面验证 53 项通过，最新结果与剩余边界见[浏览器地址栏精简交付记录](./browser-toolbar-compact-plan.md#交付记录2026-11-03)。该修订覆盖本文旧布局安排；以下首版实现与验收数字作为历史记录保留。

## 交付目标

Agent 普通点击和悬停只需 `windowId + ref`，运动参数自动继承用户偏好。浏览器设置新增 AI 自动化组，默认显示原生虚拟光标、启用平滑移动与控制反馈。工具栏始终提供接管入口；接管期间固定网页外框和状态行，不改变原生网页矩形，不向网页注入光标。

移动速度允许 0.05 倍步进；高级设置保留采样间隔和绘制帧率。移动速度、采样密度、点击驻留和网页等待分别处理。全局策略合并单次覆盖后统一校验，不能同时继承 `intervalMs` 和 `sampleRateHz`。

## 实施顺序

1. 页面控制器：完整动作串行、控制代次、页面独立取消、接管清理与失败恢复。
2. 配置与原生光标：统一校验、旧配置迁移、逐页热应用和生效状态；缺字段补默认，保留已保存的 `false`。
3. Agent 入口：规范化别名、Flow/iframe/插件/远程入口、短 ref/原生 target 与默认运动策略。
4. 浏览器反馈：内嵌与独立窗口共享状态，固定外框槽和状态行；后台标签提示而不抢焦点。
5. 验证：单测、类型检查、隔离 `.4` 原生页面验证，以及当前 UI 截图检查。

## 复核后必须落实的约束

### 旧动作不能复活

动作绑定页面、运行及控制代次。权限返回、出队、定位后和真正派发前重新核对。接管、停止、人工导航或同 URL 刷新淘汰旧动作；恢复后先重新观察，不续播旧轨迹，不重放部分点击。同轮尚未开始的旧工具调用也必须失效，并为每个 tool call 返回结果。动作自身触发的导航允许结算结果，不能使后续旧坐标变为有效。

### 串行范围是完整动作

同页“定位 → 移动 → 原生点击 → 结果记录”使用同一作用域。Flow 子调用继承作用域，不重复入队造成死锁。不同页面互不误停。原生输入队列无法替代宿主语义动作的协调。

### 交还有明确失败分支

顺序为：关闭新写入口、作废旧动作、取消可取消输入、结算已提交动作、核对释放结果、确认解除保护、交还用户。清理 Promise 结束不等于释放成功；同时记录 `cleanup.failed`、原生部分点击警告和解除保护结果。失败时进入“交还未确认”，保持 AI 写入暂停，提供宿主重试和诊断。幂等关闭配置可有限重试，输入动作不重放，不自动刷新或销毁页面。

`.4` 的 `clickSelector` 一旦提交没有取消参数，中途失败也不提供 sequence 的完整清理账本；`setVirtualCursorEnabled(false)` 失败还可能恢复此前模式。不能承诺瞬间或固定秒数内绝对停止所有在途点击。若要求渲染无响应时仍可靠解除保护且保留页面，需要内核提供可确认的强制释放/取消清理契约。

### 等待与人工干预

必要结果核对可以保留有界的动作作用域；模型思考、权限等待不持有网页输入锁。作用域已经结束的等待不加锁，下一次写入重新观察与定位，不能跨未保护间隙复用旧几何。不要以 DOM `isTrusted` 猜测输入来自真实用户还是自动化。

### 设置热应用

区分已保存偏好、应用中、各页已生效状态和失败原因。旧成功/旧失败不得覆盖最后一次设置。自动化字段采用增量保存，避免旧整份配置覆盖并发更新。关闭光标或保护前先停止新写并结算当前动作；关闭显示本身不会取消 sequence。显式传入两类阻断标志，不依赖原生省略参数时的保留规则。保护开启失败不得继续派发该次输入。

### 全入口与遗留持有状态

权限与控制权使用同一份规范化调用。Flow、iframe helper、插件受管工具、远程输入和影响多个页面的 Session 写操作都检查控制权。暂停、失效和控制权变化是 Flow 硬停止，禁止 `retry_from`。旧插件若直接持有原始 WebContents，必须注明兼容边界，不能宣称已完全受控。旧 down/up、按键、触摸需登记持有状态，禁止和闭合 sequence 交错；接管关闭新写后，专属清理释放仍可执行。

### 能力、页面与布局

按实际运行内核和视图启用结果判断能力，包版本不代表已生效。协调器属于页面/WebContents；隐藏和失焦不是取消。新页面应用最新设置，人工页面不被全局切换误锁；销毁后忽略旧回调。页面转移前结算动作，转移后重验几何。

输入坐标是视口 CSS 像素，target 偏移是元素局部 CSS 像素；截图像素通过实际缩放和裁剪偏移换算，宿主布局 DIP 不混入输入坐标。状态变化不调整网页矩形；真实缩放和布局变化使旧几何失效。

### 恢复与结果

恢复只允许新的浏览器动作，不自动启动已结束聊天。状态由实际操作生命周期驱动，不以聊天 `running:false` 当作原生输入已释放。返回结构化完成、取消、失效、部分派发与需用户恢复结果；不伪造逐点进度，不把派发当作业务成功。

### 真实设备验收

已有隐藏窗口自动化不能替代真实鼠标、键盘、中文 IME、触控板、混合 DPI、失焦/最小化与睡眠恢复测试。轨迹模型仍需实机观感校准，不承诺“完美像人”。输入采样和光标绘制分别验证，固定 seed 仅用于复现。

## 关键验收场景

- 权限等待中接管后再批准；暂停后立即恢复；同 URL 刷新后的旧队列。
- 并发点击和悬停；移动后接管；目标点击按下后节点失效；iframe 定位晚返回。
- 长拖动中接管、关闭光标、切换保护；释放失败、清理超时和关闭配置失败。
- 连续开/关/开；UI 与 Agent 同时修改不同配置；部分页面应用失败。
- Flow 暂停、插件别名、远程连接中断、遗留按下后的专属清理。
- 后台 A 页操作、B 页人工；同时新建、转移和关闭页面。
- 暂停后停止聊天再恢复；每个 tool call 都得到结果，旧动作不再次派发。
- 网页缩放、侧栏变化和独立窗口坐标一致；截图不被虚拟光标污染。

## 交付记录
