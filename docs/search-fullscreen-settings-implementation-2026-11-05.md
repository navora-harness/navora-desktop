# 顶部搜索、全屏与设置调整（2026-11-05）

本轮源码已纳入 0.4.7 Windows x64 安装版／便携版，保留覆盖发布的 `45.0.0-cloudbypass.9 / replacement-714ba8c41bb5`。版本、锁文件及成品信息均为 0.4.7；类型、728 项单测、构建、源码／运行时与两种制品内嵌文件核对通过，隔离成品启动并正常退出，未运行安装器或替换个人安装。制品与验证清单位于 `release/v0.4.7/`，打包日志位于工作区 `_planning/release-0.4.7-2026-11-05/`。规划依据见 [顶部 NP 搜索与全屏规划](./已完成/search-np-and-fullscreen-plan-2026-11-05.md)。

## 搜索

每个应用窗口挂载自己的搜索宿主，原生卡片使用 NativePanel。当前聊天入口不再打开聊天列表或收起工作区；聊天、当前网页、当前文本／Markdown 和子对话使用各自的查询适配器。切换范围保留关键词，旧页面令牌／文档代次阻止迟到回执进入新目标。文本文件仅查找已加载内容，截断和不支持的格式明确提示，不执行 OCR 或 PDF／Office 内容解析。

空查询为一行胶囊，输入后展开上下项与计数；只显示当前范围支持的大小写和工具／日志选项。普通窗口放在标题栏下，避免窄独立窗口的原生窗口按钮被覆盖；全屏移到内容顶部。尺寸、主题、计数更新只更新原生树，不重建输入控件，并省略更新中的 input.value，保留输入及组合输入。

首次与重复显式打开通过公开 destroy → show 创建输入优先的焦点会话。失焦、页面点击与普通菜单不会关闭卡片，网页中的 Escape 保留网页行为；仅搜索内 Escape 或关闭入口关闭查找。隐藏聊天内输入只统计结果，显式定位匹配项才展示聊天。全局对话搜索仍检索保存的聊天，采用相同顶部布局和首焦点策略。

## 窗口与工作区

主窗口及独立浏览器／文件窗口接入真实 BrowserWindow 全屏、当前所属窗口的 F11、菜单和可见按钮。退出恢复进入前的普通窗口尺寸及最大化状态，全屏尺寸不写作普通窗口尺寸。网页元素全屏与窗口 F11 分开维护，退出元素全屏恢复原先窗口状态；切页、导航和迁移撤销对应文档的全屏声明，恢复固定视口及缩放偏好。

网页元素全屏仅允许当前前台、可见的活动页；无手势自动全屏继续拒绝，未放开其它未知权限。切换全屏调整原 View 布局，不重建网页。工作区标签本体双击切换展开／分栏，保留所选聊天或工作区内容，排除关闭、音量按钮和拖动；独立窗口不套用分栏切换。

## 设置

外观入口采用同套 Fluent Regular 调色盘图标。放手权限预设采用应用内主题确认卡片，明确能力扩大与影响范围；默认聚焦“保留当前设置”，取消／Escape／卸载均按拒绝结算，只有当前请求的明确确认才变更预设，沿用现有自动保存。关于页面突出应用及版本，移除安装版运行模式与数据目录展示，不删除任何实际数据。

搜索专项明确区分活动页面和切换标签：打开网页搜索期间不请求替代截图、不隐藏活动 View，网页身份和 RAF 持续；用户切换到文件标签时，原网页 View 正常隐藏，这不是搜索弹层的截图占位路径。其它尚未迁移的 DOM 弹层保留此前记录的截图／隐藏分支，本轮不宣称全仓归零。

当前公开 NativePanel 只有 input change／submit，没有修饰键和通用按键回调。NP 内文本、Enter、Escape 已用限定 PID 的 Win32 消息实测；同样定向发送 F3／F11 未转发到宿主（结果已记录），Shift+Enter、Ctrl/⌘F、Ctrl/⌘K 仍没有完整转发验收。搜索方向按钮及窗口全屏按钮可用，未用私有接口或全局快捷键补捕获。宿主／网页 F11 使用 Electron 定向输入事件测试，网页元素全屏包含限定测试进程的真实点击；不等同于物理 OS F11 验收。跨显示器、混合 DPI、真实视频站点及其它平台仍需实机验收。

独立审查使用普通功能审查代理，未调用不可用的专用 Bugbot 服务。确认的三处 P2（隐藏聊天被查询切回、网页 Escape 关闭卡片、窄独立窗口搜索覆盖标题按钮）均已修复并进入定向回归。
