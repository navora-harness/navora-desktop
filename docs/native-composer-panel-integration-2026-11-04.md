## 继续使用原生控件的输入区面板

- 模型面板：服务商分组、模型搜索、可滚动候选项、当前模型标记、能力说明、密钥缺省提示、思考等级选项、读取失败重试。搜索过滤不使用列表下标作为模型动作身份。动作再次检查当前会话、候选身份及运行/保存中的禁用状态。
- 回答方式与权限预设：保留图标、选中标记、用途说明及原业务处理函数。仅明确点击产生变更，打开、聚焦及关闭面板均不更改配置。
- 上下文面板：分别展示粗略估算和最近一次服务返回的实际用量。未知实际用量保持“服务尚未返回用量数据”；真实的零用量与缓存命中零仍可显示。超过预算时文本保留真实百分比，仅将进度条限制为 100%。
- 选区格式浮条：链接、粗体、斜体、正文/标题/列表。自动浮现使用不主动抢焦点的模式，显式进入工具条时启用菜单键盘模式。文字样式动作恢复并使用原编辑器选区，不重建编辑器，也不以网页输入或人工接管代替格式命令。

每个面板通过 `useNativePanel` 使用宿主统一的窗口身份、显示代次、当前会话校验、屏幕 DIP 锚点换算、主题、图标、关闭及焦点逻辑。已支持原生面板的平台若原生显示失败，会明确提示且保留草稿，不悄悄转为截图浮层。只有能力明确不支持时使用 DOM 兼容路径。

## 保留的独立编辑对话框

`ComposerSourcePicker.vue` 包含可编辑的多行资料、代码/摘录、预览图、起止行号及文件导入。`ComposerEditor.vue` 的链接编辑器也允许编辑多行显示文字。当前内核只有单行 `input`，未提供原生多行编辑控件，`icon` 也不能作为任意图片预览控件。因此这两类编辑对话框继续使用原有界面和原有兼容显示路径。本轮不声称它们已完成原生化，也不将多行资料压成单行或丢弃预览以规避能力缺口。

## 验收范围

纯函数用例覆盖搜索后控件身份稳定、模型不可用/保存中状态、估算与实际用量分离、零值、进度限制、图标和预设说明，以及自定义模型字符串仅作为普通文本。纯函数检查不代替真实原生窗口的键盘、输入法、滚动、焦点或 Agent 连续输入验收。

本轮已通过：5 项纯函数测试；23 项真实 Vue 组件及 TipTap 适配检查，报告位于 `_planning/native-composer-adapters-current/completed.json`；24 项不支持原生能力时的编辑器、选区工具、附加来源与队列编辑兼容检查，报告位于 `_planning/native-composer-dom-fallback-current/completed.json`。上述组件测试均使用隐藏的隔离 Electron 窗口、临时资料目录及本地模拟来源。23 项适配检查的 NativeUiApi 为受控桥，只证明动作映射、稳定身份、旧会话拒绝及草稿/选区保留，不把它计为操作系统原生窗口或中文输入法已通过。

`0.3.38` 实际构建另通过 25 项主窗口集成检查，报告位于 `_planning/native-composer-main-current/completed.json`。该套件加载实际 main、preload 和 renderer，构造真实 `NativePanel`，覆盖模型、思考等级、回答方式、权限、上下文、附加搜索、斜杠与选区格式。检查原网页实例、控制权、原生父视图链与 DOM 槽位坐标保持一致，真实 RAF 持续推进；所有已迁移面板的截图请求为零，WebContents 数量始终为 2。10 次原生显示复用 3 个原生实例，14 次内容更新未重建对应搜索面板。只有最后明确打开保留的多行来源编辑器时调用 1 次原有兼容预览，未计入原生零截图路径。

权限回包检查使用真实保存处理器和真实持久化结果，仅延迟返回投递。用户切换到另一聊天后才释放旧回包，原聊天权限成功保存，当前聊天标题与草稿保持不变。原生实例的 `show` 在主进程先发生，测试会等待主处理器让出及 renderer 任务往返确认后再注入动作，不把“原生已可见”误当作“renderer 已收到本次显示代次”。

首轮真实构造发现内核会拒绝显式的 `sourceWebContents: undefined`，应用已改为省略未提供的可选字段，失败证据保留为 `first-failure-undefined-source.json/log`。另保留一次真实 `outside-click` 导致测试面板被正常关闭的记录；串行复跑保留原生外部关闭行为后 25 项通过。最终退出阶段没有 stderr 输出。测试没有禁用原生外部点击关闭。

真实构建套件仅在测试 IPC 入口将原生 `focusMode` 改为 `none`，避免无人值守测试激活其他前台窗口；控件树仍通过真实内核校验，动作与关闭事件则由测试明确注入。因此该记录没有证明操作系统层的点击命中、键盘遍历、中文输入法候选窗、视频解码或运行中的真实模型任务。底层连续性证据是本地真实 RAF 和原有空闲控制器，不扩大为这些未执行场景。
