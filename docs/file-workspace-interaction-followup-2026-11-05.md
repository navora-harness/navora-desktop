# 文件与独立工作区交互优化

日期：2026-11-05。用户逐项确认的新增范围，接续 0.4.10；本记录是本轮实施依据，不将未完成源码描述为已发行功能。

## 本轮目标

1. 对话正文中的文件、图片和普通链接默认没有下划线，鼠标停留时采用虚线；键盘聚焦同样提供反馈，保留颜色、完整路径提示及点击行为。
2. 使用文档搜索框由外层圆角容器显示单一柔和聚焦反馈，去除内部方形焦点框。打开文档时书本成为左侧唯一当前入口，其他入口取消高亮；返回恢复原入口，从文档直接选原入口不能误收起侧栏。
3. 对话文件内容区采用资源管理器交互：单击选择、双击或 Enter 打开；Ctrl/⌘ 多选、Shift 范围选择、方向/Home/End、Ctrl+A、Esc、Alt+上、Backspace、F5、键盘上下文菜单。作用域限定当前可见列表，输入框保留正常编辑。未支持的复制、剪切、改名和删除不绑定伪快捷键。
4. 标签选中状态、标题、音量、加载及当前工具栏变化不能改变已分配的标签宽度；真正窗口缩放或标签数量/固定状态变化仍可重新分配。空间变化以溢出滚动承载。
5. 修复跨窗口拖动时来源 dragend 与目标 drop 争抢同一交接凭据的问题；有效接收由目标完成，取消和窗口外拆出各自只执行一次。过期、已关闭或权限不符仍拒绝，迟到准备不能复活已销毁的组件。
6. 独立文件和网页窗口统一为真实的混合工作区宿主。文件不伪装成网页，保留实际文件 owner；网页保留同一 WebContents、会话、输入、控制权与显示所有者。两类标签可共存、切换、排序、移回，只有全部内容关闭才销毁窗口。
7. 统一独立窗口左上角布局、菜单、标签栏和加号；加号新增当前上下文的网页标签。移除文件窗右上角移回按钮，既有移回操作保留适当菜单/左侧入口。文件预览使用导航工具栏，放显示方式、文件信息、刷新、缩放/打开方式及右侧更多，标题栏不再出现游离的更多按钮。

## 实施与验证安排

- 复用已有文件动作与身份检查；不通过视觉共用绕过主窗口/宿主/主 frame 权限。
- 混合宿主统一 state、active 和 order，旧文件转移 API 保持兼容。关闭最后一种内容时保留另一种，主窗口接收失败时保留原标签。
- 验证真实组件选择、标签几何和拖动异步次序，再使用隔离资料、本地网页做主窗口和混合独立窗口检查。
- 截图与测试仅使用合成文件、网页和草稿；最终记录将分别说明源码、实际窗口与成品范围。

## 实施结果

上述七项已实施并纳入 Windows x64 0.4.11 安装版与便携版。文件、网页共享 `/browser-host/:id` 和一份真实标签顺序、当前项；旧文件路由仅保留兼容入口。文件保持 DOM 预览，网页保持原 WebContentsView，不因切换或移窗重建页面。

补充保护已落实：文件激活时撤销旧网页布局租约并将键盘焦点交回宿主；迟到的网页布局、隐藏网页快捷键及后台网页标题不能覆盖当前文件。跨批网页转移失败恢复完整混合顺序和原选中项；窗口关闭等待网页确认，取消时保留内容；已打开的“全部移回”菜单遇到标签变化会要求重新打开。

使用文档已补充选择快捷键、独立窗口的加号与工具栏说明。单击选择范围仅指文件管理器内容区；聊天交付卡片和文件侧栏继续保留各自入口行为。
