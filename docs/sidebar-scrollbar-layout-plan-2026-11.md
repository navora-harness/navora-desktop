## 1. 目标与术语

每个侧栏列表的原生滚动条位于列表行外侧的独立留白中。选中背景、悬浮背景、操作按钮和键盘焦点不延伸到滚动槽，行末菜单不会与拖动滚动条争抢位置；出现滚动条时不改变行宽和文字截断位置。

统一面向用户的名称：

- **图标栏**：最左侧的图标列，切换对话、文件、浏览器、插件及设置。
- **侧栏**：图标栏旁展开的对话、资源、插件或设置列表。
- **工作区**：右侧内容区，以及其中的对话、文件、浏览器和后续子对话标签页。
- **列表行**：侧栏内可选择的对话、文件、会话、网页、插件或设置分类。
- **滚动槽**：列表行右侧为原生滚动轨道预留的区域，不是新增可点击控件。

最新用户说明撤回此前的改名要求，相关内容标签区域统一叫“工作区”。左侧按位置描述为图标栏/侧栏，不另加统一改名；不为文字规范无关地改动组件文件名、存储键和接口。

## 3. 共用几何与原生行为

桌面侧栏采用同一组默认值：原生轨道宽度 6px，列表行内容边界到轨道至少留 8px，合计约 14px 的视觉分隔。具体值在明暗主题、窄侧栏与 125%—200% 缩放下复核后固化为公共 token。

结构为固定头部、一个原生 scrollport、固定底部。scrollport 内使用 rows 容器承载行；选中、悬浮和焦点背景仅作用于 rows 中的单行。原生轨道位于 scrollport 的最右侧，独立留白不另画分隔边框，保持轻量。

实施约束：

1. scrollport 使用 `min-height:0`、明确的纵向溢出与 `scrollbar-gutter:stable`，保留系统原生拖动、滚轮、触摸和键盘滚动。
2. 独立留白使用真实内边距；即便系统采用覆盖式滚动条，也不能只依赖 `scrollbar-gutter` 留白。
3. 统一行宽的计算来源，禁止用负外边距把行背景延伸到轨道，禁止反复叠加 `calc(100% - ...)` 修补单个列表。
4. 搜索框、标题和 footer 保持既定宽度；滚动条出现时仅列表内部保持稳定，搜索框不随滚动条收缩。
5. 必要的树层级通过节点缩进表达，右侧动作对齐同一内容边界。长标题省略，不挤压菜单按钮和滚动槽。
6. 沿用原生轨道，不做自绘 thumb、假进度条、覆盖层拖动或 pointer-events 阻断。
7. 公共滚动颜色来自主题 token；深色轨道与 thumb 不保留硬编码白色描边。键盘焦点保持完整可见，不被 scrollport 裁去。

## 4. 样式归口与嵌套去重

目前 `src/styles/postpile-theme.css:180-181` 对所有侧栏后代定义滚动颜色，`:624-629` 仅覆盖 `.chat-list/.res-body/.res-tree` 的轨道与按钮，遗漏全局资源 owner 列表、插件列表和设置导航；这是源码可确认的样式分散，不代表每个平台已经复现同一种外观故障。

实施时为真正的侧栏 scroll owner 添加明确公共类，集中定义宽度、间隔、轨道、thumb 和悬浮颜色。组件只声明布局归属及必要差异；移除被公共规则取代的旧覆盖，避免再增加一层更高优先级选择器。

按上下文去重：全局文件资源移除内部竖向滚动，全局浏览器继续单一外层滚动；局部摘要卡和资源弹层保留独立限高滚动；主内容详情的代码块、错误详情等局部滚动单独保留。水平溢出若非内容必需，优先修正 `min-width:0` 和长文本截断，不出现第二条横向轨道。

## 5. 分批实施

1. 建立公共 scrollport/rows 规则与主题 token，先用对话侧栏验证无溢出、有溢出、宽度调整和末行操作。
2. 迁移全局文件、浏览器资源侧栏，清除文件树双重竖向滚动；分别复查局部摘要卡，确认没有误伤。
3. 迁移插件侧栏和设置导航；检查 Teleport 后的类名归属、焦点滚入与固定 footer。
4. 对主文件列表、技能主内容和局部详情复用合适的外观 token，保留其真实布局身份；完成移动版检查与旧子树滚动样式清理。

各批只迁移确认归属的 scroll owner，不同时重做列表数据模型或资源权限。已有列表键盘逻辑及 `scrollIntoView({block:'nearest'})` 需要随实际 scroll owner 验证。

## 6. 验收标准与证据

- 对话、文件、浏览器、插件、设置导航分别在 0 条、少量和大量内容下检查，实际溢出的列表有原生轨道，无溢出时没有假 thumb。
- 大量文件目录和多个浏览器会话展开后，每个全局侧栏只有一个纵向 scroll owner，wheel 不在内外两条轨道之间跳转。
- 出现/消失滚动条时标题、省略位置、末端更多按钮与行内容宽度不跳；hover/selected/focus 背景停在独立留白左边。
- Windows 显示/自动隐藏滚动条两种策略，鼠标拖动轨道、滚轮、触摸板、PageUp/PageDown/Home/End 均可到达首末行。
- 侧栏最窄/最宽、125%/150%/175%/200% 缩放、低高度窗口、长标题、末行菜单均不遮挡内容或导航动作。
- 明暗主题、高对比可读性与减少动态效果下检查轨道；选择和状态不只依赖颜色。
- 设置引导、插件导入等 footer 与搜索框保持可见；主内容的技能列表、文件网格、局部摘要卡仍能正常滚动。
- 以 DOM 几何与真实滚动位置验证间隔、首末项可达及无双重 owner；截图记录桌面、窄侧栏、深色和高缩放。仅离线示例通过不算生产组件或原生窗口验收通过。
