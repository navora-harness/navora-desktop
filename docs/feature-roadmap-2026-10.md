# Navora 后续功能规划

日期：2026-10-31。依据当前源码和本轮标签页工作区需求，按依赖顺序交付，不预设未经验证的完成日期。

## 本轮：文件标签工作区

文件从资源卡片中独立到右侧侧栏，支持多标签、重复打开复用、关闭相邻切换、键盘导航、宽度调整、窄屏覆盖与按对话恢复标签元数据。跨会话文件保留真实工作区归属。文本、Markdown 和图片继续受读取大小及工作区边界限制；缓存最多四个已访问预览，图片可调整缩放。

默认打开文件留在应用内；显式“在系统中打开”继续调用系统程序。关闭侧栏保留标签，关闭最后一个标签收起侧栏。对话与文件各自滚动；资源卡片仅管理和快速选择资源。

## 本轮：过程与最终答复

执行中的说明、工具、插件、自动化、日志与思考归入统一过程详情，默认折叠。最终答复独立显示正文、来源、复制与整轮耗时；过程说明不再重复显示回答操作。新消息保存明确阶段，历史消息按工具边界兼容展示，原文不改写。

资源输出与来源只收录最终答复，子任务摘要同样排除中间说明。模型提示词要求先给结果、只保留必要依据与限制，部分完成和失败必须如实说明，避免把“重试/获取页面”当成最终答复。

## 下一阶段：统一资源与产物索引

为文件、来源、附件、下载和生成产物建立稳定记录，包含 ownerChatId、runId、相对路径、类型、来源和修改版本。用文件事件更新索引，准确区分输出和输入，覆盖深层新增、覆盖、删除及读取失败。来源绑定产生引用的具体回复，可跳回证据位置。索引失败可重建，不将失败伪装为空结果，不扩大工作区授权。

验收：同名文件不会串对话，增量变更可追踪，读取失败可恢复；先做确定性的名称与摘要检索，再依据实际任务评估全文或向量索引。

## 后续：浏览器工作区与用户接管

复用现有浏览器身份与登录态，提供标签、页面状态与接管入口；明确 Agent 和用户的输入所有权。页面快照按文档版本失效、检索和缓存；导航后旧元素引用必须失效。浏览器释放时机继续由 Agent 判断，界面提供显式关闭和释放操作。定制内核方法先探测，再使用，不改变插件 Host API 的现有兼容入口。

验收：切换标签不重复创建窗口、不丢登录态；接管可恢复，失败可解释，停止贯穿页面等待与工具执行。

## 后续：可控文件编辑

在稳定的资源归属和版本记录上增加文本、Markdown 编辑、查找替换与编码提示。保存前检查文件版本，冲突展示差异并允许重新加载或另存。写入采用原子替换，失败保留旧文件；Agent 修改与用户编辑使用相同版本协议。图片标注、裁剪和导出使用派生文件，保留原图与撤销记录。PDF、表格及其他渲染器独立评估后接入。

验收：未保存修改在关闭、切换和退出前有一致处理；文件不执行脚本，目录权限不因编辑而扩大。

## 后续：响应速度、恢复与扩展契约

分开记录首字、模型调用、工具等待和完成耗时，在固定任务集上验证成功率与 p50/p95。优化普通问答准备开销、只读缓存和取消传播。恢复前确认已有副作用，避免重复提交、下载和写入。工作区最终提供受控渲染器与标签扩展点，保留现有插件与技能契约。

验收：停止后不继续启动后续工作；恢复不重复副作用；Windows、macOS、Linux 分别验证启动、窗口、输入和资源行为。未实测的平台明确记录。
