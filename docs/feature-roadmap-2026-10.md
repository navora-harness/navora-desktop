# Navora 后续功能规划

日期：2026-10-31。依据当前源码和本轮标签页工作区需求，按依赖顺序交付，不预设未经验证的完成日期。

## 本轮：文件标签工作区

文件从资源卡片中独立到右侧侧栏，支持多标签、重复打开复用、关闭相邻切换、键盘导航、宽度调整、窄屏覆盖与按对话恢复标签元数据。跨会话文件保留真实工作区归属。文本、Markdown 和图片继续受读取大小及工作区边界限制；缓存最多四个已访问预览，图片可调整缩放。

默认打开文件留在应用内；显式“在系统中打开”继续调用系统程序。关闭侧栏保留标签，关闭最后一个标签收起侧栏。对话与文件各自滚动；资源卡片仅管理和快速选择资源。

## 本轮：过程与最终答复

执行中的说明、工具、插件、自动化、日志与思考归入统一过程详情，默认折叠。最终答复独立显示正文、来源、复制与整轮耗时；过程说明不再重复显示回答操作。新消息保存明确阶段，历史消息按工具边界兼容展示，原文不改写。

资源输出与来源只收录最终答复，子任务摘要同样排除中间说明。模型提示词要求先给结果、只保留必要依据与限制，部分完成和失败必须如实说明，避免把“重试/获取页面”当成最终答复。

## 本轮：资源关联、检索与加载优化

已接入有数量边界、短期缓存、请求合并和并发限制的深层文件元数据索引。文件以 ownerChatId 与规范路径稳定标识，mtime/size 表示元数据修改版本；对局部读取失败、截断与整体错误分别显示。文件名/路径检索支持全部、产物、图片、文档、代码筛选。

仅从确认成功的内置文件写入、复制、移动、合并、下载及截图结果关联相关工具、所属提问和最终回复；未知来源保留为工作区文件。关联记录用于定位，不能代替文件实际内容验证。标签支持规范路径复用、嵌套链接、关闭焦点恢复及会话删除清理。

Markdown 导出沿用界面的过程/最终答复分类，JSON 保持完整记录。设置、创建器、帮助和远程页面延后加载，异步面板提供加载状态、重试与返回。通过现有模板自动导入按需打包组件；实测初始脚本约减少 35.4%、入口样式约减少 18.6%，这不是模型速度提升比例。

完整持久索引、统一 runId、附件/下载完整来源链、内容摘要检索与版本冲突仍属后续工作；本轮 turnId 不冒充 runId，revision 也不是内容哈希。索引始终服从现有工作区边界。

## 后续：浏览器工作区与用户接管

复用现有浏览器身份与登录态，提供标签、页面状态与接管入口；明确 Agent 和用户的输入所有权。页面快照按文档版本失效、检索和缓存；导航后旧元素引用必须失效。浏览器释放时机继续由 Agent 判断，界面提供显式关闭和释放操作。定制内核方法先探测，再使用，不改变插件 Host API 的现有兼容入口。

验收：切换标签不重复创建窗口、不丢登录态；接管可恢复，失败可解释，停止贯穿页面等待与工具执行。

## 后续：可控文件编辑

在稳定的资源归属和版本记录上增加文本、Markdown 编辑、查找替换与编码提示。保存前检查文件版本，冲突展示差异并允许重新加载或另存。写入采用原子替换，失败保留旧文件；Agent 修改与用户编辑使用相同版本协议。图片标注、裁剪和导出使用派生文件，保留原图与撤销记录。PDF、表格及其他渲染器独立评估后接入。

验收：未保存修改在关闭、切换和退出前有一致处理；文件不执行脚本，目录权限不因编辑而扩大。

## 后续：响应速度、恢复与扩展契约

分开记录首字、模型调用、工具等待和完成耗时，在固定任务集上验证成功率与 p50/p95。优化普通问答准备开销、只读缓存和取消传播。恢复前确认已有副作用，避免重复提交、下载和写入。工作区最终提供受控渲染器与标签扩展点，保留现有插件与技能契约。

验收：停止后不继续启动后续工作；恢复不重复副作用；Windows、macOS、Linux 分别验证启动、窗口、输入和资源行为。未实测的平台明确记录。


## 2026-11-01：执行记录与答复附件收敛

同一段执行的收尾日志合回最终答复前的执行记录，沿用原有折叠项标识；新提问和答复后的新工具执行保留边界。文案同时显示调用数、日志数与失败调用数；执行中、中断、主动停止和达到轮次上限分别表达，不以“有失败”代替任务结果。Markdown 导出使用同一摘要和分组，JSON 保留原始数据。

手动关闭浏览器不再追加对话日志，也不抢占任务阶段；任务进行中仍以内部操作事件告知 Agent 哪个窗口已关闭。手动释放 Session 延续无日志行为，Agent 的真实工具调用与错误仍可追溯。历史手动关闭通知在展示时收起噪声，原始记录保留。

已确认生成且仍存在的工作区文件在所属最终答复底部显示附件卡片，包含文件名、类型与大小，点击打开现有右侧标签页。卡片放在正文之后、复制和耗时之前。不凭最终回复里写出的任意路径推断产物；删除文件后不保留可用假象，更新同一文件时关联最新确认操作。

## 下一轮执行顺序与验收

### 1. 运行身份与耗时分解

先为运行建立持久 runId 与事件序号；工具、进展、日志和最终答复共享身份，排队任务分配新身份，插入纠正保留当前身份，续跑记录父运行。历史对话继续使用现有工具/消息边界，不能靠措辞迁移。持久化最终状态与首个模型输出、模型调用、工具执行和整轮耗时；等待权限和用户回复单列，不计为模型延迟。

验收：收尾事件即使晚到也不会归入下一问；重复事件不会产生第二份答复；停止与轮次上限不伪装成成功；固定本地任务可复现各项耗时。外部模型与站点单独采样，不将本地服务测试结果宣传为真实网络耗时。

### 2. 完整的输出文件契约

在现有 owner/path 与成功工具证据上补充 artifactId、来源 runId、原始文件/派生文件关系和内容版本。先覆盖内置下载、写入、截图与浏览器下载，再给插件结果提供可选 artifacts 声明，由宿主校验所有权、实际文件和权限。插件现有返回值保持兼容。

验收：一轮多文件不漏项；重复写入明确版本；改名、删除和来源缺失有准确状态；跨会话同名文件不混淆。工作区之外的桌面导出需先建立明确的输出登记与现有授权范围，再提供打开或定位；不解析普通回复文字来扩大可读目录。

### 3. 浏览器工作区与接管

按所属对话与 Session 管理标签，区分加载、可读、失败、已隐藏和已释放状态；标题和 URL 改变不创建新资源。用户接管与交回 Agent 需要宿主维护输入所有权，防止两方同时点击；显示窗口本身不冒充暂停 Agent。保留登录态，释放仍由 Agent 按任务判断或用户明确操作触发。

验收：接管过程中 Agent 的新输入受控；交回后先重新观察再操作；导航立即使旧引用失效；关闭资源保持对话安静；跨域 iframe 与定制内核能力分别覆盖本地验证。

### 4. 可控编辑与界面模块拆分

文件标签页增加文本/Markdown 编辑、查找和版本冲突处理；原子保存失败保留原文。编辑缓存与只读预览缓存分离，切换、关闭及退出统一处理未保存状态。随后按执行记录、答复附件、输入队列和资源布局拆分 ChatPage，不重写插件宿主协议。

验收：Agent 与用户并发修改时不会静默覆盖；窄窗口、键盘焦点、减少动效和远程只读预览分别验证；Windows、macOS、Linux 的运行验收分别记录。

以上阶段按依赖推进。2026-11-01 已开始首项并落地运行身份基础：已启动运行的进展、工具、日志、插入纠正及最终答复保存宿主分配的 runId、初始 turnId 和递增消息序号；更新同一条工具结果不改变序号，排队后的新运行分配新标识。分组优先使用身份，兼容没有身份的旧消息；不同身份的续跑不会误并，已带身份的迟到事件可归回原组。文件证据保留 runId，插入纠正不使之前生成的文件失去最终答复关联。

尚未交付：各阶段耗时分解、续跑父身份、独立事件去重、异步下载完整来源传播和全部失败前置路径的身份登记。此处序号是消息追加顺序，不是网络事件序列，也不代表已经实现去重、断点恢复或持久索引。后续资源版本、接管和编辑继续依赖这些基础完善。


### 2026-11-01 补充：下载与资源入口

已实现浏览器下载在进程内的运行归属、状态变化去重、实测字节进度与延迟完成附件关联。文件落盘本身不代表下载完成；进行中的下载不能作为已完成的产物。源任务之外的后续问答不接收旧任务的下载事件。此项不等于下载断点恢复或完整的持久事件系统。

文件导航选择对话与目录，主区域呈现列表/网格、路径搜索及排序；标签页继续用于阅读。收起左侧导航保留当前管理视图，返回对话或切换对话入口才退出文件管理，避免重复重建长对话。浏览器入口显示明确的会话数、窗口数和保留状态。

输入区通过统一面板选择模型及思考等级；使用 /文件、/会话、/浏览器 或 @ 对应资源选择已有上下文，文件引用写入实际工作区路径，浏览器引用保留结构化身份。输入框按内容自动增高并限制最大高度。后续可在现有归属校验基础上增加附件管理，不通过普通文本路径扩大文件读取范围。
