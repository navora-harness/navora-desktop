# 对话批注列表与移除自动静音（2026-11-06）

本轮源码与前端／主进程构建已完成，应用版本号仍为 0.4.14。未生成包含这些改动的新安装包。用户确认另一个对话正在更新内核并要求保留，本轮没有覆盖该内核文件、改变固定校验清单或更新个人安装。

## 批注入口

按用户位置要求，在对话右上角“摘要”左侧增加批注按钮和数量。列表仅包含当前对话，按创建时间从新到旧排列；可以搜索评论、网页标题、网址及所选文字，并按待处理、待核对、已解决、已保存或未保存筛选。每页最多八条，移除记录或改变搜索后自动约束页码。

用户后续允许 HTML 实现并明确要求不能与 View 重叠。最终列表统一采用 HTML，不创建新的 NativePanel。横向使用实际消息编辑器列的边界，纵向使用主区域的可用边界；窗口、列宽和面板内容变化时重新定位。对话隐藏、锚点消失或空间不足时关闭。没有覆盖整个窗口的 scrim，也不截图替代或隐藏浏览器 View。

选择一条记录后复用既有批注卡片：可继续填写／编辑、加入输入框、查看创建时证据，详情中保留定位、解决／重开、冲突恢复和确认移除。“在对话中查看”关闭列表并定位真实卡片。评论编辑器继续使用既有原生输入组件，本次 HTML 要求适用于新增列表。

切换聊天关闭面板并清空搜索和选择。支持 Escape 返回触发按钮和面板内 Tab 遍历；列表跟随现有主题，长评论／网址受限换行，窄屏不横向溢出。

## 附加已有批注

将“已有批注”提升到“附加”菜单的“添加”分组，并保留“网页批注／网页标注”等搜索词。选择后读取当前聊天已保存的批注，显示来源并按新到旧排序，沿用现有编辑器插入位置和来源引用机制，保留批注身份与版本。

原网页已经关闭仍可引用已保存批注。未保存的目标只可继续填写，不直接成为已保存引用。选择、编辑或加入输入框均不自动发送消息；实际发送继续由用户确认。

## 声音

按用户澄清删除自动静音功能，而非重新开启：删除 `BrowserAgentAudio`、任务状态到音频的同步，以及设置页开关。任务开始、操作、等待、暂停、恢复与结束均不再改变声音。手动静音／恢复声音和标签恢复继续保存真实选择。

旧配置中的 `auto_mute` 由兼容读取层丢弃，其他光标和输入保护偏好保留；新配置不再生成该字段。历史工作区的 agent 标记仅用于迁移，防止旧的临时静音被保存为用户选择，不再触发声音操作或显示自动静音文案。
