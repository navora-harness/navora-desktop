## 1. 本轮已改正式源码

### 当前聊天内查找

已复现并修复两个独立问题：查找栏成为第四个 grid 子项，却仍使用三行布局，被消息区覆盖；窄窗口工作区浮层遮住聊天时，打开查找未使聊天可见。

现在查找栏单独占行、选项有局部叠层，打开查找先确保聊天可见。正式构建的 17 项集成回归通过，实际检查几何、鼠标命中、键入、计数与结果切换、四类入口、分栏/展开/覆盖工作区，以及原生网页 Ctrl F 的归属。详细证据和边界见[查找修复记录](./conversation-find-plan-2026-11.md#8-新反馈打开没有反应的正式修复)。

### 快捷键弹窗与启停

新的快捷键面板固定标题/关闭、检索与底部操作，只有中间列表滚动；使用分组、键帽、作用范围、空结果和主题变量。Ctrl/⌘ / 打开或关闭面板，设置页、独立文件/浏览器及原生网页焦点均有对应路径；其它模态、IME 与长按重复不误触。帮助菜单显示相同按键。

提供真实端到端启停的 4 项主窗口快捷键：新对话、搜索对话、打开对话文件、退出。设置按稳定命令 ID 自动持久化并跨窗口更新，失败不假报生效；初始读取失败可重试，读取完成前不按默认值误执行被关闭的快捷键。禁用仅影响按键，菜单仍可点击；恢复默认仅恢复这四项，不重置其它配置。

编辑器、系统与网页的固定快捷键仍有完整说明，无虚假的开关；富文本说明保留。面板自身快捷键始终可达。本轮没有实现按键重绑定，不放可点击但无功能的组合键编辑入口。

实现涉及共享命令偏好、局部设置提交、统一应用快捷键分派和原生 guest→host 桥接，不将快捷键启用与命令本身是否可用混为一谈。旧/不完整配置载入时补齐四个受保护默认叶子，避免第一次新增对象的比较提交覆盖整个 app 配置。

新增可选设置的检查还发现共享比较提交在仅存在后代“原值缺失”保护时，可能直接替换既有父对象。已补通用合并修复：后代保护仅允许递归下降，不能授权祖先原子替换；相邻叶子仍逐项校验。回归检查仅新增可选对象时保留其它窗口对相邻字段的修改、拒绝未保护相邻写入/伪造祖先替换，并在同路径已被创建时拒绝过期提交。

快捷键实际原生 UI **25/25** 通过（含自动静音设置的 3 项），见[报告](../../_planning/keyboard-shortcuts-current-native/completed.json)与[默认布局](../../_planning/keyboard-shortcuts-current-native/01-shortcuts-default.png)。另有 6 项真实 Vue 偏好状态隔离检查，覆盖首次读取失败/重试、保存失败、局部恢复与退订。433 CSS px 暗色验证通过；只在隔离测试中放宽窗口最小宽度，不改变产品窗口限制。Windows 原生转发已验证，Cmd 为渲染事件检查，不等同物理 macOS 键盘验收。

### 仅 Agent 期间自动静音

设置“浏览器 → AI 自动化”增加“AI Agent 操作时自动静音”，默认开启并沿用自动保存。旧配置缺失时补 true，明确 false 保留；不再无条件将所有新浏览器页面静音。

实际被 Agent 持有的页面在任务/短操作期间临时静音，工具之间的模型等待保持静音；结束、暂停或人工接管后恢复原偏好。仅有 AI 操作许可但没有运行的闲置页面不触发。手动静音/取消静音优先于同一任务的自动值，新任务重新建立自己的临时范围。

窗口静音状态与手动偏好分开；复制、关闭恢复及会话持久化保存手动偏好，避免把一次 Agent 临时静音永久留给手动浏览。开关热更独立于输入控制，不因关静音而释放任务保护。

7 项纯策略/配置测试通过；真实 Registry、TabsService、Controller 与 WebContents 的[24 项原生检查](../../_planning/browser-agent-audio-native.report.json)通过，覆盖任务、等待、旧任务结束、手动覆盖、热更、接管/暂停、短操作/失败、复制和持久化恢复。隐藏隔离窗口内只验证真实原生静音标志，不等同实际扬声器播放验收；未访问网站或模型。报告保留 about:blank 副本历史恢复 ERR_ABORTED 的夹具边界。

### 浏览器菜单直达设置

浏览器更多菜单新增带齿轮图标的“浏览器设置”，单独分组放在下载列表之后、窗口管理之前，打开主窗口“设置 → 浏览器”。菜单退场完成后再切换和交还焦点；独立浏览器窗口通过主进程校验来源页面及所属宿主，再唤起主窗口，不把网页迁移到新宿主。

主窗口由全局入口接收设置请求，避免从其它页面进入时只由后台聊天页监听而无法跳转。聊天页保留原对话与工作区状态；设置原有凭据离开确认仍有效，不因分类跳转丢弃秘密草稿。此项不等于已经实施下方设置来源历史、帮助关于或光标卡片的完整改造。

专项检查另确认一条设置无法离开的原因：异步设置包装只暴露 `runAction`，聊天页却直接找 `.canClose()`，导致离开检查始终拒绝。已桥接到实际设置页原有 `canClose`，保留保存等待与凭据确认；包装未就绪仍拒绝离开。此修复不改顶部返回按钮语义，也不等同完成全部来源恢复设计。

最终真实 Electron UI **34/34** 通过（原快捷键/静音 25 项 + 浏览器设置 9 项），见[完整报告](../../_planning/browser-settings-current-native/completed.json)及[菜单截图](../../_planning/browser-settings-current-native/browser-more-settings-menu.png)。实际通过键盘 Enter 激活新入口，验证分栏、展开、浏览器资源页和独立浏览器四条打开/关闭恢复路径、设置标题焦点、原生页面身份/脚本状态/未提交网页输入保留、已有模型密钥草稿取消与确认切换、无凭据时真实路由离开许可，以及主窗口在文献路由时接收独立浏览器请求。

最终界面构建为 `assets/index-CoQPPfJT.js`，Vue/Electron 类型检查和两端构建均通过。窗口使用隔离临时数据并移至屏外，网页为本地测试夹具，不调用模型或读取用户凭据。Cmd、窄屏窗口限制及实际物理键盘边界沿用上述报告说明。

最终源码再次执行完整测试 **391/391** 通过，见[最终测试日志](../../_planning/browser-settings-current-native/unit-tests.log)。临时应用已退出，测试配置目录由运行器清理；正式发行文件保持原样。
