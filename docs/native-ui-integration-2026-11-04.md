## 已接入入口

普通菜单统一使用 `Menu.popup`：应用菜单、通用动作菜单、标签右键、侧栏右键与更多、输入文本右键。现有命令与目标保留；返回选择后再次核对目标、禁用状态和上下文。菜单图标转换为随应用提供的 PNG NativeImage，支持主题和 DPI；系统菜单的外观由系统与运行时决定。

原生控件面板覆盖 Agent 控制、下载列表、地址建议、模型选择、上下文用量、回答方式、会话权限及选区格式工具。模型搜索、下载进度等更新保留控件 ID；不因一次更新重建输入控件。下载分页保留所有条目，不以截断列表丢失操作。0.3.39 按用户确认，将附加来源菜单恢复为 HTML 悬浮面板，不因 NativePanel 可用而原生化；0.3.38 中附加的原生测试记录仅作历史保留。输入区具体行为见 [输入区接入记录](./native-composer-panel-integration-2026-11-04.md)。

网站信息调用真实 `webContents.showPageInfoDialog`，网站设置事件回到“设置 > 浏览器”。不得将 HTTPS 地址本身当作证书验证结果。

网页 `WebContentsView` 设置 12 DIP 圆角，继续沿用已有布局提交与显示资格约束。未新增顶层 WebContentsView，未调整网页会话、Agent 运行身份或跨窗口转移方式。

## 统一边界与生命周期

- `native-ui` 窄 IPC 仅允许实际应用窗口的主 frame；不向网页、插件或远程 RPC 暴露原生界面能力。页相关面板校验窗口、当前活动页和文档代次，导航、切页或转移后旧动作失效。
- 锚点由 CSS 坐标按应用 zoom 转换为内容 DIP，再加内容区屏幕原点；不重复乘设备像素比。原生 Menu.popup 使用窗口内容区 DIP。主题、图标及触发器移动在打开期间同步。
- 一个窗口中的原生菜单、原生面板和 DOM 面板互斥。较新入口取消仍在准备图标的旧请求；旧关闭回调不抢回新面板焦点。
- 隐藏后复用相同原生实例；每次显示产生新的会话凭据，旧更新、隐藏和销毁请求不能作用于新显示。源页面或焦点模式改变时重建对应原生面板。
- 已迁移入口单独发出原生状态，不触发截图、页面隐藏或空布局。打开面板本身不暂停、取消、重载网页，也不构成人工接管。仅明确的 Agent 控制按钮执行相应业务。
- 不支持原生能力的平台及远程界面使用 DOM 兼容路径；已支持却运行失败时显示失败提示，保留草稿，不静默绕过目标校验。

## 明确保留的兼容界面

多行资料编辑与图片预览、链接编辑、网页批注编辑及完整悬浮侧栏仍使用既有 DOM 界面。`.5` 的 `input` 是单行控件，`icon` 是小图标，不能无损替代这些编辑与富内容界面。它们仍可能进入既有 DOM 截图兼容路径；本轮不声称所有弹出界面已完成原生化。用户主动截图、批注证据和资源预览也保留各自业务。
