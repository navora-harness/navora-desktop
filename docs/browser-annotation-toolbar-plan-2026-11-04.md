## 1. 用户确定的交互

- 取消页面下方的批注栏和高度拖动区域，不再为历史列表压缩网页高度。
- 开启批注时，将地址栏所在的整行切换为简洁批注工具行；退出后恢复原地址栏与常规网页工具。
- 开启成功即进入可点选状态，用户可以直接在网页点击添加批注，不需要再点一次“添加批注”或先选元素／区域模式。
- 工具行显示批注数量，点击后通过 NativePanel 展示批注列表；帮助文字移到提示或更多菜单，常态不铺满整行。

## 2. 现状核对

当前 `BrowserTabPanel.vue` 仍显示地址栏，并在选择时同时叠加 selectionLabel、模式状态文字及结束按钮；`notesOpen` 还控制底部 `.browser-annotations` 抽屉、调整高度、搜索筛选、草稿卡和历史卡片。用户需要先打开抽屉再点添加，入口与状态说明重复。

`BrowserAnnotationEditor.vue` 已在目标附近编辑多行评论，但它是带遮挡标记的 DOM 浮层；主页面另有 `annotationTargetImage` 铺在原生网页区域作为静态预览。迁移时应保留证据采集，退出这种背景替换路径。

底层已有连续点／拖选择、独立批注光标、临时网页操作，以及 target/version、记录 revision、草稿冲突、定位、比较、状态与加入对话等业务。新界面复用这些身份和持久化逻辑；需要补齐的是入口、工具行与原生面板映射，并核实实际内核能力。

## 3. 一行布局

批注模式建议排列：**批注 3 ▾ → 弹性留白 → 操作网页 → 更多 → 完成**。

- 数量按钮带批注图标和简短文字，点击打开列表；0 条时也可打开并显示一条空状态。按钮的展开状态与 NativePanel 实际开闭同步。
- “操作网页”切到临时浏览，再次点击或“返回批注”回到点选；为未使用空格快捷操作的用户保留直接入口。
- “更多”容纳显示／隐藏标记、草稿入口、批注帮助等低频项，不把所有功能摊在工具行上。
- “完成”退出批注模式并恢复普通地址行，不发送对话，也不删除或强制提交草稿。

维持普通地址工具行的逻辑高度、外边距、边框和按钮规格，不新增一行；切换前后网页 viewport 顶边与高度保持一致。窄宽度优先收缩留白和动作文字，保留数量、临时浏览和完成的可达性。

模式内隐藏普通地址输入、后退／前进／刷新及无关常规工具，需要导航时先完成批注。窗口／标签切换等宿主操作仍可用。工具曾 Teleport 到共享栏的场景也按当前网页身份切换，不把批注按钮串到聊天或另一页的工具栏。

常态不显示“点击目标或拖动框选／Space 临时浏览”等长句。只在等待控制交接、失败或页面变化确需处理时，给出短状态；完整说明放在提示和帮助。状态错误不把评论正文挤掉。

## 4. 点选、输入和连续添加

开启流程为：收敛当前输入操作 → 确认批注控制会话 → 换工具行 → 直接待选。选择任意可见元素，空白位置按点位处理；拖动继续使用区域选择，同一个入口完成，不增加两个常驻模式按钮。

选取只选择目标，不激活网页链接、按钮或表单。真实 View 使用独立批注指针，与 AI 自动化虚拟光标及设置中的三款样式分开。点选目标使用细描边，编辑时显示当前目标，连续添加时可显示简短编号；历史标记可在更多菜单关闭。

目标旁的评论编辑也采用 NativePanel，常态只保留输入、保存和收起动作；不在底部重开编辑栏。Enter 换行，Ctrl/⌘ Enter 保存；中文组合输入优先确认候选。提示以 placeholder／快捷键提示提供，不常驻显示大段操作说明。

- 保存成功后回到待选，可继续点下一处，批注模式不退出。
- 未写意见的临时目标不生成空历史记录；保存失败保留目标和文字，数量不增加。
- 收起编辑器、打开列表、切目标时先保留草稿；新目标不能覆盖旧草稿。查看／恢复草稿放进列表，工具行不堆草稿提示卡。
- 编辑器保存已有批注使用 revision 校验；冲突保留副本，不以最后一次回包覆盖当前输入。
- 取证截图与目标身份、文档代次、位置一致才可提交；失败可重试，不把静态截图铺满实时网页。

## 5. 数量与 NativePanel 列表

### 5.1 数量定义

工具行数字为当前网页标签 `pageId` 下已保存、未删除的批注数量，沿用当前归属，不受列表搜索或状态筛选影响。已解决记录仍是批注，计入数量；未保存的临时目标、编辑缓冲和冲突副本不计入。

默认列表范围同样为当前页面；可在面板内部切到“当前对话”，标题展示该范围实际数量，不把全部对话的数量写回工具行。页面导航后旧记录继续保留并核对来源，不能把旧锚点当成新文档中的有效目标；不同标签和对话不混计，即使它们使用公共浏览器会话。

新增、删除只在主进程确认后更新数量。面板关闭不清零，跨窗口更新以权威记录重算，不仅依靠前端加减。

### 5.2 列表与动作

面板锚定数量按钮，在窗口内尽量展开、超出时按屏幕工作区避让；内容长时内部滚动，不推动网页和工具行。建议宽约 340–400 CSS px，最终按应用缩放、DPI 和窄窗口验证确定。

列表以评论首行和编号为主，必要时显示简短来源／状态；完整 URL、创建时信息、冲突说明和证据详情按需展开。顶部保留搜索，状态筛选和排序收进筛选入口，默认最近添加优先。零记录、无搜索结果、加载失败分别只给一条对应提示。

点击条目进入同一套原生详情／编辑视图，可返回原搜索和滚动位置。常用动作是编辑、定位、加入对话；标记解决／重新打开、比较来源和删除放更多菜单。支持选择多条后“加入所选”，第一批若批量链路未完成只保留单条入口，不摆无效按钮。

“加入对话”插入带 annotationId／annotationRevision 的现有引用，先交给用户编辑，再由用户发送；不自动调用 Agent。批量加入保持选择顺序并去重，不悄悄切换引用版本。独立浏览器窗口加入对话时唤起正确对话，保留批注草稿。

定位先核对来源与锚点；失效时简短说明“原位置已变化”，可查看创建时证据，不随意跳到相似元素。删除当前记录沿既有证据保留规则，已引用修订的历史证据继续可读；保存／删除失败保留重试入口。

列表关闭仅关闭列表，不退出批注模式。打开记录编辑时复用同一批注面板或在协调器中明确切换，避免列表、编辑器和多个评论框彼此争焦点。更多菜单与原生面板按父子关系处理，不能误判成外部点击而丢草稿。

## 6. 临时浏览、退出与控制权

“操作网页”是显式临时浏览状态，此时恢复网页交互，工具行改为“返回批注”，不再落下新目标；返回后恢复独立批注指针。已有 Space 临时操作保留为辅助快捷键，仅在 guest 待选状态且不处于输入控件／IME 中生效，帮助说明不常驻。

按 Esc 时先处理中文候选，再收起编辑器并保留草稿／关闭列表，最后在待选态退出模式。临时浏览的失焦、漏 keyup 和切标签有明确收敛，避免永久穿透或拦截。

同一页面批注期间保持对应的人工批注会话，不在每次保存后自动交还 AI。完成退出遵循原控制令牌与任务状态；已经结束、暂停或更换的 run 不被旧退出回调恢复。进入等待和取消可幂等执行，失败不能同时允许 Agent 与用户写同页。

切标签时关闭所属原生面板并保留草稿；不让该页的批注工具行跟到另一页。回到原页经有效会话确认再恢复。导航、刷新、崩溃或页面关闭会作废待选目标并处理草稿；不沿用旧文档的坐标。主窗口／独立窗口转移期间先收敛批注会话，避免旧面板留在原宿主。

## 7. 原生承载与新定制版依赖

地址行在原 renderer 中切换，网页仍是现有 WebContentsView；列表、目标编辑和相关详情由 NativePanel 承载。不增加覆盖用 WebContentsView，不为打开列表／输入意见调用背景 preview、frozenFrame 或隐藏实时网页。业务取证可以继续截图，但与展示背景分开。

主进程验证窗口、chatId、pageId、批注会话、文档代次及请求代次，拒绝旧页／旧面板动作。屏幕 DIP 锚点从实际工具行和目标几何换算，跟随窗口、滚动、缩放和 DPI，不重复乘系统倍率。展示与移动面板不改变 guest viewport。

列表基础布局可复用已有 NativePanel 控件，升级的关键依赖为：

1. **原生多行编辑**：长度限制、文本和选区、连续 change、Enter 换行、修饰键保存、中文组合输入、Esc 分层；更新状态不重建输入框或覆盖在输入文字。
2. **输入与关闭可靠性**：焦点恢复、宿主／面板归属、与原生菜单及 IME 候选窗的协调、外部点击关闭语义；确认关闭不会把同一次点击送入网页触发业务操作。
3. **就地更新与事件身份**：稳定节点 ID、更新保留搜索和滚动／选择、关闭及重新显示的代次；防止迟到保存／列表动作作用于另一目标。
4. **证据预览的受限能力**：需要在详情内预览时使用明确的原生图片接口；icon 不冒充大图。图片查看能力单独核验，不要求常态列表必须带缩略图，也不拿整页截图充当实时背景。

以上是能力要求，不假定新版本的字段名、版本号或已经发布。新定制包到位后核对匹配类型、公开文档与运行时功能查询，再完成接入与真实窗口验证；缺少必需能力时不宣称新模式已支持，不为了提前上线新增截图替代路线。

`.6` 公开查询只有 NativePanel.isSupported()；以上“功能查询”由应用依据发布类型及隔离探针登记，不代表可调用内核 getCapabilities。相同 ID/type 更新时，列表／状态刷新不携带旧输入 value，避免组合结束覆盖新文字。当前外部点击 hook 不消费事件，关闭不误触网页是待补要求，不是已有保证；原生 Menu 与编辑面板的父子归属也不能仅靠应用延迟 hide 来替代。

## 8. 应用侧迁移顺序

1. 定稿工具行状态、数量范围、列表／编辑动作及统一批注会话；保留已有草稿、版本与证据格式。
2. 新定制 Electron 发布后先验证多行输入、IME、关闭命中与焦点，再接窗口级可复用的批注 NativePanel。
3. 接地址行替换、开启直接待选、列表与目标编辑；删除底部批注栏、调整高度状态和旧入口，不只是用 CSS 隐藏仍在运行的抽屉。
4. 退出 annotationTargetImage 作为网页背景以及相关 DOM 编辑遮挡路径；证据采集和旧修订读取照常保留，打开原生面板保持实时页面。
5. 覆盖工作区、展开工作区和独立窗口，完成回归并更新实际进度；发布仍遵循全部弹层截图替换清理完成的既定条件。

## 9. 验收

- 开启后地址整行直接成为简洁批注栏，可立即点击／拖选；下方不出现抽屉，进入、退出和列表开关不改变网页尺寸。
- 数量范围准确，0／新增／失败／删除／筛选／跨窗口变化都一致；NativePanel 的长列表、搜索、键盘和焦点可用。
- 原生多行、中文输入、保存／取消、连续添加、切目标、重复提交及冲突恢复不丢字、不产生空历史、不误触网页。
- 进入／结束、临时浏览、Space／Esc、切标签、导航、关闭和移窗保持正确控制权及页面身份。
- 加入对话使用实际修订，旧证据和草稿可恢复；位置失效时不误定位。
- 实时视频或动画保持推进，打开列表／编辑时截图替换计数为零；业务取证独立统计。多 DPI、缩放、窗口边缘、独立窗口与物理输入／IME 分别做真实验收。

本轮仅记录和完善规划，未修改源码、现有用户批注或运行窗口；等待新定制版 Electron 后实施。
