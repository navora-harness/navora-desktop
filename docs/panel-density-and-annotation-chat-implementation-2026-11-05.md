# 面板密度、对话批注与右键直接批注

日期：2026-11-05。用户确认的本轮范围已接入源码；基于当前 0.4.12 工作区继续修改，尚未重新生成安装版／便携版，不将本轮增量算入既有 0.4.12 成品。

## 范围与跳过项

用户要求只完成面板密度前四项，取消 NP 持焦 F3／F11、Ctrl+F／Ctrl+K、Shift+Enter 的转发规划。局部查找位置、既有宿主快捷键和批注输入的字体测量／随内容增高已有实现，本轮沿用。没有修改或安装定制 Electron。

独立批注列表及数量入口按用户要求删除；旧批注详情的固定高度和两排按钮布局随之退出生产入口，不再另做列表优化。原生批注输入面板保留，历史批注、草稿、冲突副本、证据及修订身份继续使用现有持久化格式。

## 当前行为

- 对话搜索、引用来源、工作区文件选择：空列表不分配固定结果区，少量结果按内容收缩，超过上限后滚动。实际原生内容树的宽度、文字预算和结果高度随窗口可用区域变化；搜索标题／时间同排，摘要一行。聊天搜索长列表从原 380 缩到最高 240 CSS px，并受可用内容高度 45% 约束；空／单项继续按内容缩短，不再保留大块固定空白。
- 引用来源：标题优先显示，网站名／域名避免重复，摘要至多两行，完整网址保留在提示和点击动作中；分页和来源身份保持。
- 文件选择：刷新、整表失败及部分目录失败共用一个主要重试入口；状态集中展示，部分成功的文件保留可用。
- 通用技能／插件／商店弹窗：表头、底栏、文字、边框、关闭按钮沿用现有主题变量。安装确认默认只展示名称、版本和两行简介；“安装详情”展开完整简介、来源路径、标识、大小和套件。覆盖安装、套件替换及阻断警告常驻。
- 批注：保存后直接在所属对话中显示网页批注卡片；草稿也在对话中提供继续编辑入口。卡片沿创建时间插入现有记录的展示序列，不伪造用户消息、不触发 Agent、不自动写入输入框。显式“加入输入框”才建立批注引用，原页面已关闭时仍可加入已保存的证据引用。
- 卡片提供编辑、证据查看，详情内保留定位、状态、删除确认、未保存修改与冲突副本恢复。关闭原页面后，目标草稿仍能列出并丢弃；恢复原生位置编辑仍需要原页面存在，失败时保留文字和证据。
- 网页元素右键：显示“批注”，直接核对并使用右键命中的目标，捕获证据后打开原生填写面板，不进入等待第二次点击的模式、不合成网页业务点击；单次编辑结束后释放批注会话。工具栏原有连续点选／拖选入口保留。

编辑请求会保留至所属网页组件就绪，切换对话时取消，避免首次展开工作区时丢失点击。连续保存期间的迟到取证回执按会话和目标身份拒绝，不将上一条回执写回新目标，也不把当前状态误改为失效。

主要实现：`shared/native-dialog-panels.ts`、`NativePanelDialog.vue`、`SkillDialogShell.vue`、`PluginImportDialog.vue`、`browser-page-context-menu.ts`、`browser-annotations.ts`、`BrowserTabPanel.vue`、`BrowserAnnotationChatCard.vue`、`useChatAnnotations.ts` 和 `browser-annotation-chat.ts`。`BrowserAnnotationsPanel.vue` 已移除。

## 与其它规划的边界

“直接目标批注”在面板专题与网页右键专题中指同一项，本次合并完成，不重复留为待办。菜单关闭后会复核宿主、页面、文档、控制状态、真实保留节点、矩形和视口；目标变化时拒绝旧动作并释放会话。

同源／跨域子 frame 右键只能在可靠情况下批注外层框架容器（`embedded-container`），不表示已取得内部元素的可信凭据。**子 frame 内部可信命中／编辑、beforeunload 内核与宿主完整链路仍未完成**，本次没有扩大这些能力。跨平台／混合 DPI、真实物理输入／中文候选仍按既有实机验收边界保留。
