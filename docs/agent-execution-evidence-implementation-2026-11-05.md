# Agent 历史执行事实修复实现记录

日期：2026-11-05。源码已实施，尚未打包。对应 `agent-evidence-and-page-blocker-repair-plan-2026-11-05.md` 第 3 节；网页阻断检测和控制交接由同轮的独立实现负责。

## 已实现的数据流

- `shared/agent-execution-evidence.ts` 定义 V1 运行摘要与单工具事实。保留宿主运行、任务轮、消息和工具回执引用；工具派发、字段回读、页面变化与业务完成独立计数。任意 evaluate 只记脚本完成，不能由其返回文本宣称业务成功。未知业务确认计数使用 `unknown`。
- `runTool()` 在完整结果压缩前生成脱敏片段，随原工具消息持久化；策略和历史使用同一归一化口径。`agent_run_start/end` 保存身份和最终摘要。插入指令沿用运行 ID，后续片段记录插入消息的任务轮 ID；问卷和持久确认继续记录原运行引用。
- `agent-evidence-history.ts` 在全部持久化消息上选择最多三个相关运行，再构造对话历史。快速问答、完整 Agent、总结轮、内容过滤后安全重试均附当前运行和历史运行的独立事实，当前零不能否定前轮非零。
- 每运行最多保留八个详细证据用于模型上下文；历史默认 4,000 token、当前默认 1,500 token，并随模型上下文缩减。压缩先减条目，保留计数、停止原因、错误码、未决状态与消息引用。最小摘要也无法容纳时明确报 `history_evidence_unavailable:context_budget`，不悄悄删证据。
- 旧数据优先采用旧结束摘要，缺失时按实际工具回执保守重建；旧 actions 指标不当作物理输入次数。缺运行身份时按连续用户边界分组；重复回执去重，未结算工具及无结束记录的运行标记中断。读取不会就地改写旧聊天。
- 新增诊断只采纳枚举、布尔、计数和本地 ID，丢弃字段正文、URL、查询参数、token 和堆栈。未细分的 operation invalidated 原因保持 unknown。页面阻断事实也按白名单进入最终和历史摘要。
- 键盘效果采用逐事件 `not_observed/confirmed/contradicted/unavailable`；由浏览器宿主固定只读前后回读提供。没有独立证据不会把 Tab/Ctrl+A 说成失败，也不会由后续指定目标输入倒推出它们成功。
- 必须本人处理的页面建立只含引用的 ResumeCheckpoint，结束原因为 `waiting_for_user`。只有用户明确继续才新建链接原运行的任务，沿用原任务授权和约束，先新观察，再做剩余步骤；检查点不保存或回放 Flow/工具队列。一次检查点只能被认领一次；明确停止持久取消，关闭的页面不能恢复。控制器单纯恢复不会创建聊天运行。
- 运行仍有等待检查点时，无页面归属的下载／会话请求以 `page_blocker_scope_required` 拒绝，不能用请求替代受阻步骤；显式未受阻页面继续正常准入。恢复的新运行在新鲜页面回执之前也保留此约束。关闭等待页面后泛化“继续”不会启动模型或新建页面。
- 菜单停止 API 可携带捕获的 `expectedRunId`，主进程在暂停队列、取消确认和停止任务之前同步核验，过期菜单不会停止新运行；旧调用保持可用。
- ChatStore 保持原有合并写入节奏，改为先完整写临时 JSON 再替换，避免写到一半损坏上一份聊天；未将高频运行摘要复制到独立数据库。

## 验证及边界

新增协议/历史测试、实际本地 HTTP 假模型请求测试，并回归运行策略、问卷恢复、草稿和子对话持久化。测试数据均为合成内容，不读取个人账号或重放真实网页操作。验证包括前轮非零与本轮零、auto/chat/full 共用事实、部分成功和失效错误、安全摘要重试、超过 30 条历史、预算不足、未知版本、重复回执、运行中断后的实际 ChatStore 重开、插入指令归属和页面验证历史。

业务成功保持未自动推断；Flow 聚合回执若未提供可独立计数的原生子动作，则输入次数保留 unknown。旧的字段值只代表当时，不证明当前页面状态；本次恢复事实不会复用旧输入租约或重新执行动作。
