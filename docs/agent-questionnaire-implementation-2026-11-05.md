# Agent 问卷与文件路径提示实施

日期：2026-11-05。首版已纳入 0.4.8 Windows x64 [安装版](../release/v0.4.8/Navora-0.4.8-Setup.exe)和[便携版](../release/v0.4.8/Navora-0.4.8-Portable.exe)。版本、锁文件和成品信息一致，源码／运行时及两包内嵌文件已核对，成品隔离启动并正常退出。旧 0.4.7 制品保留原交付范围。

## 问卷填写与工作区

新增 `agent_ask_form` 工具。Agent 提供结构化问题，由应用统一渲染为工作区表单。支持短文本、长文本、单选、多选、开关和数字，以及自填答案、题目备注、整体补充和允许的不确定、跳过、交由 Agent 决定等状态。推荐项不会自动算作用户回答，开关未选择、关闭和数字零分别保存。

全应用同时只有一个“问卷”标签。重复打开会激活已有入口，不同聊天的问卷在同一标签中切换，草稿按问卷归属独立保留。标签不能拖出或在独立窗口复制；恢复工作区时会去重。后台问卷只提醒，不替换正在填写的内容。

0.4.9 追加标题规则：有标题时标签显示“问卷: 标题”，空标题显示“问卷”；切换和恢复问卷时同步标题，后台记录更新不激活标签。历史保存的“问卷”标签不会被当作正文标题重复拼接。0.4.9 已打包核验；旧 0.4.8 制品及截图保留原标签样式。

表单采用当前软件主题变量，连续单列排版，正文宽度与输入区协调，底部保留保存状态和提交动作。浅色、暗色、窄窗口及主题切换保留填写内容。聊天保留待答入口、侧栏提醒及问卷记录；子任务也能打开对应问卷。

## 草稿和提交

草稿沿用对话编辑框的保存与恢复语义：输入后自动保存，切换、关闭前刷入修改，重启恢复已持久化的内容。前端本地缓存用于保留尚未同步的输入，主进程按问卷独立写入磁盘。草稿和对话编辑框互不覆盖。

保存采用版本校验，乱序回执不能覆盖新输入；冲突保留两份内容并支持恢复。保存失败保留输入，切换问卷时要求先完成保存或处理冲突。提交前保存不可变答案快照，确认接收后再继续任务；同一提交重试不会重复接收。

“切回聊天讨论”先定位聊天编辑器，用户真正发送消息时，宿主先持久接收消息，再结束表单等待。关闭标签只收起页面；取消问卷、停止任务和删除聊天分别处理归属与失效状态。

重启恢复基于会话历史和已保存任务约束继续运行。问卷提交后保留继续运行状态，处理退出中断和多个恢复请求的调度；原进程执行栈不会跨进程恢复。

## 文件完整路径提示

聊天正文中的文件链接、图片替代链接、内嵌图片以及回答下的输出文件卡片，悬停时显示完整绝对路径。路径使用文件所属聊天的真实工作区根目录，跨聊天输出分别解析；工作区根目录更新时同步刷新。点击打开、文件菜单及工作区内的相对路径协议保持原行为。

## 验证范围

验证使用隔离数据和本地模型响应夹具，不读取日常对话、不调用外部模型。

- 类型检查、前端和主进程构建。
- 问卷协议、草稿版本、冲突副本、提交快照、写失败、取消删除及接收顺序的单元检查。
- Agent 运行时的问卷等待与提交、待答重启、提交后中断恢复、取消及停止场景。
- 真实 Vue 和 Electron 组件检查：基础题型、自填与特殊态、草稿恢复、失败重试、乱序保存、主题、窄窗和文件悬停路径。
- 完整主应用使用同一隔离配置启动两次，检查跨聊天唯一标签、关闭重开、磁盘草稿及新进程恢复。
