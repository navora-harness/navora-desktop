## 正式源码变化

- 子对话：保留父对话身份，在一个稳定的子对话工作区标签内切换列表和详情；左侧主列表不再渲染子树。名称和稳定本地 SVG 图案进入真实详情，询问、权限、草稿、停止、重试、模型和文件分别归属子对话。轻量索引不加载全部正文，迟到快照不能覆盖流式更新。已读按实际可见消息版本记录，打开列表不等于读完详情。
- 资源归属：子对话文件和网页可在父工作区显示，原资源 owner 不改写；网页操作、关闭、重排及宿主转移使用实际资源 owner。子对话标签不是伪造文件路径，不进入文件拖出 IPC。工作区元数据迁移为 version 2，兼容原文件标签记录，不储存正文和凭据。
- 输出：按原消息顺序交错呈现正文、工具活动与子任务入口，移除主聊天的 run 大卡片；保留安全 Markdown、原消息锚点、资源和错误。详情按需展开，长工具输出分页／窗口化，复制保留完整原文，查找可以显示后半段命中。未知状态不冒充成功或用户终止，最终回复末尾统一显示回复操作。
- 查找：父、子组件分别命名自己的 CSS Highlight，失活只清理自己的高亮；恢复查询不抢焦点。资源回消息、待处理请求和父委派位置均定位到实际所属对话。
- 工作区：内容预算低于聊天 480 + 工作区 400 + 边界 1 CSS px 时自动展开；手动展开与自动原因分开。拖动越界在松开后提交，支持展开工作区或聊天，取消不持久化预览。恢复采用 80px 迟滞与 250ms 稳定时间，并延后编辑、输入法及弹层期间的非必要恢复。分栏比例单独保存。
- 侧栏：单一列表实例支持固定占位和悬浮覆盖，显隐与展示偏好独立；标题栏按钮恢复上次有效列表，悬浮可点外部／Esc 关闭，固定状态不会被外部点击关闭。设置和创建器使用固定分类导航，返回后保留原展示偏好。侧栏原生滚动槽留在行背景之外，资源内层不再叠加滚动。
- 设置：统一受控入口和有文字的返回按钮，齿轮可返回，Alt Left 仅在合适上下文处理；保留真实内容实例、草稿、工作区、焦点和阅读位置。等待保存、超时、失败和凭据放弃都有对应反馈。帮助关于统一进入设置关于，独立窗口入口校验来源与宿主；光标选择使用与主题一致的真实几何预览卡片。
- 浏览器几何：布局 owner、宿主与页面代次共同校验；新页面先保持隐藏且无可见原点矩形，有有效几何才显示。忙碌期间只保留最新布局并在原生输入边界结束后提交，过期 owner 不能隐藏或复活页面。CSS 像素只按界面缩放转换为原生 DIP，不重复乘设备像素比。
- 标签、工具行及批注：由对应专项模块接入，具体几何、原生输入、目标草稿及保存验收随最终报告记录；不能以旧样板替代正式窗口验证。
