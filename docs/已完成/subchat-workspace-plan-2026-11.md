## 1. 目标与现状

主对话仍是任务及资源的组织入口。左侧对话列表只显示主对话，不再展开子对话树；子对话通过父聊天中的名称、任务汇总和待处理提示进入，在父对话所属工作区查看。

现有真实能力可以复用，不另造一套子任务数据：

- `shared/types.ts` 的 ChatSession 已有 kind、parentChatId、parentToolCallId、spawnPurpose、spawnStatus。
- `electron/modules/agent-runtime.ts` 已有创建、等待、状态查询和父任务通知。当前仅支持一层子对话，默认每父对话最多同时运行 4 个，可配置为 1–8 个。
- `src/pages/ChatPage.vue` 已有两处消息内子任务名称入口，但目前调用 selectChat，改变全局 activeId，并加载子对话草稿及重置视图；不能直接沿用来实现工作区详情。
- 子对话目前可以继续交流，不能在重排界面时无说明地删除这一能力。

本轮新增主流程不提供虚假的“新建子对话”。第一阶段使用既有真实创建工具；手动创建若后续加入，必须调用同一创建服务、并行限制和权限校验。

## 2. 三种入口、一个工作区标签

每个父对话只有一个稳定的“子对话”工作区标签，内部包含列表与详情。标签键按父 ID 生成，重复点击复用；不同子任务切换不堆出一排重复标签。

1. 父聊天中的“图案 + 子对话名称 + 状态”为可点击入口，直接进入对应详情。相同子任务可以在多个消息位置出现，仍指向同一对象。
2. 父聊天工具区或任务汇总中的“子对话 · N”打开列表。待处理数量单独表达；N 是实际子对话去重数，不按消息链接数量累加。
3. 待确认卡、资源所有者、引用定位、浏览器呈现和历史链接统一经过会话目标路由。同父打开详情；跨父先进入所属父对话，再打开对应详情。

单击不会安装插件、启动新任务或停止已有任务。父对话保持左栏选中，模型、权限选择、草稿、引用和阅读位置保持各自状态。主聊天 DOM 与编辑器仅保留一份，不在详情中嵌套整个 ChatPage。

## 3. 列表和详情

### 列表

- 顶部显示标题、总数、名称/任务说明搜索及状态筛选；固定头部，列表独立原生滚动。
- 默认分组为“需要处理 / 进行中 / 已完成 / 未完成”。需要处理包含等待用户答复或权限；失败和已停止保留不同文字及图形。
- 每行依次为稳定图案、名称、最新简短进展、状态和时间。长名称省略并保留完整 title，不把大段模型输出塞进列表。
- 有可靠运行记录才显示耗时；历史数据只有更新时间时显示“更新于…”，不拿 updatedAt 冒充运行开始时间。
- 区分尚无子对话、筛选无结果、加载中、读取失败和已删除；失败提供重试，空列表说明可以从聊天中委派任务。

### 详情

- 顶部“返回子对话列表”、稳定图案、最新名称、状态；可定位父聊天最初委派位置。
- 正文复用消息、工具和错误呈现，任务说明可折叠；任务过程与结果可查。只给当前子对话处理询问、权限、停止与重试。
- 保留明确的“继续交流/发送补充”入口。运行中补充沿用现有插入或排队规则；发送、模型配置、草稿和重试快照归属实际子会话。
- 返回列表还原搜索、筛选、展开项和滚动；重新进入同一详情还原其阅读位置。查看旧消息时收到流式输出不强制滚到底。
- 标签关闭仅隐藏视图。停止当前子任务、停止父任务及全部子任务、删除记录是不同操作，不能用一个“关闭”混淆。

## 4. 与展开工作区的关系

分栏时父聊天在左、子对话标签在右工作区。展开时父聊天固定为首标签，子对话、文件、网页使用统一 36px 标签几何和现有 48px 标签行；标题省略、图标、关闭热区与焦点规则一致。

查找、更多、摘要和停止等工具位于标签栏右侧、工作区控件分隔线左侧，根据当前标签确定对象。子详情的 Ctrl/⌘ F、F3、更多和停止必须作用于子会话；父任务整体停止另有明确名称。

父聊天标签拖离仍恢复分栏，不创建新聊天窗口。子对话汇总标签第一阶段只支持关闭、返回列表、定位父聊天和条内排序；不冒用文件拖出 IPC 创建独立文件窗口。独立子对话窗口属于后续能力。

切到子详情时撤销原生网页显示资格，切回网页后由正确宿主和已应用边界恢复；网页不得覆盖子详情或标题栏。先解决[原生视图错位回归](./browser-view-origin-regression-plan-2026-11.md)，再整合新标签类型。

## 5. 万花筒图案

使用代码生成的本地 SVG，沿用 frontend-design 约束和现有 Fluent 操作图标。图案是子对话身份，操作仍使用通用图标，不混用花形表示停止、删除或权限。

- 使用种子程序化生成大量不同的万花筒，不限于花瓣、风车、晶体几张成品。由子对话 ID 与算法版本初始化确定性随机序列，分别派生对称瓣数、曲线／切面轮廓、长宽比例、收腰、偏转、内外层组合、中心形状和多色配色；轮廓本身也必须变化，不能只更换颜色。
- 2026-11-04 已实现 v2 生成器：4–10 瓣外层、独立内层结构、连续几何参数、可选折面及圆形／多边形／星形中心，色相、色差、饱和度和明度共同生成配色。曲线与切面为组合构件，不是固定成品池；使用本地 SVG，不依赖图片库、网络或外部资源。
- 同一算法版本下身份保持稳定；刷新、改名、切主题和列表重排不重新随机。本次 v1 → v2 升级会统一更新现有图案一次，之后相同 ID 在各处继续一致。
- 同一 ID 在消息、列表和详情中显示同图案；不按每次渲染 Math.random，避免找不到刚才的任务。
- 浅、暖、深主题使用可辨描边和背景；状态始终有独立文字/形状，不依赖颜色或图案识别。
- 默认静止；运行状态可用独立状态指示，不持续旋转花形。减少动态时不播放装饰动画。
- 图案有可见名称作邻接文本时 aria-hidden；无文本入口必须有完整可访问名称。

## 6. 会话状态与事件隔离

把“当前选中的主对话”和“工作区正在展示的子会话”分开。新增按 chatId 管理的会话缓存与读取状态；父、子同时流式更新时按真实 chatId 归并，不能把子消息写入 active.messages。

- 加载详情携带请求代次和消息版本；迟到响应不能覆盖新选中的子对话或后来的流式内容。
- 当前 phase、草稿、查找、展开消息、阅读位置、错误和编辑状态按会话隔离；全局监听只注册一次。
- 父与直接子现有共享权限队列继续复用。提交答复带原始 requestId、chatId；父卡与子详情共享请求状态，不能重复确认。
- 子任务需要处理时更新父聚合提示，不自动切标签或抢编辑焦点。打开汇总页不等于读完全部子对话；只有实际可见详情的已读消息版本才被记账。
- 父资源汇总继续去重，资源 owner 仍是实际子会话。打开子文件或子浏览器不会为了呈现资源而调用全局 selectChat(child)。

全部旧入口统一调用 routeConversationTarget：消息中的两种子任务按钮、父运行摘要、待处理询问、资源所有者、引用定位、浏览器 onPresent 和重启恢复。不能只修可见的一个按钮。

## 7. 运行契约需要一并补齐

以下为源码审计发现的实施前置项，尚未修改或验证为新功能：

1. **任务结果与后续交流分离。** 目前 finalizeSubchat 只记录首次终态；之后继续交流/重试不会更新父原卡。保留首次委派的结果记录，同时为后续运行保存独立 run/attempt 与当前状态，不能让旧“已完成”掩盖新的运行。
2. **恢复中断运行。** 当前并行计数会看 persisted spawnStatus=running，未找到启动时统一核对。增加 interrupted/recovered 处理，崩溃后不能永久占用并行名额，也不能伪报成功。
3. **统一配额。** 自动 spawn 与通用 agent.run/retry 入口对子任务的限制不完全一致；继续交流、重试、未来手动创建采用同一父任务配额和取消语义。
4. **时间真实。** 新运行保存 runId、startedAt、finishedAt、终态原因，旧数据允许缺失。等待用户不是完成，终态和当前待处理分别记录。
5. **继承语义明确。** 创建时权限、服务商和模型为快照，非父设置实时绑定；当前 reasoningLevel/executionMode 没有完整复制，应确定显式继承并测试。任务说明与上下文有长度限制，不自动复制全部父历史或秘密。
6. **资源生命周期明确。** 默认文件工作区独立；显式共享与浏览器资源 owner 按既有规则处理。完成/失败/停止后资源可保留。停止父任务会停止运行中的子任务；停止某个子任务不影响兄弟。删除记录与删除工作文件分别说明，不暗中删除文件。

列表宜新增轻量 subchats.list(parentId) 索引，包含标题、当前状态、待处理、运行身份、真实时间、摘要、资源数和修订。正文按需 chats.get；避免每次筛选拉回所有子对话完整消息。

## 11. 正式接入与验收更新（2026-11-03）

本轮已接入正式源码：每父对话一个显式 `kind=subchats` 标签，列表和详情直接读取真实子会话；父聊天保持选中。消息内名称、列表、待处理和资源定位复用父工作区。子详情复用正文、工具活动行、真实输出文件和编辑器，不嵌套 `ChatPage`。任务说明默认折叠，继续交流的模型、权限、队列、草稿及请求 ID 归属实际子会话。附加菜单在整段编辑器上方左对齐，支持原生键盘导航；发送按钮使用正式主题的 `--navora-ink` 颜色。

运行层已补独立 attempt、真实时间、创建时继承快照、崩溃中断恢复和统一配额。首次委派回执保留，后续失败不再借用旧成功答案作为本次摘要。重启后没有活跃 promise 的持久询问仍可从子详情停止，取消同时清理磁盘状态和待处理提示。

会话缓存按真实 chatId 分流，正文缓存有上限；读位、展开、查找和草稿独立。父子查找使用不同 CSS Highlight 名称，隐藏实例不抢焦点或清掉另一实例的结果；长工具输出按真实偏移展示命中窗口并可前后分页。打开列表不标读，只有实际可见且读到最新的子详情确认当前消息版本。

父工作区呈现子文件和子网页时仍保留资源的真实 owner。浏览器快照按“工作区查看者 + 资源所有者”分别记录版本；只替换明确覆盖的 owner。根对话的局部树不能清除子页，缺席或空 owner 需读取其真实版本快照。固定和普通标签分别合并，保留其它 owner 与未解析标签的位置；同一待恢复固定标签不会被重复加入。
