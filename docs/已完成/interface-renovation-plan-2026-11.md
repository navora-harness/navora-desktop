## 2. 统一体验约束

1. **一个位置表达一种状态。** 复合输入只由外层容器显示焦点，内部文字区不重复描边；按钮、菜单、开关保留可见的键盘焦点。普通输入本体仍可承担焦点。
2. **一个动作具有明确结果。** 附加资料不会自动安装或执行插件；浏览资源不会意外写入草稿；关闭页面不等于清除会话数据；折叠高级设置不等于恢复默认值。
3. **已保存与已生效分别表达。** 设置界面显示本项保存、校验、失败及生效范围，不用全局“已保存”掩盖某项未成功；路径与服务连接等局部草稿需要具名提交。
4. **空状态提供下一步。** 没有页面、已保存但无页面的会话、未加载、搜索无结果和读取失败分别呈现。没有文件时不保留大块空文件卡。
5. **保持真实对象。** 对话、编辑器与网页只保留一个真实实例；切换只是改变视图和宿主呈现。源身份、修订、文档版本和异步代次需要跨菜单与窗口验证。
6. **视觉使用同一套规则。** 延续冷蓝灰、系统 UI 字体和项目 Fluent Regular 图标。行高、控件高度、禁用与错误状态集中归口，避免通过不断叠加全局 CSS 修补单点问题。

## 3. 实施优先级与依赖

### 0. 先恢复回归并形成基线

优先处理 AI 页面输入保护在工具间断开的控制期问题、浏览器浮层白屏、输入区与搜索框重复焦点、开关几何异常。先补可复现的隔离验证，再小范围修复；保留页面、表单和会话数据。鼠标移入不视为接管，宿主中的暂停／人工接管始终可达。浏览器截图无响应时仍须提供可操作的恢复控件，不能仅撤回非阻塞保护而引入无限等待。

### 1. 建立共用控件与设置提交基础

确定复合输入的焦点归属、开关和表单几何；建立字段／业务组的设置提交、修订合并与失败反馈。先迁移简单自动设置，再迁移路径、连接、密钥、权限和运行时重配置。最后移除所有旧的全局“应用”入口，避免删掉按钮后产生无法提交的设置。

### 2. 重构附加与编辑文档

先接菜单与现有来源／创建器，再增加句内引用及文档迁移。行内引用需要贯穿草稿、复制粘贴、队列、快照与发送，不单独维护一份附件数组。

格式与附加候选按可用视口限制高度、内部滚动；先统一浮层滚动与快捷键分派，再交付当前聊天内查找，避免同时抢到网页 Ctrl F 或 Escape。

### 3. 工作区与浏览器资源共同整理

统一对话／文件／网页的视图层标签状态和工作区展开逻辑；同时调整资源树导航与菜单。底层页面顺序、宿主归属与关闭恢复继续使用现有权威服务。

### 4. 渐进整理高级能力

模型基础连接与默认值优先可理解；高级参数折叠但非默认值和错误可见。技能／插件资料、跨对话摘要、会话改名等按新增契约逐类交付，不用假入口充满界面。

上述批次可以在独立模块上并行开发，但应按依赖逐批验收，不一次替换编辑文档、设置存储和原生网页挂载三条高影响链路。

## 6. 补充审阅发现的四项优化

这些是跨模块规划尚需补齐的契约，不能视作已经复现的生产故障。已分别写回输入区与工作区详细规划，保留当前修复优先顺序。

1. **P1：切模型与发送同步确认。** 模型／回答方式保存中不能以旧界面选择提交新配置；文档和已确认会话配置一起冻结。队列按入队身份固定非秘密配置，执行前复核失效或修订，权限仍采用当时有效授权。验收切换同时按 Enter、跨窗改端点、模型删除和失败重试。
2. **P1：统一标签栏的键盘规则落定。** 单一 Tab 停靠点、方向键与首尾跳转、三种内容的统一索引、原生网页快捷键分派，以及关闭后焦点回退采用明确目标。避免新增对话首项后数字跳转或关闭错位。
3. **P1：查看资料时也能处理任务。** 首对话标签必须提示待确认／失败；资料视图保留停止入口。提示不自动切页，点击定位具体确认卡，资料滚动和聊天草稿保留。
4. **P2：关键异步结果可被读屏识别。** 模型切换、保存、来源读取、发送和停止各有一次简短结果反馈；禁用原因关联控件。搜索与流式输出合并提示，保持焦点稳定，避免不停播报。

## 7. 0.3.36 之后追加的规划与缺陷

以下为新的用户反馈与目标，不追写成 0.3.36 已包含的功能。快捷键弹窗明确要求本轮实施；其余新界面先交规划与示例，缺陷先复现并分别记录修复状态。

1. **P0：资源打开原生网页出现在窗口左上角。** [原生错位复现与修复方案](./browser-view-origin-regression-plan-2026-11.md)已证实忙时跳过几何提交却显示默认 800×600、前端去重阻止重试及缺少统一空闲 flush。首次或跨容器展示必须等正确边界提交，不能靠 CSS、重载网页或中断任务规避；正式修复待实施。
2. **P1：当前聊天查找无反应。** 新反馈需重新验证菜单、聊天工具图标、Ctrl/⌘ F 和展开工作区，不以先前组件用例通过否定用户现场。复现和实际修复单独增补到[查找规划](./conversation-find-plan-2026-11.md)。
3. **P1：子对话从消息进入工作区。** [新规划](./subchat-workspace-plan-2026-11.md)采用每父对话一个汇总标签，列表/详情内部导航，移除左侧子树；稳定种子 SVG 代替每次渲染随机图案。先补会话缓存、生命周期/配额恢复、类型化标签，再接全部入口，不丢失继续交流能力。
4. **P1：重设计整个对话输出。** [输出规划](./conversation-output-redesign-plan-2026-11.md)按参考图的正文、灰色工具行与子任务名称交错布局，保留真实时间顺序、错误/权限处理、折叠详情、查找与阅读锚点；正文内容重新设计，样板不执行截图任务。
5. **P1：设置进入与返回。** [设置导航规划](./settings-navigation-and-cursor-plan-2026-11.md)统一 open/close 与来源快照、明确返回和保存等待反馈；帮助关于跳到设置关于，不再两套内容。光标改为外观主题一样的卡片选择，仍使用真实原生 SVG 与现有配置。
6. **P2：侧栏轨道与名称。** [滚动槽规划](./sidebar-scrollbar-layout-plan-2026-11.md)让原生轨道在行元素右侧独立留白，固定标题搜索、每栏一个滚动主体。按最新要求，相关内容区域称“工作区”，撤回此前改名“导航栏”的要求；左侧仅用图标栏/侧栏描述，不替换工作区名称。
7. **本轮正式实施：快捷键弹窗与开关。** 使用固定标题/关闭、可滚动列表、分组、检索与键帽；Ctrl/⌘ / 切换面板，包括原生网页焦点。只有实际接通全部分派路径的应用命令提供启停；编辑器/系统固定快捷键只读说明，菜单点击功能不随快捷键开关禁用。自定义重绑定另立冲突与持久化契约，不放假编辑入口。
8. **本轮正式实施：仅 Agent 自动静音。** 浏览器设置增加默认开启的开关，实际任务/操作期间才临时静音；完成、暂停、接管后恢复手动选择，复制和持久化不保存临时值。原生 24 项通过，设置界面默认/关闭自动保存/恢复开启另有 3 项验证，见[追加工作记录](../next-iteration-check-2026-11-03.md)。
9. **新增规划：自适应工作区与悬浮侧栏。** [整体逻辑](../workspace-responsive-and-floating-sidebar-plan-2026-11.md)按真实内容预算决定分栏/自动展开，保留用户意图、比例、当前标签和阅读；分隔拖动越界在释放时提交，恢复有迟滞。侧栏固定/悬浮为两种展示，显隐独立；标题栏同位按钮控制显示，固定操作不切页或复制列表。截图 Ctrl Shift S 与编辑器删除线冲突，不直接照搬。
10. **新增规划：标签图标、换位动效及地址整行。** [详细规划](./workspace-tab-label-and-icon-plan-2026-11.md)统一混排标签的身份、加载、音频原因和标题可达；保留已统一的 36px 几何及关闭占位，补邻项让位、单次顺序提交、短位移动效和减少动态。地址行整合导航组、地址框、Agent 与附加操作，给出 44px 行/36px 框候选并清理多层尺寸覆盖；待实测确定，不用静态偏移定位原生网页。
11. **新增规划与样板：网页悬浮批注。** [详细规划](./browser-floating-annotation-plan-2026-11.md)将现有选完后底部抽屉的交互改为统一点击/拖选、目标描边与邻近评论条，保留草稿修订/冲突处理。使用专用的批注系统光标，和三款 AI 虚拟光标分开；Space 临时操作网页、输入法与失焦清理、原生 View 及跨 frame 能力分别验收。[样板](../../../_planning/browser-floating-annotation-example.html)不操作真实网页。
12. **本轮正式实施：浏览器菜单进入浏览器设置。** 更多菜单新增齿轮入口，置于下载列表之后、窗口管理之前，菜单关闭后打开主窗口的设置浏览器分类。独立浏览器沿已验证页面/宿主的主进程入口唤起主窗口，保留网页和工作区身份；从主窗口其它路由也可达，不依赖后台聊天页接收。专项验收记录见[追加检查](../next-iteration-check-2026-11-03.md)。
