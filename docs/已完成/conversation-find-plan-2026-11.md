# 当前聊天内查找规划（2026-11-03）

> 归档于 2026-11-05：功能及后续无反应修复已实施，并有正式构建专项记录。 原始设计、阶段状态及验收边界保留；实施依据见[相关记录](../remaining-plans-implementation-2026-11-03.md)，最新功能见[当前状态](../current-state.md)。

状态：正式功能已接入当前聊天，以下规划保留为设计依据；本轮实施与验证记录见第 7 节。现有跨对话搜索保留原入口。

## 1. 当前情况与目标

现有 Ctrl/⌘ K“搜索对话”遍历多个对话的标题与正文，每个对话取一段摘要，最多显示 50 个对话结果；点击仅打开对话。它不能逐个定位当前聊天里的关键词。相关实现位于 `src/pages/ChatPage.vue` 的 `chatSearchHits`、`messageSearchSnippet`、`pickSearchChat`，共享命令为 `conversation.search`。

本功能沿用[路线图 C03](../feature-roadmap-2026-11.md#c03--搜索命中消息与长对话定位--p1)，新增当前聊天正文的查找、命中计数、上一个／下一个与片段高亮；不另立一套重复的全局搜索工程。搜索入口与浮层规则继承[界面总规划](./interface-renovation-plan-2026-11.md)。

## 2. 入口与布局

- 当前聊天标题栏提供放大镜图标，title 为“在当前聊天中查找（Ctrl/⌘ F）”；聊天更多菜单与编辑菜单提供同名入口。左侧 Ctrl/⌘ K 保持“搜索对话”。
- 查找栏在聊天标题栏下方、消息区上方展开，占聊天自身的一行布局；不遮住首行消息、不覆盖编辑器，不横跨右侧网页／文件。
- 首层为搜索框、`3 / 18` 命中计数、上一个、下一个与关闭；`18` 按匹配片段次数计数，同一消息可有多次命中。
- 默认普通关键词匹配，支持中文、英文、数字与代码，英文不区分大小写。大小写选项和“包含工具与日志”收进简短的筛选菜单；首版不增加正则、语义检索或向量配置。
- 空查询提示“查找当前聊天内容”；无结果显示“未找到匹配内容”，前后按钮禁用。扫描中显示进度；未完成扫描时标记暂计结果，不能把当前批次数量冒充最终总数。
- 窄窗口允许把计数和导航排为第二行，保持输入、关闭和结果跳转可达；焦点仅由外层搜索框承担，避免再次出现内部矩形描边。

## 3. 快捷键归属

- Ctrl/⌘ F：聊天消息区或消息编辑器为当前操作区域时打开本聊天查找；已有输入则聚焦并选中查询。正文选中词可作为初始关键词，编辑器草稿及选区保持不变。
- 焦点在原生网页时仍查找网页；在文件预览中走该内容已有能力，未支持时明确反馈，不偷偷切换到聊天。设置、模型等临时弹层不被后台聊天查找抢走焦点。
- 查询框内 Enter／Shift Enter 为下一个／上一个；查找激活时 F3／Shift F3 在所属聊天区域跳转。Escape 只关闭当前最上层临时交互，关闭查找后恢复原触发点；不顺带关闭文件、停止任务或提交消息。
- 输入法组合及结束同一事件周期内不执行跳转或关闭。查询框 Enter 不得传播到消息发送。
- `BrowserTabPanel.vue` 当前使用 window 级 Ctrl F 监听，未按聊天与网页焦点分派。必须先统一快捷键目标仲裁，再接本功能，避免分栏中同时打开两个查找栏；原生网页的主进程快捷键转发也需验证。
- 完成正式功能后将按键与作用范围写入“帮助 → 快捷键说明”；仅规划时不在帮助中宣传可用。

## 4. 搜索范围与显示对应

- 默认查找当前聊天的用户消息及助手公开正文，包含代码块、链接显示文字和正文里的来源名称；不搜索未发送草稿、其他聊天、子聊天内部消息、磁盘文件全文或网页全文。
- 工具与日志默认排除，用户显式开启后纳入已有可访问文字，并标明类型。隐藏／受限的思考数据和凭据不因查找而暴露。
- 可见的流式助手正文参与增量查找，以稳定的运行／消息身份关联；最终持久化时合并对应结果，不重复计算同一段实时内容。
- 基于语义文本片段检索，并保存片段到显示文本的偏移映射。强调、链接、Markdown 标记、代码、跨文本节点匹配、空白与大小写归一化后，计数与高亮使用同一结果，不能命中原文却无法定位可见文字。
- 符合范围的折叠公开内容仍可检索，跳转时只展开命中需要的层级，并注明“执行记录”等所属区域。查找产生的临时展开与用户手动展开分别记录，关闭后恢复临时变化，不覆盖用户在查找期间的操作。

## 5. 跳转、长聊天与运行中的稳定性

命中身份至少包含 `chatId + messageId/streamId + 内容片段ID + start/end + 内容修订`，有 runId 时保留。按时间顺序和片段位置导航；首次选择当前阅读位置附近的命中，首尾循环时轻量提示“已回到开头／末尾”。

- 复用 `jumpToMessage` 的折叠记录展开、`data-msg-id` 定位和延迟布局校准，再定位片段；不能只滚到整条长消息顶部。
- 当前并无真正的消息虚拟列表，但已有 `content-visibility:auto`、延迟图片和 `v-memo`。搜索依据完整数据，不只扫描当前可见 DOM；高亮更新必须触发受影响消息的显示更新，不能被 memo 缓存挡住。
- 确认跳转后暂挂自动追随底部；流式输出、工具消息与新回复继续更新，但不能把阅读中的命中拉走。关闭查找保持当前阅读位置，只有用户点击“返回最新”才恢复追随。
- 流式更新只重算受影响片段，保留当前命中身份；新结果显示为计数变化，不自动跳到新增内容。删除、编辑、重试裁剪使命中失效时，选择相邻有效结果并说明更新。
- 切换聊天使当前查询代次失效，清理旧高亮及临时展开；迟到结果不能跳转新聊天。跨聊天结果到命中消息的跳转也复用同一定位接口。
- 查询、筛选与临时展开仅为窗口内 UI 状态，不写入消息正文、发送快照或全局设置；关闭不改草稿、队列或真实运行状态。

## 6. 接入拆分与验收

建议抽取 `useConversationFind`、独立查找栏与消息文本／偏移适配层；新增 `conversation.find` 或经统一 `content.find` 路由的聊天处理器。跨对话搜索 C03 后续直接复用命中结果和跳转接口，避免维护两套定位器。

先交付当前聊天普通文本查找、计数／跳转与高亮，再覆盖折叠记录、实时正文及增量优化；先测量再决定是否需要工作线程或虚拟列表。沿用 C03 的单会话 5,000 条与跨会话 50,000 条固定夹具，搜索延迟和输入响应分别记录，输入更新按既有 P95 32ms 门槛验收。

必须覆盖：同消息多处命中、零结果、首尾循环、中文输入法、长代码／链接／强调、折叠命中、图片晚载、流式输出不抢滚动、重试裁剪、快速切换聊天、键盘查找归属、Escape 只关闭一层及焦点恢复。搜索内容按普通文本处理；高亮不能直接拼接未经转义的查询到 HTML。读屏用节流的礼貌状态提示播报结果数与当前命中，减少动态效果时跳转不使用长距离动画。

## 7. 正式实施与验证（2026-11-03）

当前聊天标题与快捷键已经接入 ConversationFind。默认只查用户和助手公开正文，工具结果与日志显式开启；计数按出现次数计算，同条消息可逐处跳转。可见文本与 Markdown 偏移共同映射到 CSS Highlights，不改写消息 DOM，兼容现有缓存。工具定位只映射实际结果，不把参数或复制用标题误算为正文。流式正文提交为持久消息时去重，并保留当前命中。

真实组件夹具完成 **18 项**检查：同消息多命中、Enter／Shift Enter、折叠定位、跨 Markdown 文本节点高亮、工具与日志真实显示文本、Escape 逐层关闭、流式更新不导航／不移动阅读位置、最终消息去重与当前命中保留、输入法组合保护、切聊天清理及再次搜索、窄屏换行、选项菜单视口边界，以及关闭后的高亮清理和焦点恢复。脚本为 `scripts/ui-conversation-find.mjs`，机器记录与截图位于 `release/ui-conversation-find/`。

夹具通过组件的定位回调模拟折叠内容展开，不等同于真实主窗口全部消息折叠层级。主窗口真实滚动、跨标签显示及产物定位由整体 Electron 长链路另行覆盖；尚未进行本规划所述 5,000／50,000 条搜索专项性能基准，也未把隐藏窗口合成输入视作系统输入法真机验收。

## 8. 新反馈“打开没有反应”的正式修复

已在原正式构建复现，并区分于前一节独立组件夹具：四个入口均能设置 opened=true，但桌面聊天的三行 grid 加入第四个查找栏后将第二行压为 0。搜索栏实际约 14.57px，与消息区起点重叠，输入和按钮被覆盖；不是没有查询数据。

`ConversationFind.vue` 现在仅在可见聊天存在查找栏时使用四行 auto/auto/minmax(0,1fr)/auto，并为查找栏和选项建立局部叠层。关闭后恢复原三行，不改变网页或文件布局。搜索栏实际恢复约 46.57px，消息区从其下方开始，鼠标能命中输入。

另在 900px 桌面窄窗口复现工作区 overlay 遮住聊天，应用菜单打开查找仍落入隐藏内容。`ChatPage.vue` 的 openConversationFind 现在先清理非聊天模式、收起覆盖工作区；正常展开模式则选中固定聊天标签，待视图更新后再打开和聚焦查找。

正式重建后的主窗口回归 **17/17 通过**，见[报告](../../../_planning/conversation-find-diagnostic/built-final/completed.json)。包括图标、更多、编辑菜单、Ctrl F、鼠标命中与实际键入、结果计数、F3/Shift Enter、选项、关闭恢复、分栏/展开/覆盖工作区以及原生网页 Ctrl F 仍打开网页查找。对照截图与修复前结果在同目录的 baseline/source-final/built-final 中保留。

渲染进程错误为空；[主进程日志](../../../_planning/conversation-find-diagnostic/built-final.log)保留两次迟到旧编辑目标的 composer_source_changed 拒绝，发生于工作区关闭/重开，未造成上述用户路径断言失败。不能因此写成主进程零错误，也不能以本次 17 项替代大数据性能或真实系统输入法验收。源码及开发构建已更新，现有 0.3.36 发行包未重打。
