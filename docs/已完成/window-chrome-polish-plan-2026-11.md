## 1. 这次调整解决什么

截图中 Logo 与应用名已相邻，但品牌组和菜单缺少稳定的外侧间距；应用名 12px／600 与菜单 13px／常规字重也存在节奏差异。左侧第一个导航图标紧接标题栏，品牌与导航的分界偏弱。目标是品牌成组、菜单对齐、导航起点明确，并延续所选主题。

当前证据：`src/pages/ChatPage.vue` 的 `.window-titlebar-brand` 与 `ApplicationMenuBar` 是相邻元素；`src/styles/postpile-theme.css` 中标题栏 44px、左内距 10px、品牌图标 24px、品牌文字 12px、内部间距 8px，没有明确的品牌外间距。`ApplicationMenuBar.vue` 的菜单按钮文字 13px、高 28px；`main-window-layout.css` 的导航宽 52px、上内距为 0。最终样式应在布局归口文件集中调整，避免跨主题重复覆盖。

## 2. 推荐尺寸与层次

- 标题栏保持 44px。Logo 调整为 22px，中心对齐左侧 52px 导航轨道的中心线；左内距由几何推导为 15px。
- Logo 与 Navora 间距 8px，应用名 13px、600 字重；作为一个不可拆分的品牌组垂直居中，不把应用名当菜单按钮。
- 品牌组到第一项菜单留 20px。菜单 13px、常规字重，统一 20px 文字行高、28px 点击高度；各菜单间隙 2px、左右内距约 10px。
- 品牌、菜单文字按同一中心与基线核对；所选主题统一提供文字和悬停色，品牌不额外换一种强调色。
- 左侧导航顶部增加 1px 低对比度横线，左右各内缩 10px，线长 32px，所在高度与右侧内容表面的顶部边界一致。
- 导航图标组在细线下留 8px，再开始首个 32px 点击区域。下移整个上方图标组，组内间距维持 8px；底部设置入口继续贴近底部，不因加间距溢出。
- 横线仅负责分组，不可点击、不进入 Tab 顺序。选中导航的侧标记与数字角标保持对齐，主题深浅变化后仍清楚。

这些是 CSS 逻辑尺寸。不能根据放大后的截图像素直接倍增；需在系统缩放 100%／125%／150%／200% 和应用缩放下检查。

## 3. 窗口行为约束

- 保留现有 Windows 窗口控件预留，品牌／菜单变化不得伸入右上角命中区；不用覆盖菜单的透明拖动层来凑对齐。
- 菜单按钮、Logo 说明及其他可交互区域命中明确；可拖动区通过剩余空间推导。当前 `.window-titlebar-drag` 的固定 left 120px 需检查并改为品牌＋菜单之后的布局空间，避免新间距后挡住菜单。
- 菜单 F10／Alt、左右切换、上下选择与 Escape 恢复焦点沿用现有命令模型。放大、侧栏收起、展开工作区时，标题栏和导航起点不跳动。
- macOS 继续采用当前独立的原生窗口控件／菜单布局；不把 Windows 的 Logo 行和预留宽度强加到 macOS。移动端抽屉也使用自己的品牌布局。
- 高对比模式用主题结构色绘制分隔线；普通主题的细线只作辅助分组，键盘焦点仍由各按钮承担。
