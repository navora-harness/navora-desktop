## 3. 统一提交规则（待实施）

### A. 完成选择即保存

- 开关、主题卡片、不需确认的枚举/单选，产生一次用户操作即提交该字段。
- 初始加载、默认值填充、展开高级区、切选当前服务商、搜索和筛选均不产生保存。
- 一项选择导致多个关联字段变化时，作为一个业务补丁提交，例如权限模式及预设标识。
- 禁用关联设置只禁止编辑，保留其已保存值；重新启用不重置先前偏好。
- 可先预览可逆外观；持久化失败恢复已保存的有效外观，同时保留失败意图供重试。

### B. 局部草稿、手动提交

- 文本、数字、路径、URL、端口、密钥、映射与列表编辑，先进入所属小组草稿。
- 使用“更新路径”“保存连接”“保存模型能力”“保存访问规则”等具名动作，附“取消修改”。
- 仅提交本组变动；按钮只在有有效改动时可用，错误定位到具体字段。
- 不因失焦、切分类、选择服务商、收起高级区或关闭窗口偷偷提交。
- Enter 只有在表单明确声明其提交动作时执行；多行文本、输入法候选确认不得误提交。
- 当前 `@change` 修改模型 ID/采样间隔的逻辑也应迁入草稿，不能把 change 当作统一持久化边界。

### C. 独立业务动作与少量确认

- 测试连接、获取模型、导入、导出、安装、创建与打开目录保持各自含义，不附带保存其它设置。
- 清除密钥、删除正在使用的服务商、批量重置、路径影响现有文件等，按真实影响给独立确认或影响预览。
- 权限放宽到高风险档位、首次对外开放远程监听有针对性的范围说明；普通偏好不添加统一确认。
- 已保存设置的“恢复默认”是一次新配置提交；“取消修改”仅丢弃本组草稿，两者不能混名。

## 4. 按实际设置模块分类（待实施）

### 基本与外观

- 关闭到托盘、启动显示、标题生成、后续建议、来源/日志展示与折叠：自动保存。
- 运行时插入/排队模式是离散选择，应纳入自动保存；当前即时投影没有包含该字段。
- 输入框字数上限：局部“更新字数上限”，验证整数与范围；不裁掉现存长草稿，应提示超限并允许编辑。
- 主题与亮/暗/自动模式：自动保存，失败可重试；跟随系统的显示变化不是新的配置提交。

### 模型

- 选择“正在编辑的服务商/模型”属于浏览状态；设为默认独立保存，影响范围明确到默认继承规则。
- 名称、Base URL、API Key：连接草稿，使用“保存连接”；密钥清除另为具名动作。
- 添加服务商先创建局部草稿；确认保存后才进入可用目录，避免把空连接自动写入配置。
- 模型 ID/名称、能力、输出参数和推理映射：按服务商或模型 ID 的局部事务保存，详见第 9 节。
- 最大轮数、续跑轮数：一组数字草稿，使用“更新推理限制”；注明从下一次任务/续跑读取。

### 浏览器

- 虚拟光标、平滑移动、反馈、输入保护、窗口可见性、弹窗阻止、load/网络空闲等待：自动保存。
- 移动风格与帧率等离散选择自动保存；速度滑杆拖动中只预览，松手或键盘调节完成后合并提交一次。
- 轨迹采样间隔、导航/操作超时、空闲判定时间：数字草稿，“更新移动参数”“更新等待时间”分别提交。
- UA 预设联动 UA 文本，与自定义 UA、语言放入“保存网站标识”事务，不单独保存半套关联字段。
- 网址白名单：多行草稿，校验并去重后“保存访问规则”；清空意味着不限制，需直说影响。
- 诊断日志开关：说明记录内容与本机日志位置；提交状态与日志是否已写出分别表达。
- 写明“新会话使用 / 下一次导航或操作读取 / 可热更新”；不自动刷新页面，不覆盖现有会话专属 UA。

### 工作区

- 内置相对目录与自定义根路径共用草稿；“选择文件夹”只填候选值，之后点击“更新路径”。
- 主进程检查路径规范化、合法范围、存在性/创建方式及可写性；远程端不能假装拥有本机选择器。
- 显示实际目标路径、受影响对话及独立覆盖路径；新路径、继续旧路径、迁移文件不是同一个动作。
- 首期不搬迁旧文件；若切换影响已有目录，阻止误切并提示先处理旧目录或明确选择只改变后续归属。
- 迁移另立工程：占用检查、冲突、空间、进度、取消与回退；不以“自动保存”掩盖数据迁移。

### 技能与插件

- 已安装技能启停及插件开发模式保留明确开关操作；失败恢复该项状态，不牵连全页。
- 技能内容编辑、新建、删除、提案、导入导出与商店安装继续使用现有专用流程。
- 编辑器中的启用/需读取标记与技能内容属于同一草稿，用户取消编辑后不得单独落盘这些字段。
- 开发模式监听器重载失败显示“已保存，部分插件未重载”，可查看并重试该副作用。

### 远程访问与权限

- 远程开启需先有有效的已保存账号/密码/地址，使用明确开启动作，不能提交未完成的连接草稿。
- host、port、username、密码作为“保存远程连接”事务，必要时“保存并重新连接”，说明当前连接会中断。
- 关闭远程访问可直接提交；从远程端关闭本连接前明确提示，响应/断开时序单独验收。
- 区分“配置已保存”和“监听成功”；端口占用时不谎报已启用，保留值并提供“重试启动”。
- 权限档位/预设属于离散动作，整组模式与 preset 原子提交；新对话/继承空对话/既有权限分别说明。
- 大幅放宽预设先展示影响；搜索能力、分组与“仅显示不同项”是本地过滤，不写配置。

### 询问/决策、子对话与关于

- 询问/决策的启用、选项说明、推荐、现场证据、记住选择等已实现开关自动保存。
- “不限时”与有限超时联动：选择不限时提交 0；选择有限时间先确认当前有效秒数，再整组提交。
- 秒数、子对话最大并行数量使用局部保存；降低并行上限不强停已运行子任务，约束后续创建。
- `inline_low_risk`、`allow_revise` 目前仍被强制关闭，继续显示未实现说明，不做可用开关或假保存。
- 关于、查看版本、打开数据目录不产生配置写入；不属于设置页现有字段的功能另立项。

## 5. 配置协议与并发基础（优先实施）

- 新建共享提交入口，覆盖桌面 IPC、Agent 更新、远程 shim 与引导页，副作用只维护一份实现。
- 提交包含 `operationId`、变动字段、预期字段值/组修订及来源；返回规范化值、修订、有效范围和局部错误。
- 不同字段可合并；同字段在基线后改变时返回冲突，展示“采用最新值 / 保留我的修改后重试”。
- 全局 revision 用于排序与订阅；只因无关字段 revision 变化不得拒绝本次独立修改。
- 服务商/模型目录以稳定 ID 执行增改删；对数组或关联组加比较条件，避免旧整列覆盖新成员。
- 主进程按配置事务串行持久化；窗口内按字段/组排队并合并最后意图，避免旧响应覆盖新值。
- 网络探测/路径检查可取消旧请求；已提交写操作不能仅靠取消 UI Promise 当成未发生。
- 设置页订阅已提交更新：更新未编辑字段，保留草稿字段，并对同字段外部变更显示冲突。
- 回执/广播携带修订及操作标识；旧广播不能把新回执降级，卸载后响应不操作已销毁视图。
- 禁止整页深度 watch 自动保存，以及在每个控件中各自组装完整旧 snapshot。
- 服务端逐字段/组校验有限数、边界、URL/端口、关联模型与权限；不可只依赖前端数字钳制。
- 配置采用同目录临时文件与可恢复替换策略，持久化成功后才提交内存和广播；验证 Windows 文件占用失败。
- 新接口对旧 `config.save` 提供适配期，迁移所有调用点后再收紧全量写入，避免引导/Agent 回归。

### 凭据与副作用

- API Key 继续进入 secrets，明文仅在必要调用的内存载荷中；不写配置、日志、事件、URL 或持久草稿。
- 以“已配置/未配置/待更新”展示密钥，默认脱敏；空输入不代表清空，清空须明确操作。
- 连接配置与 secrets 是两个存储：设计补偿或分阶段事务，报告“连接已保存，密钥写入失败”，保留草稿重试。
- 不自动回滚删除另一窗口刚写入的新密钥；补偿/重试比较本次版本，旧密钥可用性需真实验证。
- 监听重绑、插件监听、浏览器原生设置逐项返回运行时结果；落盘后失败不能伪装为全事务未保存。
- “重试生效”只重试相应副作用；“重试保存”只发送原失败组，二者不可替代。

## 6. 保存状态、撤销与离开策略（待实施）

- 顶部保留轻量汇总：“保存中…”“有 2 处未保存”“1 项需要处理”，没有全页应用/还原。
- 自动项局部显示“保存中 → 已保存”；失败回到最近已确认值，同时保留待重试意图及错误。
- 保存与生效分别显示，如“已保存 · 监听启动失败”“已保存 · 新会话使用”。
- 启动时读取的设置显示“下次启动使用”；只有确实要求重启的能力才显示“需重启”。
- 局部草稿显示“未保存”与具名提交/取消；失败不清空输入，不使其它分组全部禁用。
- 可逆自动项允许短时“撤销本次修改”，发送比较修订后的反向补丁；外部已改同字段则先提示冲突。
- 路径迁移、密钥删除、安装卸载不承诺通用撤销，使用各自恢复能力和真实边界。
- 切分类保留草稿并标修改数量；收起高级区保留草稿且摘要提示，不额外弹确认。
- 关闭设置/返回对话：无草稿直接离开；非敏感草稿保留于当前窗口内存，明确“已保留，返回后继续”。
- 有凭据草稿时离开提供“继续编辑 / 放弃本组”，默认不跨设置会话保留秘密；关闭不解释为保存。
- 真正关闭窗口/退出进程且有未保存组，共用离开守卫提供“返回编辑 / 放弃并离开”，列出分组。
- 显式点击局部保存后离开，只等待已提交操作并显示进度；失败留在对应组，不弹全页应用确认。
- 自动提交尚排队时离开先交给队列完成；异常退出可能丢失未确认操作，不能提前显示已保存。
- 遮罩、Esc、路由返回、内嵌切换、系统关闭共用策略，不只拦一个返回按钮。

### 每个组件只指定一个焦点归属
