## 1. 本轮目标与问题定义

截图中浏览器侧栏铺陈约 51 个对话，多数标为 0 页；当前对话的会话中有一个新标签页。
另一种零页状态只在中部留下“新建网页”；新标签首页还出现无文件时的搜索、分类与空文件卡。
这些是资源组织、状态表达及动作归属的问题，不应只靠增大卡片、增加装饰或自动创建页面填空。

- 优先呈现实际可打开的页面，同时保留无页持久会话的可发现入口。
- 区分全页浏览器模块、聊天内工作区及新标签首页，分别提供符合任务的内容。
- 明确会话名称、默认选择、存储策略及不同关闭／清除动作的影响。
- 浏览、筛选、展开和重命名保留草稿、真实页面实例及其网站数据。
- 新功能按优先级列入实施批次；本轮不修改正式组件。另有离线交互示例用于排版与状态评审，见第 11 节，示例不是正式浏览器验证。

## 2. 当前实现与证据

- `src/components/sidebar/GlobalResourcesPanel.vue`：`owners` 在 `kind==='browser'` 时保留全部 `chats`，因此无资源对话也进入列表；数字是列表中的对话数量，不是有页对话数量。
- 同文件已有对话标题、页面标题及网址搜索；占位仍是“搜索对话”，没有当前／全部范围、会话名或有页过滤。
- 同文件按对话分组，默认展开当前对话；`openOwner` 优先复用选中页／已有页，否则复用会话或创建会话及 `about:blank` 页面。
- `src/components/sidebar/BrowserResourcesPanel.vue`：`visibleSessions` 已将有页会话置前，新出现页面的会话会展开，但无页会话仍逐条显示。
- 同文件会话行及名称按钮单击直接 `add-ref`；页面单击则显示页面，造成导航与引用语义不一致。
- 同文件显式新建会话传 `persist:true`；`quickOpen` 无会话时传 `persist:false`，存在会话则复用，不应在重排界面时悄悄改动策略。
- `src/components/sidebar/BrowserResourceActions.vue`：页数与更多按钮复用固定槽位，已有 hover、focus-within 及触屏处理；多页显示 `9+`，真实数量仍写入可访问名称。
- `src/components/BrowserStartPage.vue`：推荐访问、对话文件及最近访问均固定出现；对话文件直接挂载 `WorkspaceFilePicker`，即使无文件仍显示搜索、类型筛选和空提示。
- `src/components/FileWorkspace.vue`：全页零页已有标题、说明及新建动作；聊天内零标签另有“打开对话文件”，不能把截图的稀疏状态误写为代码完全没有空状态。
- `src/pages/ChatPage.vue`：`browserWorkspaceTabs` 仅筛选浏览器标签；聊天工作区混排文件与网页。对话首标签仍是关联规划目标。
- `shared/types.ts` 的 `BrowserTreeSession` 尚无自定义名称、默认标记或活动时间；当前显示名只来自 `sessionIndex`，新元数据需补全主进程及持久化路径。
- `electron/modules/browser-registry.ts`：`createSession` 的 `persist` 默认为 false，真实隔离分区与会话身份已经存在；名称修改不应重建它们。
- 同文件 `savePersistent/restorePersistent` 仅保存／恢复 HTTP(S) 页面，不恢复空白新标签；无页持久会话记录仍可恢复。
- `electron/main.ts` 的会话关闭 RPC 固定调用 `closeSession(sessionId,true)`；后者销毁全部页、清理网站数据并移除会话，不是仅关闭页面。
- `ChatPage.vue` 菜单写“释放会话与登录状态”，确认框却写“关闭 Session”；同一危险动作的名称、对象和结果需要统一。
- “已保留登录状态”当前只来自 `s.persist`，没有登录有效性检测；它只能说明会话数据存储策略，不能证明用户登录了任何网站。
- 搜索双焦点来自外层 `.global-resource-filter:focus-within` 与全局 `control-system.css` 的 input `:focus-visible` 叠加；局部 `outline:none` 不足以覆盖高优先级全局规则。

## 3. 界面职责与排版

### 3.1 全页浏览器模块

用途是查找、打开和管理浏览器资源；侧栏展示资源层级，主区展示选中页面或明确的浏览起点。
标题区保留“浏览器”，下方紧凑排列范围、搜索及筛选；新建页面为主动作，新建会话为次级动作。
资源层级为“所属对话 → 会话 → 页面”；页面使用标题／域名，会话使用自定义名称及简短状态。
在全部范围查看其他对话的资源时，始终可见所属对话，“打开对话”是明确动作。
接入时需核对 `ChatPage.vue` 的 `browser.present` 归属切换，避免仅隐藏界面而保留错误的编辑目标。

### 3.2 聊天内工作区

用途是围绕当前任务查看资料；资源范围默认当前对话，文件／网页混排及来源定位继续复用现有工作区。
分栏时保留聊天与资料并排；展开后按关联规划将当前对话置于首标签，与文件、页面共享一栏。
浏览器全页的资源筛选不等于工作区展开，两者不共用一个含混的“展开浏览器”开关。

### 3.3 视觉约定

延续项目颜色、间距、菜单表面与 Fluent 图标，保留现有 `workspace-expand/restore` 语义。
页数、状态与更多菜单对齐在固定位置；列表保持单行标题，次级信息仅在需要时补充。
不用持续显示的 0 页徽标、空文件卡或重复说明填满空间；窄屏保证主动作和返回路径可达。
搜索框焦点由外层圆角表面唯一承担，对内部 input 的 `:focus-visible` 做明确局部重置；与统一控件规划共用规则，保留搜索整体及按钮的可见键盘焦点，不全局关闭 outline。

## 4. 范围、搜索与列表组织（P0）

- 提供“当前对话／全部对话”范围；全页首次默认全部，聊天内入口默认当前，后续分别记忆用户选择。
- 当前对话不存在时禁用该范围并说明原因；不创建虚假的默认对话。
- 常态列表默认优先显示有打开页面的对话；当前对话若无页，仅保留一条简短创建入口。
- 有页会话先显示；无页但保留数据的会话合并到“未打开页面的会话（N）”，默认折叠。
- 临时空会话可并入该管理入口并标注临时；隐藏空项只影响展示，不自动删除任何会话。
- 完全无浏览器资源的其他对话不逐条铺陈；通过“在其他对话中新建…”搜索选择所属对话。
- 提供“有页面／全部会话”筛选；全部会话包含持久与临时，不把持久空会话做成无法找回的隐藏状态。
- 搜索占位改为“搜索对话、会话、页面或网址”；名称、域名、网址均在所选范围匹配。
- 搜索可命中折叠的空会话，并明确提示其没有打开页面；不能让默认有页筛选吞掉名称搜索结果。
- 对话命中时显示其相关会话；页面命中时保留其祖先路径，并突出匹配内容，避免展开所有无关页。
- 数量分清“匹配页面／匹配会话／所属对话”；不要把 51 个对话称为 51 个浏览器资源。
- 当前页保留选择高亮；有页分组内当前所属对话置前，其余先延续既有稳定顺序，避免刷新后跳动。
- 最近使用排序若后续启用，需新增真实活动时间记录；不能从会话序号推断最近使用。
- 切换范围、刷新和关键词异步返回采用所属范围／请求版本校验，过期结果不覆盖新选择。
- 首期保留清空搜索、恢复默认筛选及手动刷新；没有必要首期引入复杂的多条件查询语言。

## 5. 五类空状态与加载状态（P0）

### 5.1 工作区 0 页

“当前没有打开的网页”，说明当前范围；主动作“新建页面”，次动作“选择已有会话”。
若其他范围有页，显示具体的“查看全部对话的 N 个页面”；无证据时不展示推测数量。
不为填充空屏自动创建新标签，不强制打开推荐网站，不默认删除空会话。

### 5.2 会话存在但 0 页

显示会话名称及“暂无打开的页面”，主动作“在此会话新建页面”。
持久会话说明“会话数据保留，可继续使用”；临时会话说明“退出应用后不保留此会话”。
这些说明不保证网站凭据仍有效，也不暗示零页会话没有存储数据。

### 5.2.1 零页面隐藏标签栏（用户补充）

纯浏览器窗口或全页浏览器的当前宿主实际没有任何页面时，隐藏整条浏览器标签栏，包括标签后的加号、分隔线和专属数量控件，不留下只有加号的空白横条。新建页面动作由空状态区域和资源标题区提供。首次新建页面后恢复标签栏；关闭最后一页后再次隐藏。独立窗口若按现有生命周期直接关闭，不为展示空状态强行保留空窗口。

页面正在加载、失败或临时被弹层遮挡仍是已有页面，不能按零页隐藏。资源搜索无结果也不改变真实宿主页数或清除当前页面。聊天展开后的混合标签栏只要还有对话／文件标签就继续显示；不把“没有浏览器页”等同于“统一工作区没有标签”。零页面切换完成时同步清理旧地址栏和原生视图显示状态，保留会话数据与新建入口。

### 5.3 已创建的新标签页

保留地址栏及“输入网址或搜索”引导；推荐访问为紧凑可选内容，最近访问有记录才显示列表。
对话文件仅在有实际文件时出现，最多显示少量最近／相关条目及“查看全部”，不嵌入完整文件管理器。
文件加载完成且为空时隐藏整段文件区；加载中用轻量状态，失败提供小型重试提示，不能按空目录处理。
确实需要导入文件时，通过附加／文件模块入口完成，不长期保留一张空文件卡。
既有访问历史仍按对话隔离；清除最近访问记录不等于清除网站数据或退出登录。

### 5.4 搜索无结果

显示关键词、当前范围及生效筛选；提供“清空搜索”和适用时的“扩大到全部对话”。
不显示常态空屏的新建大卡，也不丢弃原搜索条件或跳转其他对话。

### 5.5 读取失败与网页失败

资源读取失败保留已加载列表并标示未更新，提供重试；没有成功快照时显示失败状态而非 0 页。
网页导航失败／崩溃继续沿用 `BrowserTabPanel.vue` 的失败页、重试与返回行为，不伪装成新标签页。
骨架、错误及空状态使用不同分支；所有已知操作中状态都有退出与重试路径。

## 6. 会话名称、默认选择与存储（P1）

- 重命名支持行内输入或轻量对话框，Enter 保存、Escape 取消；空名称回退“会话 N”，长名截断但可查看完整名。
- 名称只是元数据：保留 `sessionId/chatId/sessionIndex/partition`、页面实例及已有引用身份。
- 元数据通过主进程校验并与会话持久记录一起保存；旧记录无名称时无需迁移分区，继续使用原显示名。
- “默认会话”限定于所属对话，只决定未指定目标时新页面落在哪里；每个对话至多一个。
- 明确指定的会话优先；快速打开先复用活动／已有页，无页时使用有效默认会话，再沿用已有可用会话。
- 无会话时快速打开延续当前临时创建策略；显式新建会话提供“保留会话数据／临时会话”，默认延续当前持久创建行为。
- 默认标记不代表持久，也不代表已登录；临时默认会话失效后自动清掉失效指针，不悄悄改成持久。
- 持久标记统一显示“保留会话数据”，临时显示“临时会话”；详细说明可提及网站 Cookies 和站点存储。
- 网站可能要求重新登录、凭据过期或自行清除数据；不新增虚构的“已登录／登录正常”状态。
- 首期存储策略在创建时选定，不把 `persist` 当成可无损原地切换的开关；跨分区迁移另行规划。
- 会话排序及重命名不得重编号旧会话，旧引用、书签、活动页面及恢复关系保持稳定。

### 6.1 将关闭、清除和删除拆为不同动作

- “关闭页面”：仅关闭所选页面，保留会话和网站数据，沿用现有网页卸载与任务协调行为。
- “关闭此会话全部页面”：保留会话名称、默认标记及网站数据；实现需独立于当前清除型 `closeSession` RPC。
- “清除此会话的网站数据…”：保留会话定义，明确实际清理范围及是否需要关闭页面，成功后才报告已清除。
- “删除会话及数据…”：关闭其页面、清除网站数据并移除会话记录；不删除所属对话、文件或历史消息。
- “释放会话与登录状态”不再作为含糊的常用动作名称；若要释放页面资源，使用准确的关闭页面动作。
- 清除／删除的确认框统一显示会话名称、所属对话、受影响页数、数据影响及最终动作名，取消不改变状态。
- 执行中锁定目标身份，发生关闭／重命名／归属变化时重新校验；有 AI 操作或选取任务时沿用协调规则。
- 默认会话被删除后清除默认指针并按既定回退选择；不能删除成功后保留幽灵条目或失效默认标记。

## 7. 菜单归属与键盘行为（P0/P1）

- 模块工具栏：新建页面、新建会话、范围／显示设置及刷新；不放当前选中会话的破坏性动作。
- 对话分组菜单：在此对话新建页面／会话、打开所属对话；不越级清除此对话所有会话的数据。
- 会话菜单常用区：打开已有页、在此会话新建页面、重命名、设为默认、附加会话引用。
- 会话菜单管理区：关闭全部页面；危险区分隔并后置“清除网站数据…”及“删除会话及数据…”。
- 页面菜单：打开／定位页面、附加页面引用、复制网址、已有页面显示动作及关闭此页；不包含会话级清除。
- 主浏览器导航场景中，会话单击选择并展开，必要时显示其已有页；0 页显示会话说明，不因单击名称就新建页面。
- 会话引用改为明确的菜单动作；保留拖拽引用，但遵守来源归属及草稿插入位置校验。
- 页数／更多共用槽位继承现有实现；键盘聚焦与触屏始终可发现更多操作，菜单打开时固定目标。
- 树用左右键展开／收起，上下键移动焦点，Enter 打开；菜单支持方向键、Enter、Escape、Shift+F10。
- Escape 关闭菜单后回到触发控件；重命名与搜索输入期间，快捷键及中文输入不能误触页面关闭或引用。
- 原生网页承载层按附加规划第 13 节先修正现有截图／隐藏竞态，再复用统一的菜单遮挡协调；不能让网页遮挡菜单、接收被拦截的点击或因菜单打开而整块留白。

## 8. 草稿、页面及附加衔接（P0/P2）

- 筛选、搜索、折叠、模块切换、重命名和布局变化只改展示元数据，不重新导航或克隆已有页面。
- 复用真实 `pageId`、会话分区与宿主转移链路，保留网页表单、历史、缩放、静音、固定页及人工控制状态。
- 返回当前对话恢复同一编辑器及草稿；若实际需要切换对话，先完成现有草稿保存／冲突处理再改变编辑目标。
- 对话首标签采用关联规划的单一工作区模型；展开／恢复分栏不新增第二份聊天、输入框或浏览器实例。
- 新“附加”菜单中的浏览器页面／会话读取同一来源目录；侧栏附加动作调用统一的插入位置书签逻辑。
- 行内引用保留来源身份；页面摘录是可编辑副本；会话引用不复制登录数据、Cookies 或未授权网页正文。
- 浏览全部对话资源不扩大引用权限；跨对话来源必须走既有校验或明确的摘要副本流程。
- 页面关闭／会话删除后保留用户已写草稿，并将相应引用标为不可用；不静默删除文字或自动换成另一页面。
- 远程端沿用远程查看能力，不能照搬仅本地可用的拖出窗口、原生页操作或数据管理动作。

## 9. 分批实施与验收

### 第一批：列表、空状态与菜单表达（P0）

修改范围以 `GlobalResourcesPanel`、`BrowserResourcesPanel`、`BrowserResourceActions`、`BrowserStartPage` 及相关状态为主。
验收含 51 个对话多数 0 页、有页与空会话混合、全部无页、仅临时会话及持久空会话等场景。

验收五类空状态、慢加载、失败重试、关键词无结果、当前／全部范围及清空筛选；空文件区不占位。
验收零页时整条浏览器标签栏不占高度，首个页面创建后恢复、最后一个关闭后隐藏；加载／失败页和搜索无结果不误隐藏，混合栏中的对话／文件不受影响。
菜单目标、点击／拖拽行为、键盘与触屏可达性可复现；这批不冒用清除接口实现保留型关闭。

### 第二批：会话元数据与动作拆分（P1）

补齐名称、默认指针、存储说明、主进程命令、持久记录兼容及 UI 结果回传，先定义契约再接菜单。
验收旧数据回退、改名后重启、同名会话区分、默认失效回退、重复点击、部分失败与 AI 操作中的目标协调。
关闭全部页后会话及网站数据保留；清除数据与删除会话有不同结果；取消确认不产生任何清理。
以测试站点实际验证存储行为，不以 `persist` 图标代替登录或数据保留证据。

### 第三批：统一工作区与附加联动（P2）

随附加规划接入对话首标签、统一来源及插入书签，验证切回草稿、引用失效、跨对话边界与远程显示。
展开 → 页面 → 对话 → 文件 → 恢复分栏后，草稿内容一致、编辑器唯一、原页面实例与网页状态延续。
继承 `about:blank` 不重启恢复的既有行为；有效持久 HTTP(S) 页面恢复、页顺序及宿主归属仍按现有链路处理。
适配窄屏、独立窗口和多窗口事件；不回归为大堆 0 页条目或以新页面掩盖真实零页状态。

## 12. 地址栏 Agent 按钮的内缩与边框（新增）

用户截图中，机器人按钮的背景接近地址栏全高，右边缘与圆角又没有完全接合，容易呈现“半贴边”的状态。采用内缩按钮方案，与地址栏保持明确的内外层关系。

代码证据：`BrowserAgentControl.vue` 默认触发器为 32×32px；`BrowserTabPanel.vue` 又将地址栏压成 32px 高、带 1px 边框，并在后部覆盖为右内距 1px。子按钮高度达到父容器外高，超过父容器内容高度，且两个组件分别管理圆角，造成视觉接缝风险。

推荐统一到浏览器工具栏尺寸变量：地址栏逻辑高约 40px，边框 1px，Agent 可见按钮 30px，内侧四周 4px；按钮圆角约 8px，外框约 12px，图标 18–20px，垂直居中。若正式产品保留更紧凑高度，应按同一公式缩放：按钮高度 = 地址栏高度 − 两侧边框 − 两侧内距；不能让子按钮仍为父外框高度。触屏地址栏 44px、按钮约 34px。

- 地址栏保留完整的一道边框。机器人按钮在普通／悬停／AI 允许／忙碌／暂停／警告状态都不触碰外框，状态不改变几何尺寸。
- 普通态透明，悬停和 AI 允许态使用主题填色；暂停／警告用小标记及可读 title，不只换颜色，不用按钮背景持续闪烁。
- 右侧预留完整动作宽度，长网址可以在文字区截断或横向编辑，不伸入按钮；提示、批注选择状态等也不得挤坏按钮。
- 地址输入焦点由外框承担，内部文字不重复描边；Agent 键盘焦点由自己的按钮承担，轮廓收在安全内距中。
- 继续保留已有左键显式切换、右键／向下键／Shift F10 查看面板、触屏长按等操作。本次尺寸调整不修改输入控制权，更不能因鼠标经过按钮或 view 触发人工接管。
- 不通过父容器 overflow:hidden 粗暴掩盖尺寸错误，以免裁掉键盘焦点、状态角标或浮层。
- 地址栏和工具栏高度变更后，用实际测量的工具栏下沿重新布局原生网页，复核缩放、展开工作区与独立窗口；不沿用旧的固定偏移，避免网页顶端被覆盖或产生空缝。

[标题栏与导航示例](../../../_planning/window-chrome-example.html) 同时展示内缩 Agent 按钮，可切换冷暖主题和 AI／人工示意状态。正式接入需验证普通／选中／悬停／聚焦、缩放、窄栏、长网址及原生网页浮层恢复；该原型不加载真实网页。
