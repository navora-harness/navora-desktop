## 1. 本次调整

截图的核心是：导航及地址栏保持可见，旁边有选中态的“批注”开关；页面目标用蓝框标记，目标旁出现轻量胶囊评论输入。

据此建议取代上一轮“整行地址栏变成批注工具条”的布局：保留正常导航／地址输入，在同一行增加批注开关和独立数量入口，点击开关后直接在页面点选或拖选。继续取消底部批注抽屉，不增加占据页面高度的历史栏。

当前新建及编辑统一采用原生多行面板，保留完整正文、草稿和旧记录，不再按单双行拆成两个编辑入口。固定输入高度可以验证多行与提交语义，但不能视为用户要求的自动增高已经完成。

这是基于新截图的建议方案；“整行替换、常驻操作网页／更多／完成”保留在[上一版](../browser-annotation-toolbar-plan-2026-11-04.md)作历史，不与本版叠加显示。

## 2. 同一行的入口与状态

常态顺序为：**后退／前进／刷新 → 批注开关 → 地址栏 → 数量入口及原有网页工具**。布局适配工作区、展开工作区和独立窗口，共用组件规格与实际测量。

- 批注开关沿参考采用选区／指针图标和“批注”短标签；关闭为普通按钮，开启为主题强调色浅底，`aria-pressed` 明确状态。再点同一按钮退出，不再同时常驻“完成”按钮。
- 数量是独立按钮，例如批注列表图标和数字 3，点击只打开 NativePanel 列表，不顺便切换模式。避免同一个“批注 3”按钮既开关又开列表的歧义，也不嵌套两个 button。
- 模式开启时显示数量，零条也可开列表；普通浏览时有记录才显示数量，无记录可从批注开关或更多菜单发现。计数为当前 pageId 下已保存、未删除的记录，不计临时选区或未提交草稿。
- 开关选中态与数量列表展开态分开，打开列表不代表进入点选，关闭列表不代表退出模式。
- 窄窗口优先缩短地址文本和非必要标签，保留批注开关、数量及导航的可用性；不另起一行，不改变网页 viewport。

地址编辑和导航仍可用。执行后退／前进／刷新或新地址导航前，先保留当前草稿并收敛旧批注会话，导航后回到普通浏览；不把旧选区或旧回包附到新文档。

## 3. 简短帮助，不常驻讲解

参考图黑色提示属于辅助说明，不作为常驻第二条工具栏。建议仅首次开启或聚焦／悬停时出现简短说明：“点击或拖选；按住空格临时浏览”，开始选取或输入后收起。

优先沿系统 tooltip／既有帮助能力，不为了复刻黑色大提示卡另加 HTML 覆盖或背景截图。需要完全被动的自定义原生提示卡时，仍按独立命中穿透要求核验；它不是基础批注流必须新增的面板。更多帮助留在数量列表的更多菜单。

## 4. 页面选择与专用光标

点击批注开关后先安全收敛当前输入操作，取得本页批注控制会话，随即待选；不再点第二次“添加批注”。

- 悬停给可见目标轻量蓝色轮廓，点击确定元素；空白处形成点位，超过明确拖动阈值形成区域。不要常驻元素／区域两种按钮。
- 选择链接、按钮或输入框只建立批注，不执行网页业务。点击评论条或工具栏不同时创建页面目标。
- 页面使用专用批注指针，保持与 AI 自动化虚拟光标独立；蓝框和蓝色锚点属于批注装饰层，不随自动化光标设置切换。
- 蓝色锚点提示评论属于哪个目标，可以接近截图的标记效果；不把圆角 NativePanel 参数描述为能直接绘制任意水滴轮廓。选择层绘制蓝框／锚点，原生评论条单独定位。
- 同时只突出当前编辑目标。已保存目标可有小编号，显示／隐藏标记放在列表更多菜单，避免页面叠满蓝框。

滚动、页面 zoom、visualViewport、DPI 和窗口移动时重新计算目标与评论条位置；不能把 NativePanel 跟随父窗口移动等同于跟随网页元素。元素不可验证、导航或 frame 失效时保留草稿并提示重新定位，不把框指向相似元素。

## 5. 目标旁评论面板（以 .7 规划为准）

采用[.7 多行面板](./native-annotation-multiline-panel-plan-2026-11-04.md)的圆角长方形及下方按钮目标；自动增高仍需补齐原生能力，不以固定 height 内滚动代替。以下为 `.6` 单行方案历史，提交规则与视觉尺寸均由新规划覆盖。

评论条使用 NativePanel 原生控件，建议 `row + borderless input + 保存 iconButton`，输入区域不使用会连带响应整行 click 的 item。外壳高圆角、浅色表面、细边和轻阴影，位置贴近蓝色锚点；视觉沿项目主题，暗色也保持目标与文字可读。

建议首版宽约 320–420 CSS px、高约 44–48 CSS px，最终按应用 zoom 换算 DIP，并受可用屏幕和窗口内容区约束。在边缘翻转或缩短，不能遮住全部目标或越过系统窗口控件；不挤压网页。

- 空输入显示“添加评论…”，保存不可用；输入后显示明确的保存图标与可访问名称。Enter 保存这条批注，不发送聊天；中文组合态 Enter 先确认候选。
- 保存成功后收起当前条并继续待选，数量在主进程确认后增加；失败保留文字与目标，就地给短错误，不把数量先加一。
- 外部点击／Esc 收起时保留草稿，不等于保存为历史；需要主动放弃时从目标或草稿菜单处理。IME 的 Esc 优先交给组合输入。
- 点击另一目标前先保留旧草稿，再切换。旧 dismissed、保存和草稿回包按 page／document／target／请求代次拒绝，不清掉刚打开的新条。
- 列表刷新或保存状态变化省略无关 input.value，不重建正在输入的控件；明确恢复草稿才写入对应版本的文字。

图中的麦克风不自动成为需求。首版不放没有录音／识别链路的空按钮，也不申请麦克风权限；若后续需要语音输入，另行定义录音、取消、识别和授权，不能与保存评论混成一个动作。

## 6. 单行新评论与历史长评论

`.7` 目标统一用原生多行面板新建及编辑，不再按单双行分成两个入口。下方是 `.6` 能力限制下的历史兼容策略；保留全文、版本和证据的要求继续有效。

基础流只在用户主动创建或编辑纯单行评论时使用单行输入。保留现有 4000 字限制与评论版本规则，不将换行替换成空格，也不在一次摘要保存中覆盖全文。

粘贴多行文字同样需要保留原文并转入长评论处理，不能因单行控件自动折叠换行就宣称无损。接入前核对真实原生粘贴行为；必要的拦截／转交能力未具备时把这项明确列为兼容缺口，不用读取整个剪贴板历史来绕过。

已有多行批注在列表中可首行省略预览，详情按原文读取；不把全文塞入单行 input。长评论／历史多行编辑保留明确入口，完整原生编辑仍等待多行能力，或另行评审使用既有工作区正常布局的详情编辑。后一种是待确认的布局方案，不在本轮擅自实施，也不把不可编辑隐藏成迁移完成。

因此可用 `.6` 验证基础单行模式，同时单列长评论保真、已有草稿和旧证据回归。若整体发行要求全部原有操作可用，则长评论兼容仍是发行条件；“首版单行”不豁免既定功能和截图清理门槛。

## 7. NativePanel 列表与加入对话

新增[网页右键批注入口](../browser-page-context-menu-plan-2026-11-04.md)：可从原命中位置／选区进入同一批注流程，目标不可验证时明确进入重新选择；不增加底部栏或另一份批注存储。输入继续按 `.7` 多行规划。

保留此前“数量打开 NativePanel 列表”的要求，入口移到正常工具行。默认当前页面，可切当前对话；搜索、筛选、排序在面板内，评论首行为主，状态和来源简短显示。草稿在独立小组恢复，不混入已保存计数。

点击记录查看／编辑，定位先核对锚点；历史来源变化时可查看证据，不擅自命中类似元素。常用动作保留定位、编辑、加入对话，解决／重新打开、比较来源和删除归更多菜单。搜索、滚动及选择按稳定记录 ID 保留。

保存批注、加入对话和发送任务是三步不同动作。加入对话使用 annotationId／annotationRevision 的已有引用，放进正确对话输入区供用户编辑，不自动请求 Agent；删除列表记录不破坏已引用的历史证据。

面板列表与评论编辑有明确的切换顺序，关闭／隐藏先保留草稿。NativePanel 与原生子菜单的归属、外部点击传播仍需实窗验证，不能靠一段延迟 hide 保证。

## 8. 临时操作、退出与任务控制

保留参考图“按住空格临时操作网页”，但仅在页面待选状态生效；评论输入、网页输入控件、contenteditable 和 IME 中的空格保持正常输入。松开返回点选，失焦、漏 keyup 和切标签安全收敛。

不能按住空格的用户可从更多菜单切换临时浏览；这不是常驻工具行按钮。临时浏览期间不落批注，工具开关状态给短暂反馈。

再点批注开关或待选态 Esc 退出模式；编辑态先处理输入法，再收起保留草稿，最后才退出。退出不自动提交／发送，不丢草稿；安全交还遵循原 run／令牌状态，已暂停或结束任务不被旧退出回调重新启动。

切标签或移窗前收敛目标与面板，草稿按真实页面保存；页面再显示时核对身份后恢复，不让当前输入条跟随到另一个标签。公共浏览器会话共享登录不改变批注所属对话与页面。

## 9. .7 已发布与待验证范围

`.7` 已发布多行 textarea，应用仍需接入与真实窗口验证。输入高度自动增长尚缺原生排版测量／自动尺寸契约，不因存在 textarea 类型自动成立，也不以单行验证完成代替新需求。

已有 row、borderless、iconButton、圆角和主题可用于面板结构；页面选择层负责蓝框和锚点。按 `.7` 真实多行字段扩展桥接，具体布局及动作语义以[多行面板规划](./native-annotation-multiline-panel-plan-2026-11-04.md)为准，不重新建设单行胶囊分支。

仍需在后续接入中实测：原生输入法 Enter／Esc、焦点、切目标草稿、目标与屏幕 DIP 转换、滚动／缩放／DPI、实际面板圆角命中和外部点击。`.6` 的 outside-click hook 只是观察；`.7` 关闭和传播按公开契约重新核对，不能从版本号推断关闭点击已被消费。批注选择层需要防止同一次点击穿到业务控件，缺少可靠契约时向定制方补要求，不合成重放点击。

原生面板只接受已发布字段；多行能力已发布不代表自动增高、任意异形外壳、被动穿透或父子 popup 等要求同时满足，各自按 `.7` 契约登记。不中途引入顶层 WebContentsView，不用 HTML 评论条遮挡原生页面。

网页始终是原 WebContentsView，圆角取消的决定保持。蓝框／标记只在选择层绘制，评论正文只进入原生面板。业务取证先隐藏装饰再采集并校验目标，不用取证图铺满实时网页，不触发背景 preview／frozenFrame。

## 10. 实施与验收顺序

1. 用本版入口与 `.7` 多行输入更新状态契约，复用现有目标、草稿、revision、引用和权限链路；不改写旧批注内容。
2. 后续获准实施时，以 `.7` 真实 textarea／下方按钮验证全文提交、Shift+Enter、中文输入与命中边界，再接模式开关、蓝框与锚点；自动增高按缺口单独核验，不以估算字符高度伪造。
3. 接独立数量入口、列表、连续保存、草稿恢复、临时操作和退出；移除底部栏及旧地址行替换分支，保持导航和 viewport。
4. 完成新旧多行评论、草稿和所有旧记录回归；缺失的尺寸能力保留明确状态，不降低原有读写要求或自行将用户目标改成固定高度。
5. 验证实时视频／动画、同一页面实例、表单与滚动保持、Agent 安全交接和零背景截图。工作区、展开工作区、独立窗口、窗口边缘及多 DPI 都有实际证据。

验收必须区分：多行公开能力已发布、应用原生实测通过、自动增高目标满足、历史评论完整兼容、整应用截图替换全部退出，不能用其中一个结论替代其他结论。发行仍按[.7 总规划](../electron-7-readiness-and-implementation-plan-2026-11-04.md)的既定门槛。

本轮只重新规划，未实现新控件、录音、多行降级或修改用户资料。
