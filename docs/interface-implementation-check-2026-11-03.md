## 已接入的行为

- **附加与富文本。** 主输入和队列编辑共用图标附加菜单，支持 `/`、输入框上方左对齐、搜索、键盘选择与内部滚动。添加分组提供文件、页面、会话；工具分组提供插件／技能创建器；更多来源接入消息、标注、文字代码、网址、本地导入、已安装技能与插件说明。后两者附加说明副本，不自动安装或执行。引用可穿插正文，摘录保持可编辑；选区显示链接、加粗、斜体与段落／标题／列表浮层，无固定格式栏，帮助列出快捷键。
- **文档与发送。** 文档升级至版本 2，兼容版本 1；草稿、复制粘贴、来源、队列及发送使用同一结构。未知未来版本保留原始数据并阻止覆盖，避免旧客户端静默丢弃。提交冻结正文及已确认模型／推理档／回答方式；跨窗配置变化会拒绝新提交或暂停已接受队列，不静默换端点执行，重复回执保持幂等。
- **输入区控件。** 回答方式与权限具有图标；模型面板可搜索、按服务商分组，显示上下文／图片／思考能力、加载／重试／失效状态。保存选择期间禁止错发。发送区区分普通发送、运行中插入／排队与停止。上下文环明确是历史及当前输入的文本估算；系统、工具和图片等未计入项不造零，服务返回的实际输入／输出／总计／缓存用量单独持久化展示，最新回复缺少用量时显示未知。
- **工作区与查找。** 展开时当前聊天成为固定首标签，与文件／网页统一导航；普通标签统一为 36px 高，共用宽度、内距和视觉状态，固定网页保留图标窄标签。仅保留一个聊天编辑器，切换保留草稿、文件阅读位置、网页表单和聊天阅读位置。当前聊天的搜索／更多／摘要，以及文件／网页工具按活动标签切换，位于标签栏右侧分隔线左边。聊天标签拖出栏外恢复分栏。Ctrl/⌘ F 在当前聊天查找，支持计数、高亮、前后跳转、工具／日志选项及输入法保护；查找与流式更新不抢阅读位置，Ctrl/⌘ K 保持跨聊天搜索。
- **摘要提示。** 首次载入的历史资源保持安静；新增文件、文件内容变化和首次有效网页生成未读提示，重复事件、网页标题／加载更新及空白页不重亮。只在摘要实际可见时清除；隐藏但挂载的摘要不误清，切换对话独立保留未读，删除资源后同步移除失效提示，不再自动展开摘要。
- **浏览器弹层与资源。** 弹层先取得、解码并呈现冻结画面，再挂起原生 view；带短超时、失败说明和过期结果取消。资源界面支持当前／全部对话、有页面／全部会话、名称与网址搜索、改名和默认会话。关闭页面保留 Cookie／站点存储，不保证站点登录始终有效；清除网站数据、删除会话分别确认，并遵循网页取消关闭的结果。纯浏览器没有页面时隐藏整条标签栏，新建首个页面后恢复；新标签页没有文件时隐藏空文件卡。
- **设置与组件。** 移除全局应用按钮；开关、单选等自动保存，路径、连接和数值等 11 组使用具名局部提交。采用比较基线的字段事务，避免多窗口覆盖；保存失败可重试，最近自动修改可撤销。普通未提交草稿在本窗口返回后恢复，凭据离开前确认且不写入草稿缓存。路径提交先检查目标可写；远程监听按实际 host／port 重绑，失败原值可重试。修复开关位移、双重焦点、模型表单溢出和只查看设置就产生修改的问题，模型高级能力折叠并保留原值。
- **控制权、光标与外观。** 启用输入保护且页面已取得任务租约时，保护贯穿整轮任务及工具之间的等待，鼠标移入不自动接管；显式人工接管仍可中止并等待清理。隐藏光标图形不解除鼠标／键盘保护。接入 Navora 箭头、焦点环、精密十字三款原生图像与缩放热点。标题栏统一品牌与菜单间距，移除导航顶部细线、保留 12px 留白，地址栏 Agent 按钮内缩。继续使用项目 Fluent Regular 图标和主题变量。

## 验证边界

定制 Electron 的原生光标图像、输入保护参数及状态确认已经接入，已验证真实原生点击、iframe 和任务状态；隐藏窗口中的自动化检查不能证明前台物理鼠标／键盘被 OS 层完全阻断，也不能证明所有显示缩放和 GPU 合成环境下光标都可见。此项保留实机验收，不能标成已验证全部物理输入。

整轮保护不覆盖未取得该轮租约的其他网页、主动关闭输入保护的配置或缺少运行身份的旧式短调用。缺少必要原生能力时拒绝受保护输入，不采用不安全的 DOM 替代；光标图像能力缺失时可保留原生默认可见光标，但不会假装支持受保护隐藏光标。会话原生 14 项中的取消关闭由故障注入验证事务回滚；源码等待 beforeunload 结果，真实站点确认框交互仍需实机检查。用量展示最近一次服务商请求，不是多轮累计；发送前文本估算不是模型 tokenizer 的精确计量。

未运行 macOS／Linux 真机、真实触屏／系统输入法全过程、第三方模型账单校准、真实站点登录／反自动化、安装器交互或长时稳定性。较大的首屏构建产物仍有 Vite 提示，不冒充构建失败，也未以无关拆包替代本轮交互修复。
