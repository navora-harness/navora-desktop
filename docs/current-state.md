# 当前功能与验证边界

更新日期：2026-11-01。版本以 package.json 为准。本文描述已实现行为；具体界面与安装回归入口见末节。

## 主窗口与侧栏

左侧图标栏提供对话、文件、浏览器、插件以及更多、下载、设置。新对话与搜索位于对话列表上方；Ctrl/⌘ N、Ctrl/⌘ K 在导航收起时仍可使用。对话、文件、浏览器和插件为独立单选入口，没有拖动组合或预设组合。侧栏可调宽；关闭导航只保留图标栏，文件或插件详情工作区继续保留，避免切换时反复重建对话。

右上角固定显示右侧栏开关和页面更多菜单，与系统窗口按钮分开。对话菜单提供浏览器、摘要、文件夹、标题、置顶、导出、删除及运行时停止；切换文件、插件、设置、创建器时，菜单入口保留并改为对应页面操作。

对话列表采用紧凑标题行，提供批量置顶和删除；当前为空对话时重复新建会复用它。设置在主窗口内显示，对应设置导航使用左侧栏。创建器、设置、帮助和插件工作区按需加载。

对话、文件、浏览器、插件侧栏及右侧文件预览、资源卡片的右上角统一使用更多菜单；隐藏操作收纳在菜单内。文件预览还可从菜单关闭当前标签页，隐藏整个预览不会清除已打开的标签。菜单支持方向键、回车和 Escape，关闭菜单不会隐藏侧栏。

## 对话与执行

普通问答、执行任务和自动选择继续共用现有模型配置。输入框自动增高；模型和思考等级在同一面板选择。输入 `/文件`、`/会话`、`/浏览器` 或 `@` 选择已有资源；文件引用使用真实工作区路径，浏览器保留结构化资源身份。运行中消息默认入队，可编辑、删除或插入，设置可修改默认方式。

中间说明、工具调用、自动化、插件、思考和日志归入统一执行详情，默认折叠且收起时不显示外框。最终答复单独显示，附件位于答复底部。手动关闭浏览器或释放会话不追加对话日志；执行中的 Agent 仍会得知已关闭的资源。

新运行持久记录 runId、初始 turnId 和消息追加序号。浏览器下载在进程内保持原任务归属，状态变化去重，实际完成后才关联产物；旧下载晚于下一提问完成时，仍附到原答复。尚未实现完整的持久事件系统、断点恢复或各阶段耗时分析。

## 文件与浏览器

文件导航管理全部对话的有文件资源，隐藏无文件对话；右侧主区域为文件管理视图，支持列表/网格、目录、搜索与排序。打开文件使用右侧标签页预览，保留所属对话和路径，不因预览切换当前对话。预览工具栏提供图片缩放、默认应用打开、打开所在文件夹和通过系统保存对话框另存为或下载。右侧加号新建网页标签，文件选择移至侧栏更多菜单；文件与网页可并列为标签，关闭网页不影响文件。侧栏网页使用独立隔离视图，不与 Agent 浏览器窗口混为同一资源；后者仍从页面更多菜单和浏览器导航管理。当前支持受大小限制的文本、Markdown 和图片阅读，尚未提供通用文件编辑、PDF/表格原生编辑或图片标注。

当前对话摘要卡片展示输出、来源与浏览器，入口使用摘要图标。空间足够时并列，空间不足时覆盖对话，点击卡片及其菜单之外收起。资源管理器按钮直接打开该对话的系统文件夹。会话滚动条保持在对话工作区最右侧，卡片开关不移动它。

浏览器导航管理全部对话的会话和窗口。Agent 决定何时关闭或释放资源，子任务结束不会一律销毁登录态。主文档与开放 Shadow DOM 支持内容快照；闭合 Shadow 与跨域 frame 有原生定位/查询能力，尚不等于完整跨文档内容索引。网页导航实际转为下载时，返回下载移交状态，不能将下载开始描述为已经完成。

## 插件工作区与商店

点击左侧插件图标，导航中提供搜索插件、已安装插件、插件商店。已安装分类只读取本机；搜索可同时匹配已安装的名称、用途和工具，以及商店产品和变体，避免重复列出同一已安装包。商店不可达时仍可管理本机插件，失败后可重试并保留已读取列表。

右侧显示插件介绍、来源、启停状态、安装位置、说明、工具与版本。支持本地 ZIP 导入、文件夹外链、导出、卸载和创建器；随附插件可以停用，不能卸载或覆盖。已停用插件已知的工具列表仍可查看，加载失败会显示错误。说明按 Markdown 清理后展示，不执行其中脚本。 插件工作区、本地说明和商店详情使用统一阅读组件：标题层级、列表、提示块、代码复制与表格滚动保持一致；长文档提供章节目录，窄区域改为可展开目录，章节链接在原文内定位。

商店安装、更新、变体更换继续使用原安装器与确认步骤，校验版本约束、路径、字节数和 SHA-256，再交给 PluginStore。安装后原位刷新本机状态。插件工作区的管理列表保留来源/状态筛选与批量操作；设置中仅保留开发模式开关；技能商店仍从设置 → 技能进入。

当前商店是本地或可切换源的静态目录，不是公共发布平台。跨平台产物自动选择、原生运行时下载和托管子进程属于后续设计，见 [跨平台安装规划](./plugin-platform-installation-plan.md)。

## 验证与范围

- `npm run build`：类型检查、源码测试、前端及主进程构建。
- `npm run test:ui:plugins`：真实桌面内核、独立临时配置，验证插件导航、搜索、说明、启停、导入导出、安装更新卸载、失败重试、窄屏及减少动效；目录和包来自隔离的本地测试商店。
- `npm run test:ui:creators`：插件/技能创建、安装、试用及设置中的库管理。
- `npm run test:ui:renovation`、`npm run test:ui`：对话、资源、文件、模型及通用界面回归。
- `npm run test:browser`：当前定制内核的浏览器和插件契约。

开发验证平台为 Windows。构建目标包含 macOS/Linux，尚未以本轮 Windows 回归替代其它平台实机验收。真实服务、站点、真实模型延迟与隔离本地测试分别记录；不因本地测试通过承诺任意站点或第三方商店可用。
