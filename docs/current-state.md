## 浏览器 Agent 自动化（2026-11）

- Windows x64 运行时升级到 Electron `45.0.0-cloudbypass.3`，新增原生覆盖感知快照和查找，并将原生 target 接入浏览器点击、鼠标、键入、按键及触摸工具。该能力可读取跨域 iframe 和开放/封闭 Shadow DOM，并支持在未显示/未聚焦窗口中派发可信输入。

## 工具授权请求

同一对话的并发工具请求按到达顺序排队；切换对话后展示所选对话及其子对话的待处理授权，处理或取消一项只移除对应请求。卡片优先提供单次允许/拒绝，并区分“本次运行中，此对话允许/拒绝”。后两项只在当前应用运行期间生效，不会写入长期权限设置。请求说明中的 token、Cookie、密码、密钥及常见认证头会在显示前脱敏。

本轮验收在桌面界面注入并发请求，检查先进先出、仅取消对应项、切换对话隔离和敏感值隐藏；完整结果记录在 `release/ui-renovation`。

## 弹层定位、文件查找与队列编辑

地址建议跟随浏览器内容区的尺寸和位置变化，调整侧栏或工作区宽度后自动重新对齐；窗口较矮时根据可用空间向上或向下展开，避免固定最小高度造成越界。打开的右键菜单在窗口缩放或菜单内容尺寸变化后重新限制到可视范围，继续支持方向键、Home/End 和 Esc，关闭后返回原输入或文件条目。

文件查找新增“显示更多”，每次增加 30 项，允许访问索引内的全部匹配结果；搜索、类型筛选或切换对话时重置批次并回到列表顶部，保留索引截断和部分目录不可读的说明。展开更多后焦点移至第一条新增结果，图片、代码与文档显示对应 SVG 图标。文件选择弹窗采用单层背景和一致的内外宽度，修复右侧空白外框；打开后聚焦搜索，矮窗口中仅列表滚动，搜索、筛选、关闭与结果数量保持可见。

编辑待发送消息时自动聚焦输入框，取消和保存后恢复到编辑按钮；支持 Ctrl/⌘+Enter 保存、Esc 取消，并忽略输入法组合期间的快捷键。快捷键与按钮共用空内容、长度和忙碌检查，避免空消息触发失败提示及重复提交。取消队列编辑不会停止当前任务。

## 新标签页、地址栏与资源侧栏

新建网页在主工作区和独立窗口显示同一个本地首页：推荐访问、快捷访问、最近访问。推荐入口为 Bing、GitHub、MDN、Wikipedia，全部使用应用自己的 SVG 图标，不请求外部图标或预加载站点。页面保持单列分区与轻量网格，自适应 320px 及以上宽度。

快捷访问可添加、编辑名称与网址、移除，也可通过地址栏星标保存当前网页；最多 12 项，所有本地窗口共享。历史由实际成功加载的网页及主框架内导航记录，重复地址更新到最前，最多保留 200 项；按对话隔离，支持单条移除和清空当前对话记录。数据保存在配置目录的 `browser-start.json`，采用原子替换，异常原始文件改名保留，退出时刷新待写历史。推荐入口不会自动产生访问记录。

地址栏未编辑时简化显示协议和末尾斜线，聚焦后提供完整网址并选中。输入网址直接打开，普通关键词使用 Bing 搜索；工具导航的 URL 校验规则保持不变。候选来自快捷访问和当前对话历史，支持方向键、Enter、Esc 与输入法组合保护；下拉展开时网页保留预览并让出原生点击区域，收起后恢复。网页中的 Ctrl/⌘ L、F、T 会将焦点交给相应应用控件，异步加载完成不会抢走用户刚开始的输入。

工作区标签栏统一紧凑高度和圆角，当前页以浅蓝底及底边标记突出；关闭按钮收窄并与标签融为一体，非活动页仅在悬停或键盘聚焦时显示关闭按钮，减少标签行的视觉噪声。

下载直接合并到所属对话的实际文件树和主文件列表，不增加下载标签或单独下载分区。文件树统一 28px 单行条目与 16px 层级缩进，展开目录使用细引导线与旋转箭头，选中项使用轻底色和左侧标记；对话分组不再使用大块选中底色。下载和普通文件严格同高，行背景与底边细线承载进度，右侧以百分比或暂停、完成、失败、取消图标表示状态；悬停可查看状态和传输字节，状态保留无障碍说明。侧栏和主文件列表复用同一个下载指示组件，进度层不占高度、不拦截点击，支持减少动态效果。

下载目标尚未落盘时先显示待下载文件，完成后原行转为本地文件，避免出现重复项；仅过滤明确对应当前下载的 Chromium 临时文件。新下载首次展开其目标文件夹，持续进度不会重置当前目录，也不会反复展开用户收起的文件夹。未完成文件不会打开预览，右键按可用能力提供暂停、继续、取消；工具下载可停止所属对话的当前任务。清除下载状态会保留文件，已删除的完成文件不会被历史记录重新生成。下载状态沿用现有内存记录生命周期，重启后本地文件正常保留。

进入文件主界面会收起之前的浏览器预览，网页及标签继续保留，避免展开的浏览器遮住文件列表；右键操作返回焦点只改变文件选中项，不会误开预览。文件侧栏和主文件列表共用路径匹配与状态规则，按对话和完整相对路径关联，支持嵌套目录、递归搜索和同名文件。桌面活动栏底部取消独立下载入口，文件图标显示进行中数量或新完成提示，浏览器图标显示页面数量；移动端和浏览器工具栏保留便捷下载入口。侧栏入口名称简化为“对话文件”“浏览器资源”，范围标题去掉“全部”。

文件主内容区使用紧凑目录工具栏与浅色内容面板：宽窗口把目录、刷新、搜索、排序和视图切换放在同一栏，窄窗口自动分行。目录面包屑标明当前位置，新增返回上一级按钮，根目录禁用该操作；标题在窄区域保持单行，并保留原生窗口控件的空间。列表默认 38px 行高，搜索显示相对路径时统一为 46px，网格为 104px 等高卡片；下载始终与同视图的普通文件等高。文件夹、图片、代码和文档使用配套 SVG 图标，大小与时间采用弱化文字，进度沿用整行或整卡片的背景及底边。空目录、空搜索和加载失败提供相应说明与恢复操作；搜索筛除当前选中项后仍可用键盘聚焦首个结果。

浏览器资源取消“已隐藏”和显示/隐藏切换，统一点击打开，以背景、文字和边缘指示标明选中页面；多个宿主窗口共享唯一的资源选中状态。底层原生视图在切换、弹层覆盖和离开工作区时仍正确让出内容区域。独立浏览器与文件窗口改用和主窗口相同的系统窗口控件：Windows 标题栏覆盖层、macOS 交通灯、Linux 原生框架；标签页保留在应用标题行，并为系统控件预留空间。

## 批注草稿恢复（阶段一）

草稿逐个读取和校验。JSON、字段、文件名或大小不合法的文件会单独改名隔离，保留原始内容；健康草稿继续读取与写入，批注面板提供可展开的异常文件提示。隔离记录在再次启动后仍可识别，不会用新草稿覆盖原始坏文件。

跨窗口写入发生版本冲突时，主进程先将被拒绝的文字另存为冲突副本，再返回冲突。副本按批注和编辑窗口分别保存，较旧的输入序号不能替换较新的文字。即使用户停止输入，输入框获得焦点时发现其他窗口的新草稿，也会主动保留当前文字。界面仅在确认副本已落盘后提示已保留；写入失败时保留编辑缓冲，禁止直接载入其他草稿丢弃本地文字。

每张批注卡片可展开冲突副本，查看文字和时间，采用某份副本或与当前输入合并。合并超过 4000 字时提示先缩短文字。采用和合并均检查看到的草稿版本及副本输入序号；期间再次更新会拒绝覆盖，失败的合并候选单独存为一份副本，保留合并前的两份文字。成功后仅清除所选副本，其他副本继续保留，意见仍需用户主动保存。恢复记录不会出现在“输出内容”的成果列表中，工作区仍允许显式读取原始文件。

批注列表支持当前页面/当前对话范围、按处理状态筛选，以及按标题、网址、选区文字、已保存意见和本地草稿检索；可切换最新优先或最早优先。长历史每批显示 20 条；截图只在条目进入当前批次时读取。筛选和排序暂时隐藏卡片不会丢失该卡片的编辑缓冲。搜索框按向下键聚焦首条结果，结果卡片可用上下键切换；卡片内仍可通过 Tab 操作定位、截图展开和编辑。当前页面网址与批注创建时网址不同时，卡片标出“与当前页面不同”，并继续显示创建时快照。

同一浏览器标签的批注卡片可主动检查创建时与当前页面的网址、标题及选区锚点。元素批注会检查 CSS 定位符是否唯一、元素是否仍存在及文字是否变化；不会滚动页面或更改批注。区域批注不运行像素相似度判断，提示用户查看创建时截图。来自其他标签的批注不提供当前页比较按钮。

新增 `npm run test:ui:browser:recovery`：使用同一临时配置，正常退出应用后启动全新进程，检查内嵌页与独立窗口的身份、网址、宿主归属，以及草稿、副本、损坏文件隔离和界面合并操作；不操作日常使用的配置或窗口。截图见 `release/ui-browser-recovery/recovered-drafts.png`。

## 浏览器操作与故障恢复

本轮优化接管与批注的衔接、草稿跨窗口保留及下载菜单。下载面板与子菜单采用统一的 12px 圆角、单层边框/阴影、主题配色与按钮规格；弹层按入口方向展开，工具栏入口向下，侧栏底部入口向上，保持在窗口边界内。键盘焦点和减少动态效果继续支持。

## 主窗口与侧栏

左侧图标栏提供对话、文件、浏览器、插件以及更多、下载、设置。新对话与搜索位于对话列表上方；Ctrl/⌘ N、Ctrl/⌘ K 在导航收起时仍可使用。对话、文件、浏览器和插件为独立单选入口，没有拖动组合或预设组合。侧栏可调宽；关闭导航只保留图标栏，文件或插件详情工作区继续保留，避免切换时反复重建对话。

对话右上角固定显示摘要、工作区开关和页面更多菜单，与系统窗口按钮分开。更多菜单保留打开或复用浏览器、文件夹、标题、置顶、导出、删除及运行时停止；新对话、搜索和工作区切换不再重复出现在菜单内。切换文件、插件、设置、创建器时不显示聊天摘要和工作区开关；设置的应用、插件的刷新与管理留在对应页面，避免与全局菜单重复。

对话列表采用紧凑标题行，提供批量置顶和删除；当前为空对话时重复新建会复用它。列表初次显示最近 60 个主对话，点击底部按钮每次再显示 60 个；搜索仍覆盖全部对话，切换到较早的当前对话时会自动显示到该项，批量管理模式显示完整列表。系统不会自动归档或删除旧对话。设置在主窗口内显示，对应设置导航使用左侧栏。创建器、设置、帮助和插件工作区按需加载。

导航侧栏标题新增直接隐藏按钮，并保留更多菜单的隐藏入口。右侧统一称为工作区，文件与网页共用标签栏；标签右侧提供新建网页、更多、展开/还原和隐藏，窄栏把展开收进更多。更多菜单可打开文件、关闭标签或将网页移至独立窗口。隐藏保留标签与页面；右侧工作区没有标签时打开会创建一个默认新标签页；已有文件或网页时恢复原选择，隐藏再打开不会重复创建，关闭所有标签后再打开会重新提供默认页。分隔线支持拖动、键盘调整和双击恢复宽度。菜单支持方向键、回车和 Escape；上下文菜单关闭后归还焦点。

## 工作区默认标签与菜单覆盖

右侧工作区通过统一打开入口补齐默认浏览器标签，当前没有标签时才创建；已有文件或网页时保留原标签和选中状态。首次默认页聚焦地址栏，关闭最后一个标签仍会收起工作区，再次打开生成一个新页。标签初始化尚未返回页面身份时关闭，会先按稳定标签键取得同一页面再关闭，避免留下孤立页面。浏览器主内容区的空状态保持独立，不因打开浏览器侧栏自动创建页面。

共用 ActionMenu 的样式直接覆盖传送到弹层容器的菜单，按竖排列出操作，统一图标、留白、分隔线、焦点和禁用状态；弹层外壳不再重复叠加背景与边框。原生网页与弹层相交时，在隐藏原生表面前获取并解码当前画面，使菜单背后的网页保持可见；菜单退出后恢复同一原生页面，保留输入、滚动和运行状态，不重新加载。没有覆盖网页的弹层不暂停网页表面。画面只暂存在内存，关闭弹层或切换页面后释放；预览接口仅向所属宿主窗口返回当前活动页，离屏测试宿主不提供原生合成画面。

## 对话与执行

## 文件与浏览器

文件导航管理全部对话的有文件资源，隐藏无文件对话；右侧主区域为文件管理视图，支持列表/网格、目录、搜索与排序。打开文件使用右侧标签页预览，保留所属对话和路径，不因预览切换当前对话。预览工具栏提供图片缩放、默认应用打开、打开所在文件夹和通过系统保存对话框另存为或下载。右侧加号新建网页标签，文件选择移至侧栏更多菜单；文件与网页可并列为标签，关闭网页不影响文件。网页标签与 Agent 浏览器现在共用稳定的页面记录和 Session，通过原生 WebContentsView 内嵌到右侧。支持调整侧栏宽度、展开、固定视口、独立网页缩放，以及标签排序、拖出为独立窗口、拖回合并；独立窗口也提供菜单移回入口。迁移保留同一 webContents，关闭标签遵循页面关闭提示，隐藏面板不销毁页面。当前支持受大小限制的文本、Markdown 和图片阅读，尚未提供通用文件编辑、PDF/表格原生编辑或图片标注。

当前对话摘要卡片展示输出、来源与浏览器，入口使用摘要图标。空间足够时并列，空间不足时覆盖对话，点击卡片及其菜单之外收起。资源管理器按钮直接打开该对话的系统文件夹。会话滚动条保持在对话工作区最右侧，卡片开关不移动它。

浏览器导航管理全部对话的会话和窗口。Agent 决定何时关闭或释放资源，子任务结束不会一律销毁登录态。主文档与开放 Shadow DOM 支持内容快照；闭合 Shadow 与跨域 frame 有原生定位/查询能力，尚不等于完整跨文档内容索引。网页导航实际转为下载时，返回下载移交状态，不能将下载开始描述为已经完成。

网页批注支持元素选择和区域框选，保存创建时截图、选区、URL、视口和意见。批注加入输入框后由用户发送；快照按版本保留，支持图像输入的模型能读取实际图片。处理完成转为待核对，用户确认解决；定位仅在当前元素与历史文本可靠匹配时高亮，否则保留历史快照。批注期间暂停 AI 页面操作，用户点击恢复后继续。远程端可查看历史批注，不支持创建或窗口拖拽。

持久 Session 的页面 URL、分组与固定视口写入本地恢复文件；重启后重新加载页面，不恢复 JS 内存、未提交表单或运行中的任务。临时 Session 不恢复。多显示器实际拖拽、平台差异与各类登录弹窗仍需在目标环境验收，不能把本机自动化回归等同于所有网站兼容。

## 插件工作区与商店

点击左侧插件图标，导航中提供搜索插件、已安装插件、插件商店。已安装分类只读取本机；搜索可同时匹配已安装的名称、用途和工具，以及商店产品和变体，避免重复列出同一已安装包。商店不可达时仍可管理本机插件，失败后可重试并保留已读取列表。

右侧显示插件介绍、来源、启停状态、安装位置、说明、工具与版本。支持本地 ZIP 导入、文件夹外链、导出、卸载和创建器；随附插件可以停用，不能卸载或覆盖。已停用插件已知的工具列表仍可查看，加载失败会显示错误。说明按 Markdown 清理后展示，不执行其中脚本。 插件工作区、本地说明和商店详情使用统一阅读组件：标题层级、列表、提示块、代码复制与表格滚动保持一致；长文档提供章节目录，窄区域改为可展开目录，章节链接在原文内定位。

商店安装、更新、变体更换继续使用原安装器与确认步骤，校验版本约束、路径、字节数和 SHA-256，再交给 PluginStore。安装后原位刷新本机状态。插件工作区的管理列表保留来源/状态筛选与批量操作；设置中仅保留开发模式开关；技能商店仍从设置 → 技能进入。

当前商店是本地或可切换源的静态目录，不是公共发布平台。跨平台产物自动选择、原生运行时下载和托管子进程属于后续设计，见 [跨平台安装规划](./plugin-platform-installation-plan.md)。
