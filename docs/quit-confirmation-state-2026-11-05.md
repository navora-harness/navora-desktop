# 退出确认的实际运行状态

日期：2026-11-05。已实施并纳入 Windows x64 0.4.12。

## 行为

- 全应用没有运行中的 Agent：只显示“确定要退出程序吗？”。
- 有活动任务：显示“当前有 N 个 Agent 正在运行，退出将停止这些任务。确定退出吗？”。其他主对话和子任务一并计入。
- 打开确认框时查询主进程实际状态，框内收到任意聊天的运行状态变化时刷新。查询期间不把未知状态显示为 0；查询失败显示重试，不能直接确认退出。
- 取消保留草稿和任务。确认后先保存问卷及消息草稿，再次核对运行数；任务增加时更新提示并要求再次确认。主进程提交前同步检查，堵住最后一次查询与退出之间的新任务竞态。

## 实施依据

`AgentRuntime.runningChatIds()` 含正在取消清理的运行租约，所以数量必须再经 `isRunning(id)` 过滤；历史 `spawnStatus`、当前聊天指示灯及渲染器缓存都不是全应用活动数。

共享退出状态位于 `shared/app-quit.ts`；`electron/modules/app-quit.ts` 提供实际计数及提交保护。状态查询和退出仍是仅限本地主窗口的 IPC，远程界面不获得退出宿主的能力。`useAppQuitConfirmation` 处理查询代次、关闭/销毁后旧响应及错误重试，`ChatPage` 让菜单、托盘请求与快捷键沿用同一确认框。

## 验证与交付

完整构建与类型检查通过，842 项单测通过。新增定向单测覆盖跨聊天/子任务、停止清理租约、提交前任务增加、任务减少以及无效确认参数。实际主窗口 23 项检查通过，渲染异常 0，包含查询乱序、关闭后的迟到响应、重试、保存时新任务、提交竞争与草稿保留。

界面测试使用临时合成聊天和受控 AbortController 状态；零任务场景调用真实主进程查询，有任务场景使用真实计数函数和无副作用的提交器，没有调用模型或停止真实任务。通过报告与截图见 [0.4.12 发行说明](../release/v0.4.12/RELEASE-NOTES.zh-CN.md)。

安装版及便携版的 28 个应用构建文件、67 个运行资源、两包各 77 个内嵌文件和核心摘要核对通过。成品隔离启动版本 0.4.12、错误列表为空、自然退出 0、未强杀、测试资料已清理；没有替换日常个人安装。
